# Optimal Learning Path

If you're studying this seriously, follow this order:

1. HTTP + REST API
2. Java Core + basic Spring Boot
3. SQL + transactions + indexing
4. XML + SOAP + WSDL
5. Integration patterns
6. TIBCO BW6 process design
7. TIBCO error handling / deployment
8. API Gateway (Kong/WSO2)
9. Redis cache
10. Kafka async messaging
11. Security + observability
12. Capstone project

## A note on interview prep

Interview prep should only be an **appendix at the end of the course**. The real core is: how do you design an integration system that is **correct, stable, secure, traceable when something fails, resilient under load, and never corrupts transactional data**.
