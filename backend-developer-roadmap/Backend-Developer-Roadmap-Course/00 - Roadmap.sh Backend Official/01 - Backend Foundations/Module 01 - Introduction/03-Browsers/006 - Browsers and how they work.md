## 1. Tom tat

Bai nay giai thich **Browsers and how they work?** trong boi canh backend hien dai. Sau bai hoc, ban nen nam khai niem, biet vi sao no quan trong va co mot bai tap nho de ap dung.

## 2. Muc tieu hoc tap

- Giai thich duoc Browsers and how they work? bang ngon ngu cua ban.
- Nhan biet khi nao kien thuc nay xuat hien trong backend project.
- Thuc hanh mot vi du nho va ghi lai loi thuong gap.

## 3. Khai niem chinh

- Browser parse HTML/CSS/JS, gui HTTP request va enforce security policy.
- Backend can hieu browser vi CORS, cookie, cache, CSP va HTTPS deu bi browser kiem soat.
- DevTools network tab la cong cu debug backend/API cuc ky huu ich.
