## 1. Tom tat

Bai nay giup ban danh gia **Ruby** nhu mot ngon ngu backend: diem manh, he sinh thai, use case va nhung kien thuc can hoc de xay service that.

## 2. Muc tieu hoc tap

- Biet khi nao nen chon Ruby cho backend.
- Nam toolchain co ban: package manager, framework, testing va deployment.
- Xay duoc mot API nho voi database hoac storage don gian.

## 3. Khai niem chinh

- Ruby noi tieng voi Ruby on Rails va toc do phat trien product nhanh.
- Rails co convention manh cho MVC, ORM, migration va testing.
- Can hieu dynamic language trade-off va performance boundary.

## 4. Vi du / Demo

```text
Input: mot yeu cau backend nho
Process: ap dung khai niem trong bai vao API, database, queue hoac deployment
Output: ghi lai ket qua, loi gap phai va cach debug
```

## 5. Bai tap thuc hanh

- Cai toolchain Ruby va tao HTTP server hello-world.
- Them endpoint CRUD nho va validate input.
- Ket noi database hoac in-memory storage, sau do viet test cho mot endpoint.

## 6. Loi thuong gap

- Hoc thuoc dinh nghia nhung khong tao vi du.
- Bo qua edge case vi demo nho van chay.
- Khong ghi lai cau hoi con mo de quay lai sau.

## 7. Checklist hoan thanh

- Toi co the giai thich **Ruby** trong 1-2 phut.
- Toi co mot vi du nho hoac ghi chu thuc hanh cho bai nay.
- Toi biet bai nay lien quan den API, database, security, deployment hoac operations nao.
- Toi da ghi lai it nhat mot cau hoi can tim hieu sau neu con mo ho.

## 8. Tong ket

**Ruby** la mot moc trong lo trinh backend. Hay bien no thanh mot vi du nho, mot checklist debug, hoac mot project mini de kien thuc co cho bam.
