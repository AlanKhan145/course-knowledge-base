## 1. Tom tat

Bai nay giai thich **Prompt Engineering Roadmap** trong boi canh backend hien dai. Sau bai hoc, ban nen nam khai niem, biet vi sao no quan trong va co mot bai tap nho de ap dung.

## 2. Muc tieu hoc tap

- Giai thich duoc Prompt Engineering Roadmap bang ngon ngu cua ban.
- Nhan biet khi nao kien thuc nay xuat hien trong backend project.
- Thuc hanh mot vi du nho va ghi lai loi thuong gap.

## 3. Khai niem chinh

- Prompt engineering giup giao viec ro cho AI.
- Backend prompt nen co schema, API contract, error case va test expectation.
- Prompt tot tiet kiem thoi gian review va giam output lan man.

## 4. Vi du / Demo

```text
Request -> Validate input -> Call model/provider -> Validate output -> Log cost/latency -> Return result
```

## 5. Bai tap thuc hanh

- Viet 5 dong tom tat bai hoc khong nhin tai lieu.
- Tao vi du nho trong sandbox backend hoac ghi pseudo-code.
- Tim mot loi production co the lien quan va viet cach debug.

## 6. Loi thuong gap

- Tin output AI ma khong validate schema/permission.
- Khong do latency, token cost va failure rate.
- Log prompt/output co du lieu nhay cam.

## 7. Checklist hoan thanh

- Toi co the giai thich **Prompt Engineering Roadmap** trong 1-2 phut.
- Toi co mot vi du nho hoac ghi chu thuc hanh cho bai nay.
- Toi biet bai nay lien quan den API, database, security, deployment hoac operations nao.
- Toi da ghi lai it nhat mot cau hoi can tim hieu sau neu con mo ho.

## 8. Tong ket

**Prompt Engineering Roadmap** la mot moc trong lo trinh backend. Hay bien no thanh mot vi du nho, mot checklist debug, hoac mot project mini de kien thuc co cho bam.
