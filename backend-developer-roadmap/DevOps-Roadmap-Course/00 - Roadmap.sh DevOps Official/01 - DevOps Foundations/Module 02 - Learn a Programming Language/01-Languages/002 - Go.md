## 1. Tom tat

Bai nay giai thich **Go** trong boi canh DevOps/SRE hien dai. Sau bai hoc, ban nen biet no la gi, nam o dau trong workflow van hanh va cach bien no thanh thuc hanh language nho.

## 2. Muc tieu hoc tap

- Giai thich duoc Go bang ngon ngu cua ban.
- Nhan biet no xuat hien o dau trong DevOps workflow thuc te.
- Ap dung vao mot demo, command, config, pipeline hoac runbook nho.

## 3. Khai niem chinh

- Go tao binary don, chay nhanh va phu hop tool ha tang.
- Can nam module, goroutine, context, error handling va test.
- Nhieu cloud native tool nhu Kubernetes, Terraform ecosystem va CLI hien dai gan voi Go.

## 4. Vi du / Demo

```go
package main

import "fmt"

func main() {
    fmt.Println("devops automation starts small")
}
```

## 5. Bai tap thuc hanh

- Viet script Go doc mot file config va in ra mot report nho.
- Them xu ly loi, exit code va README cach chay.
- Chay script voi input dung va input loi de xem behavior.

## 6. Loi thuong gap

- Hoc thuoc dinh nghia nhung khong tao vi du.
- Bo qua edge case vi demo nho van chay.
- Khong ghi lai cau hoi con mo de quay lai sau.

## 7. Checklist hoan thanh

- Toi co the giai thich **Go** trong 1-2 phut.
- Toi co mot vi du nho hoac ghi chu thuc hanh cho bai nay.
- Toi biet bai nay lien quan den delivery, operations, reliability, security hoac automation nao.
- Toi da ghi lai it nhat mot cau hoi can tim hieu sau neu con mo ho.

## 8. Outcome lien quan

Pick one automation language and write small scripts for APIs, files, processes, and cloud tooling.

## 9. Tong ket

**Go** la mot moc trong lo trinh DevOps. Hay bien no thanh mot script, mot config, mot dashboard, mot pipeline, hoac mot runbook nho de kien thuc co cho bam.
