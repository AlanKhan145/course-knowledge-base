## 1. Tom tat

Bai nay giai thich **Git** trong boi canh DevOps/SRE hien dai. Sau bai hoc, ban nen biet no la gi, nam o dau trong workflow van hanh va cach bien no thanh thuc hanh version control nho.

## 2. Muc tieu hoc tap

- Giai thich duoc Git bang ngon ngu cua ban.
- Nhan biet no xuat hien o dau trong DevOps workflow thuc te.
- Ap dung vao mot demo, command, config, pipeline hoac runbook nho.

## 3. Khai niem chinh

- Git luu lich su thay doi va giup review moi thay doi application, infra, pipeline.
- Branch va pull request tao noi de CI chay, nguoi review va policy duoc enforce.
- Commit tot can nho, ro y dinh va co kha nang rollback.

## 4. Vi du / Demo

```bash
git checkout -b infra/add-health-check
git diff
git commit -m "Add service health check"
```

## 5. Bai tap thuc hanh

- Viet 5 dong tom tat bai hoc khong nhin tai lieu.
- Tao vi du nho bang command, config, script, dashboard hoac runbook.
- Tim mot loi production co the lien quan va viet cach debug.

## 6. Loi thuong gap

- Hoc thuoc dinh nghia nhung khong tao vi du.
- Bo qua edge case vi demo nho van chay.
- Khong ghi lai cau hoi con mo de quay lai sau.

## 7. Checklist hoan thanh

- Toi co the giai thich **Git** trong 1-2 phut.
- Toi co mot vi du nho hoac ghi chu thuc hanh cho bai nay.
- Toi biet bai nay lien quan den delivery, operations, reliability, security hoac automation nao.
- Toi da ghi lai it nhat mot cau hoi can tim hieu sau neu con mo ho.

## 8. Outcome lien quan

Use Git and hosted repositories to review, trace, and safely ship application and infrastructure changes.

## 9. Tong ket

**Git** la mot moc trong lo trinh DevOps. Hay bien no thanh mot script, mot config, mot dashboard, mot pipeline, hoac mot runbook nho de kien thuc co cho bam.
