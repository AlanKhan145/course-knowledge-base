## 1. Tom tat

## 2. Muc tieu hoc tap

- Giai thich duoc AWS ECS / Fargate bang ngon ngu cua ban.
- Nhan biet no xuat hien o dau trong DevOps workflow thuc te.
- Ap dung vao mot demo, command, config, pipeline hoac runbook nho.

## 3. Khai niem chinh

- AWS ECS / Fargate giup chay container tren nhieu node voi scheduling, scaling va rollout.
- Can hieu service discovery, health check, resource limit, network va secret.
- Orchestration tang reliability nhung can observability va operational discipline.
