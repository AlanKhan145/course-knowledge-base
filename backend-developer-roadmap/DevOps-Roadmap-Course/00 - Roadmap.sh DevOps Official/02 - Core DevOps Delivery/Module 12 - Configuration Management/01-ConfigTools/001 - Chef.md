## 1. Tom tat

Bai nay giai thich **Chef** trong boi canh DevOps/SRE hien dai. Sau bai hoc, ban nen biet no la gi, nam o dau trong workflow van hanh va cach bien no thanh thuc hanh configuration management nho.

## 2. Muc tieu hoc tap

- Giai thich duoc Chef bang ngon ngu cua ban.
- Nhan biet no xuat hien o dau trong DevOps workflow thuc te.
- Ap dung vao mot demo, command, config, pipeline hoac runbook nho.

## 3. Khai niem chinh

- Chef giup may chu dat dung desired state mot cach lap lai.
- Can hieu idempotency, inventory, variable, template va handler/restart.
- Configuration management tot giam snowflake server va thao tac tay.

## 4. Vi du / Demo

```text
Input: mot thay doi nho trong he thong
Process: ap dung khai niem cua bai hoc vao script, config, pipeline hoac runbook
Output: ghi lai ket qua, loi gap phai va cach debug
```

## 5. Bai tap thuc hanh

- Tao mot file cau hinh hoac pseudo-plan cho Chef.
- Ghi ro IAM/permission, rollback, monitoring va cleanup.
- Review plan nhu mot pull request ha tang.

## 6. Loi thuong gap

- Hoc thuoc dinh nghia nhung khong tao vi du.
- Bo qua edge case vi demo nho van chay.
- Khong ghi lai cau hoi con mo de quay lai sau.

## 7. Checklist hoan thanh

- Toi co the giai thich **Chef** trong 1-2 phut.
- Toi co mot vi du nho hoac ghi chu thuc hanh cho bai nay.
- Toi biet bai nay lien quan den delivery, operations, reliability, security hoac automation nao.
- Toi da ghi lai it nhat mot cau hoi can tim hieu sau neu con mo ho.

## 8. Outcome lien quan

Automate server state and application configuration with idempotent, reviewable playbooks.

## 9. Tong ket

**Chef** la mot moc trong lo trinh DevOps. Hay bien no thanh mot script, mot config, mot dashboard, mot pipeline, hoac mot runbook nho de kien thuc co cho bam.
