# Module 15 - QoS - Quality of Service

## Mục tiêu module
Biết khi nào dùng QoS để ưu tiên traffic quan trọng và giảm nghẽn mạng.

## Thực hành trọng tâm
Xác định traffic cần ưu tiên trong văn phòng có voice/video call và backup dữ liệu.

## Output sau module
- QoS policy sketch and traffic prioritization matrix
- Lab note hoặc troubleshooting checklist có thể dùng lại
- Danh sách rủi ro, câu hỏi mở hoặc command/tool cần luyện thêm
