# Module 05 - Network Devices

## Mục tiêu module
Biết chức năng của router, switch, hub, modem và access point trong topology mạng.

## Thực hành trọng tâm
Vẽ topology có router, switch, modem, access point và giải thích đường đi của packet.

## Output sau module
- Network device topology diagram
- Lab note hoặc troubleshooting checklist có thể dùng lại
- Danh sách rủi ro, câu hỏi mở hoặc command/tool cần luyện thêm
