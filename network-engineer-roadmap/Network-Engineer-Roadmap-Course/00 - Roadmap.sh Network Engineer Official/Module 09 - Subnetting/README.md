# Module 09 - Subnetting

## Mục tiêu module
Biết subnet mask, CIDR, VLSM và supernetting để thiết kế địa chỉ mạng.

## Thực hành trọng tâm
Chia một network thành nhiều subnet theo nhu cầu host khác nhau bằng CIDR/VLSM.

## Output sau module
- Subnetting workbook with CIDR/VLSM exercises
- Lab note hoặc troubleshooting checklist có thể dùng lại
- Danh sách rủi ro, câu hỏi mở hoặc command/tool cần luyện thêm
