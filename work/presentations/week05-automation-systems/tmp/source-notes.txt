Content facts used
- Automation workflow: sense -> decide -> act -> observe.
- Open-loop control does not measure the result; Task 1 uses a fixed 2 second LED cycle on GPIO 13.
- Task 2 reads a potentiometer on GPIO 34, compares against ADC threshold 2048, drives an LED on GPIO 13, and waits 500 ms.
- Task 3 reads an LDR on GPIO 34, treats Wokwi readings above 1500 as dark, and turns the LED on GPIO 13 on in dark conditions.
- Task 4 uses hysteresis: LED ON at readings >= 2000, LED OFF at readings <= 1200, and holds the previous state between thresholds.
- Captured examples from the Markdown: Task 2 reading 1397 -> OFF; Task 3 reading 680 -> BRIGHT / LIGHT OFF; Task 4 reading 200 -> BRIGHT / LED OFF.
- PID is presented conceptually as proportional, integral, and derivative response to error; no tuning claims are made.
- The Markdown classifies Task 2 as sensor-driven threshold control, and Tasks 3-4 as closed-loop only when the sensor measures the controlled environment.
