# Module 05 - Star Blaster

Dự án game bắn phi thuyền - 30 bài, 4 giờ.

## Mục tiêu

- Xây game bắn phi thuyền có player movement, shooting, enemy wave, damage, score, UI và build.
- Làm quen collection, loop và coroutine trong một dự án có nhịp gameplay nhanh.
- Thêm polish bằng background scrolling, explosion, screen shake, sound và music.

## Kiến thức chính

- Array và loop `for`, `foreach`, `while`.
- Enemy pathfinding theo waypoint.
- Coroutine để sinh enemy theo wave.
- Health/damage system.
- Projectile và shooting cho player/enemy.
- Background scrolling, particle, screen shake và audio.
- ScoreKeeper, LevelManager, Singleton và build.

## Bài tập thực hành

- Thêm enemy loại nhanh nhưng ít máu.
- Thêm boss wave cuối màn.
- Thêm power-up bắn đôi trong 8 giây.
- Tạo màn hình game over hiển thị điểm.

## Điều kiện hoàn thành

- Player không ra ngoài viewport.
- Enemy wave sinh đúng thứ tự và kết thúc đúng.
- Bullet của player/enemy không gây nhầm tag/layer.
- Score cập nhật đúng và UI rõ ràng.
- Build chạy được ngoài Unity Editor.
