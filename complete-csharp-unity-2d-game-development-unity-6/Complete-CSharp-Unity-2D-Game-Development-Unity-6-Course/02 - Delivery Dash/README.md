- Dùng collision, trigger, tag, prefab, camera follow và UI.

## Kiến thức chính

- `Transform.Translate()` để di chuyển object.
- `Time.deltaTime` để chuyển động không phụ thuộc frame rate.
- `[SerializeField]` để chỉnh dữ liệu private từ Inspector.
- `OnCollisionEnter2D()` cho va chạm vật lý.
- `OnTriggerEnter2D()` cho vùng trigger.
- Tag để phân biệt pickup, delivery, boost và obstacle.
- Prefab để tái sử dụng object.
- `GetComponent()` để lấy component khác trên object.

## Bài tập thực hành

- Thêm giới hạn thời gian giao hàng.
- Tạo ít nhất 3 điểm giao khác nhau.
- Thêm UI hiển thị trạng thái `Đang có hàng` hoặc `Chưa có hàng`.
- Thêm hiệu ứng đổi màu xe khi nhặt hàng.

## Điều kiện hoàn thành

- Xe chạy mượt ở các frame rate khác nhau.
- Collision block không làm game bị kẹt vô lý.
- Người chơi có thể nhặt và giao hàng từ đầu đến cuối.
- UI cập nhật đúng theo trạng thái game.
