# Practice Checklist

## Setup

- [ ] Cài Unity Hub.
- [ ] Cài đúng Unity 6 Editor.
- [ ] Cài IDE hoặc code editor.
- [ ] Tạo project 2D đầu tiên.
- [ ] Chạy script C# đầu tiên trong Unity.

## C# căn bản trong Unity

- [ ] Viết method và gọi method từ `Update()`.
- [ ] Dùng biến để chỉnh tốc độ hoặc trạng thái.
- [ ] Dùng `[SerializeField]` để chỉnh giá trị trong Inspector.
- [ ] Dùng `if` để xử lý input hoặc trạng thái.
- [ ] Dùng boolean để khóa/mở một hành vi gameplay.
- [ ] Dùng array và loop trong hệ thống wave/enemy.
- [ ] Dùng coroutine để xử lý delay hoặc spawn lặp.

## Physics 2D

- [ ] Thêm `Rigidbody2D` và `Collider2D`.
- [ ] Xử lý `OnCollisionEnter2D()`.
- [ ] Xử lý `OnTriggerEnter2D()`.
- [ ] Xử lý `OnCollisionExit()`.
- [ ] Dùng Edge Collider với Sprite Shape.
- [ ] Dùng Surface Effector 2D.
- [ ] Dùng Physics Material 2D.
- [ ] Kiểm tra va chạm bằng LayerMask hoặc `IsTouchingLayers`.

## Camera và hình ảnh

- [ ] Dùng Cinemachine Follow Camera.
- [ ] Dùng Cinemachine Confiner.
- [ ] Dùng State-Driven Camera.
- [ ] Cắt sprite sheet.
- [ ] Tạo Tilemap.
- [ ] Dùng Rule Tile.
- [ ] Thiết lập Sorting Layer.
- [ ] Tạo animation idle/run/jump/climb/die.
