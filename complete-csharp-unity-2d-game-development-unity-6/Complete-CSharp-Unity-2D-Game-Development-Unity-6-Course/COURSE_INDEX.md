# Course Index

## Complete C# Unity 2D Game Development - Updated To Unity 6

Khóa học này phù hợp nếu bạn muốn học Unity 2D bằng cách xây game thật, bắt đầu từ thao tác Unity cơ bản, rồi tăng dần độ phức tạp qua bốn dự án: game lái xe giao hàng, game trượt tuyết, platformer 2D và game bắn phi thuyền.

## Mục tiêu đầu ra

Sau khóa học, bạn nên có thể:

- Tạo project Unity 6 và tổ chức scene, asset, prefab, script.
- Viết C# gameplay script với method, biến, điều kiện, loop, array, coroutine và component.
- Làm việc với Rigidbody2D, Collider2D, Trigger, Surface Effector 2D và Physics Material 2D.
- Dùng Input System, Cinemachine, Sprite Shape, Tilemap, Animator và Particle System.
- Tạo UI bằng TextMeshPro, button, layout group, anchor và pivot.
- Xây các hệ thống game cơ bản: movement, collision, pickup, damage, shooting, enemy spawning, score, lives, scene loading và persistence.
- Hoàn thiện và build một game 2D đơn giản.

## Đường học khuyến nghị

1. Học module 01 thật chậm để quen Unity Editor và C# script lifecycle.
2. Với mỗi game, xem bài một lần, làm theo một lần, rồi tự thêm một tính năng nhỏ.
3. Ghi lại lỗi Unity Console thường gặp vào cuối mỗi module.
4. Sau module 04, tạo một mini level riêng để kiểm tra bạn đã hiểu Tilemap, camera và scene persistence.
5. Sau module 05, chọn một game để polish thành portfolio demo.
