## Bài tập thực hành

- Tạo project Unity 2D tên `Unity2D-Lab`.
- Tạo một GameObject tên `Player`.
- Gắn script `PlayerLogger.cs` và in một dòng log trong `Start()`.
- Thử đổi tên object, bật/tắt component và quan sát Console.

## Ghi chú cần nhớ

- Unity vận hành bằng GameObject và Component.
- Script C# cũng là một Component khi gắn vào GameObject.
- Console là nơi đầu tiên cần nhìn khi game không chạy đúng.
