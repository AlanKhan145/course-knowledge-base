## Cách học

1. Mở `COURSE_INDEX.md` để xem toàn bộ khóa.
2. Học theo thứ tự module để đi từ C# cơ bản đến build game hoàn chỉnh.
3. Sau mỗi module, làm phần `Bài tập thực hành` trước khi chuyển game tiếp theo.
4. Dùng `LEARNING_PLAN_8_WEEKS.md` nếu muốn học đều trong 8 tuần.
5. Dùng `PRACTICE_CHECKLIST.md` để theo dõi tiến độ và ôn lại kỹ năng.
