## What You Will Learn

- Tell the difference between prompt engineering and vibe coding, and when to use each
- Write structured, reusable prompts for UX/UI work using a role/context/task/format framework
- Use AI as a design partner for research, personas, copywriting, and layout ideation
- Use Figma's native AI features (Make, Slides, Buzz) alongside manual prototyping and animation
- Build a Figma design system with color, text, spacing, and boolean variables
- Turn ideas into working prototypes and MVPs with Lovable, Cursor, Windsurf, and v0
- Import Figma designs into v0, keep generated UI on-brand, and add simple app logic
- Test, deploy, and wire a real database (Vercel + Supabase) into a generated app
- Apply responsible AI practices: copyright, bias, privacy, and human oversight
- Use advanced prompting tactics (few-shot, ReAct, Self-Ask, prompt layering) and build a personal prompt portfolio
