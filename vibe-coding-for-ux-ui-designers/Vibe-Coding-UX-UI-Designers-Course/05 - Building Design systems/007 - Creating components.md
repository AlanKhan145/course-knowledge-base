# 007 - Creating components

## Section

Building Design systems

## Duration

4:37

## Main Idea

Walks through turning finished elements (buttons, cards, inputs) into reusable Figma components with properties, so they can be reused and updated everywhere from one source. By the end of the lesson, learners should see how Creating components connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* Component creation
* Component properties
* Reuse and single-source updates
