# 003 - Modes in variables

## Section

## Main Idea

Covers Figma variable modes for supporting multiple themes (e.g., light/dark) from the same set of components without duplicating them. By the end of the lesson, learners should see how Modes in variables connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* Variable modes
* Light/dark theming
* Avoiding duplicate components
