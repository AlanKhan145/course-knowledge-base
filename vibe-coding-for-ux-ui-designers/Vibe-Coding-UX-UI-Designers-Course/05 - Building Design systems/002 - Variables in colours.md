# 002 - Variables in colours

## Section

Building Design systems

## Duration

5:57

## Main Idea

Shows how to set up Figma color variables (semantic tokens like primary/background/text) instead of hardcoded hex values, so themes can be changed in one place. By the end of the lesson, learners should see how Variables in colours connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* Color variables
* Semantic color tokens
* Single source of truth for color
