# 001 - What is a Design System?

## Section

Building Design systems

## Duration

3:46

## Main Idea

Defines a design system as the shared set of variables, components, and rules that keep a product visually and behaviorally consistent, and why AI tools work better once one exists to constrain their output. By the end of the lesson, learners should see how What is a Design System connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* Design system definition
* Consistency at scale
* Constraining AI output with a system

## Review Questions

## Summary

Defines a design system as the shared set of variables, components, and rules that keep a product visually and behaviorally consistent, and why AI tools work better once one exists to constrain their output. This lesson is one building block toward the section's goal: Teaches how to build a Figma design system with variables, modes, and components so that both humans and AI tools generate consistent, on-brand output.
