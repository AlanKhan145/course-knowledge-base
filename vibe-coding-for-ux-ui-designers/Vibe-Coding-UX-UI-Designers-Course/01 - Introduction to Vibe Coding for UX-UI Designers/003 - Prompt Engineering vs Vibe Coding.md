# 003 - Prompt Engineering vs Vibe Coding

## Section

Introduction to Vibe Coding for UX/UI Designers

## Duration

4:44

## Main Idea

Distinguishes prompt engineering (crafting precise, reusable instructions to get a specific output from a model) from vibe coding (an iterative, conversational way of building software or design artifacts by describing intent and refining results with AI). By the end of the lesson, learners should see how Prompt Engineering vs Vibe Coding connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* Prompt engineering definition
* Vibe coding definition
* Precision vs. iteration
* When to use each approach
