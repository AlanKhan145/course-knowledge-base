# 010 - Importing Designs from Figma & Iteration of Prototype

## Section

Using V0

## Main Idea

Covers bringing a Figma design into v0 as a reference/import so the generated code matches an existing visual design, then iterating on the result with prompts. By the end of the lesson, learners should see how Importing Designs from Figma & Iteration of Prototype connects to designing and shipping AI-assisted UX/UI work without traditional coding.

* Matching an existing design
* Iterative refinement
