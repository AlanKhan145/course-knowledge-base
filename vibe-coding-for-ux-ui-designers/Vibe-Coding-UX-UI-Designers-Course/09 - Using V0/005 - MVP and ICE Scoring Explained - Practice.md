# 005 - MVP and ICE Scoring Explained

## Section

Using V0

## Duration

## Main Idea

Introduces the ICE framework (Impact, Confidence, Ease) for prioritizing which features belong in a first MVP prototype versus a later iteration. By the end of the lesson, learners should see how MVP and ICE Scoring Explained connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* ICE framework
* Impact/Confidence/Ease scoring
* MVP feature prioritization
