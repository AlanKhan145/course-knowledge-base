# 005 - Understanding Prototyping in Figma

## Section

Figma Project: Prototyping and animation

## Duration

## Main Idea

Explains Figma's prototyping model -- frames, connections, triggers (click, hover, drag), and actions (navigate, overlay, scroll) -- as the foundation for building an interactive flow. By the end of the lesson, learners should see how Understanding Prototyping in Figma connects to designing and shipping AI-assisted UX/UI work without traditional coding.
