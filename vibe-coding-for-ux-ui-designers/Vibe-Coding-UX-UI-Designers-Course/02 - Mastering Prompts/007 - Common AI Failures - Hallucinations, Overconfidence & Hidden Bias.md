## Main Idea

Surveys the main failure modes of generative AI -- hallucinated facts or components, overconfident wrong answers, and bias inherited from training data -- and how designers should sanity-check AI output before shipping it. By the end of the lesson, learners should see how Common AI Failures - Hallucinations, Overconfidence & Hidden Bias connects to designing and shipping AI-assisted UX/UI work without traditional coding.
