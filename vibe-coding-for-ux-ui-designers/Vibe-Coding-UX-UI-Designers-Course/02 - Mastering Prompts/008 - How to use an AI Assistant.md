# 008 - How to use an AI Assistant?

## Section

Mastering Prompts

## Duration

6:13

## Main Idea

A hands-on walkthrough of working with a general-purpose AI assistant (e.g., a ChatGPT/Claude-style chat) as a daily design collaborator -- starting conversations, giving feedback, and iterating toward a usable result. By the end of the lesson, learners should see how How to use an AI Assistant connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* Starting a session
* Giving iterative feedback
* Conversational refinement
* Assistant as daily collaborator
