# 003 - Model Behavior Control Parameters

## Section

Mastering Prompts

## Duration

6:40

## Main Idea

Covers the generation settings that shape a model's output -- temperature, top-p/top-k sampling, max tokens, and system vs. user messages -- and how tweaking them changes creativity vs. consistency in AI-generated designs and copy. By the end of the lesson, learners should see how Model Behavior Control Parameters connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* Temperature
* Top-p / top-k
* Max tokens
* System vs. user prompts
* Creativity vs. determinism
