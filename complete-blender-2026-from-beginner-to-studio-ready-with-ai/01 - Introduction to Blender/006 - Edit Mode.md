# 006 — Edit Mode

| Thuộc tính | Nội dung |
|---|---|
| Phần | 01 — Introduction to Blender |
| Thời lượng | 6:11 |
| Chủ đề | Vertex, edge, face và chỉnh sửa mesh |

## Mục tiêu

Phân biệt Object Mode/Edit Mode, chọn vertex/edge/face và chỉnh mesh mà không tạo object mới.

## Thực hành

Vào Edit Mode trên cube, extrude một mặt, bevel một cạnh và kiểm tra kết quả trong wireframe.

## Lưu ý

Nếu chỉ muốn thay đổi hình học, làm việc trong Edit Mode giúp giữ origin và object identity ổn định hơn.

## Checklist

- [ ] Chuyển được vertex/edge/face select.
- [ ] Extrude và bevel được vùng chọn.
- [ ] Trở lại Object Mode không làm mất mesh.
