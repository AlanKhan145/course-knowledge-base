**9 bài • 1 giờ 34 phút**

## Mục tiêu

- Đưa một AI-generated 3D model vào pipeline sản xuất.
- Retopology, UV unwrap, bake maps và chuẩn bị character.
- Dùng Mixamo, đổi tên Action và tổ chức animation.
- Assemble shot, thêm lighting/fog, blend animation bằng NLA và render Cycles.

## Pipeline

```text
AI model → Retopology → UV → Bake maps → Rig/Mixamo → Actions → NLA
→ Scene assembly → Lighting/Fog → Cycles render
```
