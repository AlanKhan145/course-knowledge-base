| Thuộc tính | Nội dung |

| Chủ đề | Mixamo rig, import animation và Action |

## Mục tiêu

Đưa character qua Mixamo hoặc workflow tương đương, import clip và kiểm tra deformation.

## Thực hành

Upload/auto-rig → chọn clip → download FBX → import Blender → kiểm tra armature, scale, frame rate và Action.

## Checklist

- [ ] Character giữ đúng hướng và scale.
- [ ] Action được đổi tên có hệ thống.
- [ ] Kiểm tra tay/chân/đuôi/vây sau import.
- [ ] Giữ file gốc trước khi retarget hoặc chỉnh sửa.
