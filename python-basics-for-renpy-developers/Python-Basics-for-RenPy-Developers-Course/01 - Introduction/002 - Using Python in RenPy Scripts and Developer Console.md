## Nội dung bài học

Phân biệt cú pháp Ren'Py với cú pháp Python, viết Python một dòng trong script, viết khối Python nhiều dòng, khai báo/thay đổi biến và kiểm tra giá trị trong Developer Console.

## Ghi chú script

```renpy
$ affection = 5
```

```renpy
python:
    affection = 5
    player_name = "Khanh"
    has_key = False
```

```renpy
init python:
    # Hàm và class dùng chung có thể đặt ở đây.
    pass
```

## Việc cần làm

- [ ] Thử Python một dòng bằng `$`.
- [ ] Thử khối `python:`.
- [ ] Thử `init python:`.
- [ ] Mở Developer Console để kiểm tra biến.
