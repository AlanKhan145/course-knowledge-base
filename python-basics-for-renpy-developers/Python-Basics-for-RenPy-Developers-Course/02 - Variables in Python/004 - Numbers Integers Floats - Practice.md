# 004 - Numbers: Integers, Floats

## Module

Module 02 - Variables in Python

## Thời lượng

3 phút 36 giây

## Nội dung bài học

Phân biệt `int` và `float`, khai báo biến số, cộng/trừ/nhân/chia, tăng/giảm giá trị biến, so sánh số và dùng số để biểu diễn điểm hoặc tài nguyên trong game.

## Ví dụ Ren'Py

```renpy
default lucian_affection = 0
default money = 100
default energy = 75.5

menu:
    "Khen Lucian":
        $ lucian_affection += 2

    "Phớt lờ anh ấy":
        $ lucian_affection -= 1
```

## Ứng dụng

- Điểm hảo cảm.
- Tiền hoặc vật phẩm.
- Chỉ số tinh thần.
- Số ngày còn lại.
- Điểm minigame.
- Số lần đã gặp nhân vật.
