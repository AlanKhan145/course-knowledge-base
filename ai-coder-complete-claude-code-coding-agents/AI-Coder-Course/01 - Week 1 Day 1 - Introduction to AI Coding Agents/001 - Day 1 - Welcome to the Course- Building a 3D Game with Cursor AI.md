## Lesson Overview

This opening lesson gives students a direct and exciting introduction to AI coding agents by building something immediately with Cursor AI.

Instead of starting with theory, objectives, curriculum, or logistics, the instructor begins with **instant gratification**: opening Cursor, creating a project, and asking an AI coding agent to build a simple 3D first-person shooter game website.

The goal is not to build a perfect commercial product yet. The goal is to let students experience how quickly an AI coding agent can generate real code from a creative prompt.

---

## Course Introduction

The instructor introduces the course as a definitive AI Coder course and describes it as **“The Missing Manual”** for becoming skilled in agentic engineering.

Over the next three weeks, students will work with multiple AI coding tools and learn how to use AI agents to generate, improve, and manage code.

The instructor warns that the course will move quickly and feel like a “roller coaster” because there will be many powerful tools, workflows, and demonstrations to explore.

## Main Concept

### AI Coding Agent

An AI coding agent is an AI assistant that can help write, edit, organize, and sometimes execute code inside a development environment.

In Cursor, the agent lives inside the editor interface and can interact with the project files. Instead of only answering questions, it can help create actual code files for the project.

In this lesson, the agent is used to generate a simple game website from a natural language prompt.

Cursor is introduced as the first AI coding tool used in the course.

The instructor describes Cursor as:

* Popular
* Easy to use
* Based on VS Code

Students who have already used Cursor or used up their free trial do not need to follow along exactly. They can watch the demo or use another AI coding product.

## Installing Cursor

### Step 1: Go to Cursor Website

Open a browser and go to:

```text
cursor.com
```

### Step 2: Download Cursor

Cursor should automatically show the correct download option for your operating system.

Supported platforms include:

* macOS
* Windows
* Linux

For example:

* On a Mac, download the Mac version.
* On Windows, download the Windows installer.
* On Linux, choose the Linux version.

### Step 3: Install Cursor

#### On macOS

Download the file and drag Cursor into the Applications folder.

#### On Windows

Open the downloaded installer, accept the agreement, keep the default options, and continue through the installation steps.

One important option is:

```text
Add to PATH
```

This should be selected during installation.

## Creating a New Project

After opening Cursor, the next step is to create a project folder.

In Cursor, “Open Project” means selecting a folder on your computer. This folder will contain all files related to the project.

### Suggested Folder Structure

A common structure is:

```text
Home Folder
└── Projects
    └── Instant
```

The project folder in this lesson is called:

```text
Instant
```

### On macOS

1. Click **Open Project**
2. Go to your home folder
3. Open or create a folder called `Projects`
4. Create a new folder called `Instant`
5. Select the `Instant` folder
6. Click **Open**

### On Windows

1. Click **Open Project**
2. Go to your home folder
3. Open or create a folder called `Projects`
4. Create a new folder called `Instant`
5. Enter the `Instant` folder
6. Click **Select Folder**

When the project is opened correctly, Cursor should show the project name `Instant` in the top-left area.

## Project Goal

For the first demo, the instructor does not focus on business impact.

## Prompt Used in Cursor

The instructor sends the following request to the Cursor AI agent:

```text
Please build a website for a 3D first-person shooter game in an arena against one computer opponent controlled by arrow keys and space bar to shoot.
```

This prompt is simple but specific enough for the AI agent to begin creating a working project.

---

## What Happens After Sending the Prompt

After the prompt is submitted, Cursor begins working on the project.

The agent may:

* Plan the next steps
* Explore the project folder
* Create files
* Write code
* Modify files
* Ask for permission depending on settings

In the demo, Cursor begins writing a file called:

```text
index.html
```

This shows that the agent is not only chatting. It is actually generating code inside the project.

---

## Important Note About AI Coding Results

The instructor explains that each student may get a slightly different result.

This is an important idea in AI coding:

> AI-generated outputs are not always perfectly predictable.

Different users may see different behavior depending on:

* Cursor settings
* Selected model
* Subscription plan
* Model availability
* Operating system
* Prompt interpretation
* Permission settings

This uncertainty is part of working with AI coding agents. Students will learn how to handle it throughout the course.

---

## Key Concepts

### 1. Instant Gratification Learning

Instead of spending the first lesson on theory, the course begins with a practical result. This helps students feel the power of AI coding immediately.

### 2. Project-Based Learning

Students create a real project folder and watch the AI agent generate real files. This makes the learning experience concrete.

### 3. AI as a Coding Sidekick

The AI agent is treated like a coding partner. The user gives it a task, and the agent helps create the project.

### 4. Natural Language to Code

The user does not need to write code manually at the beginning. A natural language request is enough for the AI to start building.

### 5. Uncertainty in AI Outputs

AI coding agents may produce different results for different users. Learning how to inspect, guide, and improve the result is part of agentic engineering.

## Common Issues

### Cursor Does Not Show the Same Screen

Use:

```text
File → New Window
```

Then open the project again.

### Sign In Button Appears

Click **Sign In** and log in or create an account.

### The Agent Asks for Permission

Read the action carefully. If it is creating or editing files inside your project and you are comfortable with it, approve the action.

### The Output Looks Different from the Demo

This is normal. AI agents can produce different results. Focus on understanding the workflow rather than matching the instructor’s result exactly.
