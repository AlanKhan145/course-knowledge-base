# Method Overview

| Nhóm | Thành phần |
| --- | --- |
| Core gameplay | Challenge, camera, controls, feedback và juiciness |
| Engagement gameplay | Rewards, renewal, difficulty và progression |
| Support features | Game mode, game structure, GUI và narrative |
| Công cụ đánh giá | Checklist kiểm tra tính đầy đủ và nhất quán của game system |
| Sản phẩm cuối | Bản thiết kế game system có thể áp dụng cho dự án indie |

## Nguyên tắc sử dụng

- Bắt đầu từ hành động và thử thách chính của người chơi.
- Chỉ thêm progression/reward khi nó củng cố core gameplay.
- GUI, narrative và mode phải hỗ trợ trải nghiệm, không kéo game sang hướng khác.
- Mỗi quyết định thiết kế nên có giả định và cách kiểm chứng bằng prototype/playtest.
