# Module 02 - Understand How to Build a Core Gameplay

Cách xây dựng gameplay cốt lõi - 6 bài, khoảng 55 phút.

## Mục tiêu

Module này phân tích các thành phần tạo nên core gameplay: challenge, camera, controls, feedback, juiciness và cách xử lý game có nhiều core gameplays.

## Kiến thức chính

- Challenge và mastery
- Camera
- Controls
- Feedback
- Game feel và juiciness
- Nhiều gameplay cốt lõi trong cùng một game

## Sản phẩm thực hành

Bộ quyết định thiết kế cho core gameplay.

## Bài tập thực hành

- Áp dụng bài học vào một ý tưởng game cụ thể
- Ghi lại quyết định thiết kế trong Decision Log
- Tìm một rủi ro hoặc giả định cần playtest
- Cập nhật checklist game system sau bài học

## Điều kiện hoàn thành

- Có ít nhất một quyết định thiết kế được ghi lại.
- Có rủi ro hoặc giả định cần prototype/playtest.
- Thiết kế mới không mâu thuẫn với các lớp game system đã xác định.
- Checklist module được cập nhật trước khi chuyển module tiếp theo.
