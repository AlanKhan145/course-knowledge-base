# Course Index

## Indie Game Design: Build Your Game's Core System

Khóa học này tập trung vào **tư duy và phương pháp game design**, không dạy lập trình hoặc một game engine cụ thể. Sản phẩm cuối là một bản thiết kế game system có thể dùng làm nền trước khi prototype hoặc production.

## Mục tiêu đầu ra

Sau khóa học, bạn nên có thể:

- Xác định gameplay cốt lõi của một trò chơi.
- Thiết kế thử thách, camera, điều khiển và feedback.
- Tạo hệ thống phần thưởng và tiến triển.
- Xây dựng đường cong độ khó hợp lý.
- Thiết kế core loop và nhịp độ gameplay.
- Chọn game mode và cấu trúc game phù hợp.
- Xác định vai trò của GUI và narrative.
- Dùng checklist để đánh giá tính nhất quán của game system.
