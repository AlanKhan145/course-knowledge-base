# Module 03 - Workshop - Define Your Game System, Part 1

Thực hành xác định game system - Phần 1 - 1 bài, 13 phút.

## Mục tiêu

Module workshop này giúp học viên mô tả core gameplay của dự án và kiểm tra các quyết định thiết kế bằng checklist.

## Bài học

- [ ] [001 - Define Your Core Gameplay](<001 - Define Your Core Gameplay.md>) - `13:02`

## Kiến thức chính

- Thử thách chính
- Hành động của người chơi
- Camera
- Hệ thống điều khiển
- Feedback
- Game feel

## Sản phẩm thực hành

Phần Core Gameplay trong tài liệu game system.

## Bài tập thực hành

- Áp dụng bài học vào một ý tưởng game cụ thể
- Ghi lại quyết định thiết kế trong Decision Log
- Tìm một rủi ro hoặc giả định cần playtest
- Cập nhật checklist game system sau bài học

## Điều kiện hoàn thành

- Có ít nhất một quyết định thiết kế được ghi lại.
- Có rủi ro hoặc giả định cần prototype/playtest.
- Thiết kế mới không mâu thuẫn với các lớp game system đã xác định.
- Checklist module được cập nhật trước khi chuyển module tiếp theo.
