# Practice Checklist

## Core Gameplay

- [ ] Xác định challenge chính.
- [ ] Mô tả hành động chính của người chơi.
- [ ] Chọn camera phù hợp.
- [ ] Thiết kế controls rõ ràng.
- [ ] Xác định feedback cho hành động chính.
- [ ] Thêm yếu tố juiciness có mục đích.
- [ ] Kiểm tra nhiều core gameplays có mâu thuẫn không.

## Engagement Gameplay

- [ ] Phân biệt core gameplay và engagement gameplay.
- [ ] Thiết kế reward ngắn hạn.
- [ ] Thiết kế reward dài hạn.
- [ ] Gắn reward với player motivation.
- [ ] Có cơ chế renewal.
- [ ] Có difficulty curve.
- [ ] Có progression system.
- [ ] Mô tả core loop.
- [ ] Mô tả meta loop.
- [ ] Kiểm tra pacing.

## Support Features

- [ ] Chọn game mode phù hợp.
- [ ] Chọn game structure phù hợp.
- [ ] GUI phục vụ hành động của người chơi.
- [ ] Có narrative pitch.
- [ ] Chọn phương pháp storytelling.
- [ ] Support features không làm lệch core gameplay.

## Review cuối

- [ ] Game system có đủ 3 lớp.
- [ ] Không có quyết định thiết kế mâu thuẫn rõ ràng.
- [ ] Mỗi giả định quan trọng có cách prototype/playtest.
- [ ] Có danh sách rủi ro thiết kế.
- [ ] Có kế hoạch prototype đầu tiên.
