# Module 07 - Workshop - Define Your Game System, Part 3

Thực hành xác định game system - Phần 3 - 1 bài, 8 phút.

## Mục tiêu

Module workshop này hoàn thiện game system bằng game mode, structure, GUI và narrative, rồi rà soát tính đầy đủ và nhất quán.

## Bài học

- [ ] [001 - Define Your Support Features](<001 - Define Your Support Features.md>) - `07:33`

## Kiến thức chính

- Core gameplay
- Engagement gameplay
- Support features
- Checklist kiểm tra mâu thuẫn
- Checklist kiểm tra giá trị thiết kế

## Sản phẩm thực hành

Bản thiết kế game system hoàn chỉnh gồm ba lớp.

## Bài tập thực hành

- Áp dụng bài học vào một ý tưởng game cụ thể
- Ghi lại quyết định thiết kế trong Decision Log
- Tìm một rủi ro hoặc giả định cần playtest
- Cập nhật checklist game system sau bài học

## Điều kiện hoàn thành

- Có ít nhất một quyết định thiết kế được ghi lại.
- Có rủi ro hoặc giả định cần prototype/playtest.
- Thiết kế mới không mâu thuẫn với các lớp game system đã xác định.
- Checklist module được cập nhật trước khi chuyển module tiếp theo.
