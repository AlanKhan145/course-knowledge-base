## Cách học

1. Mở [COURSE_INDEX.md](Godot-4-Build-Launch-Full-2D-Roguelike-Game-Course/COURSE_INDEX.md) để xem toàn bộ khóa.
2. Học theo thứ tự module vì kiến trúc ability, combat, UI và AI phụ thuộc nhau.
3. Với mỗi bài, mở file lesson tương ứng và ghi lại node/scene/script/signal đã thay đổi.
4. Dùng [LEARNING_PLAN_10_WEEKS.md](Godot-4-Build-Launch-Full-2D-Roguelike-Game-Course/LEARNING_PLAN_10_WEEKS.md) nếu muốn học đều trong 10 tuần.
