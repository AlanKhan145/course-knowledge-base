# 005 - Better tweens

## Module

## Thời lượng

## Nội dung bài học

Thực hành nội dung Better tweens trong module Floating Damage Text.

## Vai trò của bài học

Bài này thuộc game **Unknown Adventure**. Dùng bài này như ghi chú học kèm video: nắm ý chính, thực hành ngay trong Godot, rồi ghi lại lỗi, node/scene/script đã chỉnh hoặc quyết định kiến trúc quan trọng.

## Mục tiêu sau bài học

- Hiểu bài **Better tweens** đang đóng góp gì cho hệ thống game trong module này.
- Thực hiện được thao tác Godot hoặc đoạn GDScript chính theo video.
- Chạy thử scene và xác nhận hành vi mới hoạt động đúng.
- Ghi lại ít nhất một ghi chú cá nhân: lỗi gặp phải, node đã thêm, signal đã nối, hoặc điều cần ôn lại.

## Kiến thức nền của module

- Autoload
- Display damage text
- Find spawn position for text
- Tweens
- Better tweens
- Custom font
- Round the text
