# Module 07 - Network

**Hoc phan:** 04 - Network, Async and Services

## Ket qua dau ra

Call REST and GraphQL APIs, configure HTTP clients and handle loading, errors and caching.

## Project

Mini project: News App with Retrofit, OkHttp, Room cache, pull to refresh and offline error handling.
