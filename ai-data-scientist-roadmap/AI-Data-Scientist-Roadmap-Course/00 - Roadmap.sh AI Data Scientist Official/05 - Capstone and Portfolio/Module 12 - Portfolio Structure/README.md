# Module 12 - Portfolio Structure

**Course:** 05 - Capstone and Portfolio

This module has 17 lessons from the AI & Data Scientist roadmap.

## Outcome

Organize projects so reviewers can run, inspect and trust your work.

## Project

Create a portfolio repository with consistent folder structure and README files.

## Content Groups

- Project Structure (Lessons 001-006)
- Portfolio Folders (Lessons 007-013)
- Career Fit (Lessons 014-017)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
