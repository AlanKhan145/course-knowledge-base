# Module 11 - Completion Checklist

**Course:** 05 - Capstone and Portfolio

This module has 26 lessons from the AI & Data Scientist roadmap.

## Outcome

Use a final checklist to verify readiness across foundations, coding, analysis, ML, DL and MLOps.

## Project

Final readiness checklist before publishing portfolio.

## Content Groups

- Foundation (Lessons 001-005)
- Coding (Lessons 006-009)
- Data Analysis (Lessons 010-013)
- Machine Learning (Lessons 014-018)
- Deep Learning (Lessons 019-022)
- MLOps (Lessons 023-026)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
