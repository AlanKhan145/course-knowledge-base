# Module 09 - Capstone Projects

**Course:** 05 - Capstone and Portfolio

This module has 12 lessons from the AI & Data Scientist roadmap.

## Outcome

Build one end-to-end portfolio project that connects analysis, modeling, evaluation and deployment.

## Project

Capstone: End-to-End AI/Data Science Portfolio Project.

## Content Groups

- Capstone Options (Lessons 001-004)
- Customer Churn Outputs (Lessons 005-011)
- Project Pipeline (Lesson 012)

## Lessons

- [001 - Customer Churn Prediction](001 - Customer Churn Prediction.md) - a capstone option predicting which customers are likely to leave
- [002 - Sales Forecasting](002 - Sales Forecasting.md) - a capstone option predicting future sales from historical data
- [003 - Image Classification Capstone](003 - Image Classification Capstone.md) - a capstone option classifying images with a trained model
- [004 - A/B Testing Analysis](004 - A - B Testing Analysis.md) - a capstone option analyzing an experiment and recommending a rollout decision
- [005 - Notebook EDA](005 - Notebook EDA.md) - the exploratory analysis notebook for the chosen capstone project
- [006 - Notebook Training](006 - Notebook Training.md) - the notebook that trains and validates the capstone project's model
- [007 - Model File](007 - Model File.md) - the serialized, trained model artifact produced by the project
- [008 - FastAPI App](008 - FastAPI App.md) - the API layer that serves the capstone project's model
- [009 - Dockerfile](009 - Dockerfile.md) - the container definition packaging the capstone project's API
- [010 - README](010 - README.md) - the top-level documentation explaining and running the capstone project
- [011 - Insight Report](011 - Insight Report.md) - a written summary of findings, metrics, and recommendations
- [012 - Raw Data -> EDA -> Feature Engineering -> ML Model -> Evaluation -> FastAPI Deployment -> Docker + README](012 - Raw Data - EDA - Feature Engineering - ML Model - Evaluation - FastAPI Deployment - Docker + README.md) - the full end-to-end pipeline tying every capstone step together

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
