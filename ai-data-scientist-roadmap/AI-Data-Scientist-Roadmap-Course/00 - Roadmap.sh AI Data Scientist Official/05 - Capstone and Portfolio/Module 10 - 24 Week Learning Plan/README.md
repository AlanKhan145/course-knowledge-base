# Module 10 - 24 Week Learning Plan

**Course:** 05 - Capstone and Portfolio

This module has 9 lessons from the AI & Data Scientist roadmap.

## Outcome

Follow a 24 week roadmap from math foundations to a deployable portfolio project.

## Project

Weekly tracker with milestones and deliverables.

## Content Groups

- Weekly Plan (Lessons 001-009)

## Lessons

- [001 - Week 1-3: Math](001 - Week 1-3 Math.md) - building the linear algebra and calculus foundation
- [002 - Week 4-6: Probability, Hypothesis Testing, A/B Testing](002 - Week 4-6 Probability, Hypothesis Testing, A - B Testing.md) - core statistical inference and experimentation skills
- [003 - Week 7-8: Regression and Time Series](003 - Week 7-8 Regression and Time Series.md) - econometrics and forecasting fundamentals
- [004 - Week 9-11: Python, SQL, DSA](004 - Week 9-11 Python, SQL, DSA.md) - programming, querying, and data structure fundamentals
- [005 - Week 12-13: Cleaning, Visualization, Insight](005 - Week 12-13 Cleaning, Visualization, Insight.md) - turning raw data into clear, communicated findings
- [006 - Week 14-18: Supervised, Unsupervised, Feature Engineering](006 - Week 14-18 Supervised, Unsupervised, Feature Engineering.md) - core machine learning skills
- [007 - Week 19-21: Neural Networks, CNN, RNN, Transformer](007 - Week 19-21 Neural Networks, CNN, RNN, Transformer.md) - deep learning architectures
- [008 - Week 22-23: FastAPI, Docker, CI/CD](008 - Week 22-23 FastAPI, Docker, CI - CD.md) - deploying and operating models in production
- [009 - Week 24: Portfolio Project](009 - Week 24 Portfolio Project.md) - packaging everything into a capstone portfolio piece

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
