# Module 03 - Econometrics and Time Series

**Course:** 01 - Math, Statistics and Econometrics

This module has 18 lessons from the AI & Data Scientist roadmap (~22 min each, ~6.6 hours total).

## Outcome

Model relationships and time-dependent data with regression, diagnostics, ARIMA and forecasting workflows.

## Project

Mini project: Sales Forecasting with trend/seasonality analysis and a baseline or ARIMA forecast.

## Content Groups

- Econometrics Fundamentals (Lessons 001-009)
- Time Series (Lessons 010-018)

## Lessons

- [001 - Econometrics Fundamentals](001 - Econometrics Fundamentals.md) - how economic theory, data, and statistics combine to test relationships and estimate effects
- [002 - Regression](002 - Regression.md) - modeling the relationship between a dependent variable and one or more predictors
- [003 - Linear Regression](003 - Linear Regression.md) - fitting a straight-line relationship between features and a continuous target
- [004 - OLS](004 - OLS.md) - Ordinary Least Squares, the standard method for estimating linear regression coefficients
- [005 - Residual](005 - Residual.md) - the difference between an observed value and a model's predicted value
- [006 - R-squared](006 - R-squared.md) - the proportion of variance in the target explained by the model
- [007 - Multicollinearity](007 - Multicollinearity.md) - when predictor variables are highly correlated, destabilizing regression coefficients
- [008 - Heteroskedasticity](008 - Heteroskedasticity.md) - when the variance of errors changes across levels of the predictors
- [009 - Fitting Distributions](009 - Fitting Distributions.md) - matching a theoretical probability distribution to observed data
- [010 - Time Series Basics](010 - Time Series Basics.md) - data indexed in time order and the patterns unique to it
- [011 - Trend](011 - Trend.md) - the long-term upward or downward movement in a time series
- [012 - Seasonality](012 - Seasonality.md) - repeating patterns in a time series tied to a fixed period
- [013 - Noise](013 - Noise.md) - the random, unexplained fluctuation left after removing trend and seasonality
- [014 - Stationarity](014 - Stationarity.md) - when a time series' statistical properties stay stable over time
- [015 - Autocorrelation](015 - Autocorrelation.md) - the correlation between a time series and a lagged version of itself
- [016 - ACF / PACF](016 - ACF - PACF.md) - plots used to identify the lag structure of a time series
- [017 - ARIMA Model](017 - ARIMA Model.md) - a classic forecasting model combining autoregression, differencing, and moving averages
- [018 - Forecasting Pipeline](018 - Forecasting Pipeline.md) - the end-to-end workflow from raw time series to a validated forecast (mini project)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
