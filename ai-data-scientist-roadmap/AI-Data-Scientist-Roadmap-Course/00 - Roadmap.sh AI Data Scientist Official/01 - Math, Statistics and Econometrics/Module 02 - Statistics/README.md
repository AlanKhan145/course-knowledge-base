# Module 02 - Statistics

**Course:** 01 - Math, Statistics and Econometrics

This module has 33 lessons from the AI & Data Scientist roadmap (~24 min each, ~13.2 hours total).

## Outcome

Use probability, sampling, descriptive statistics, hypothesis testing and A/B testing to make decisions from data.

## Project

Mini project: A/B Test Conversion Rate with conversion metric, hypothesis test and rollout recommendation.

## Content Groups

- Descriptive Statistics (Lessons 001-009)
- Probability and Sampling (Lessons 010-019)
- Testing and Experiments (Lessons 020-033)

## Lessons

- [001 - Descriptive Statistics](001 - Descriptive Statistics.md) - summarizing a dataset's center, spread, and shape with numbers and simple charts
- [002 - Mean](002 - Mean.md) - the arithmetic average of a set of values
- [003 - Median](003 - Median.md) - the middle value of a sorted dataset, robust to outliers
- [004 - Mode](004 - Mode.md) - the most frequently occurring value in a dataset
- [005 - Variance](005 - Variance.md) - the average squared deviation from the mean, measuring spread
- [006 - Standard Deviation](006 - Standard Deviation.md) - the square root of variance, expressed in the original units
- [007 - Percentile and Quantile](007 - Percentile and Quantile.md) - values that divide a ranked dataset into equal proportions
- [008 - Skewness](008 - Skewness.md) - a measure of asymmetry in a distribution's shape
- [009 - Outlier](009 - Outlier.md) - a data point that differs markedly from the rest of the dataset
- [010 - Probability](010 - Probability.md) - the likelihood of an event, the foundation of statistical inference
- [011 - Random Variable](011 - Random Variable.md) - a variable whose value is a numerical outcome of a random phenomenon
- [012 - Distribution](012 - Distribution.md) - the pattern of values a random variable can take and how often
- [013 - Bernoulli Distribution](013 - Bernoulli Distribution.md) - a distribution for a single trial with two possible outcomes
- [014 - Binomial Distribution](014 - Binomial Distribution.md) - the distribution of the number of successes across repeated Bernoulli trials
- [015 - Normal Distribution](015 - Normal Distribution.md) - the symmetric bell-shaped distribution underlying many statistical methods
- [016 - Sampling](016 - Sampling.md) - selecting a subset of data to estimate properties of a larger population
- [017 - Sampling Bias](017 - Sampling Bias.md) - systematic error introduced when a sample does not represent the population
- [018 - Sample Size](018 - Sample Size.md) - how many observations are needed to detect an effect reliably
- [019 - Central Limit Theorem](019 - Central Limit Theorem.md) - why sample means tend toward a normal distribution as sample size grows
- [020 - Hypothesis Testing](020 - Hypothesis Testing.md) - a framework for deciding whether data supports or contradicts a claim
- [021 - Null Hypothesis](021 - Null Hypothesis.md) - the default assumption of no effect or no difference being tested against
- [022 - Alternative Hypothesis](022 - Alternative Hypothesis.md) - the claim that there is an effect or difference in the data
- [023 - p-value](023 - p-value.md) - the probability of seeing results this extreme if the null hypothesis were true
- [024 - Confidence Interval](024 - Confidence Interval.md) - a range of plausible values for an unknown population parameter
- [025 - Type I / Type II Error](025 - Type I - Type II Error.md) - false positives and false negatives in hypothesis testing
- [026 - t-test](026 - t-test.md) - a test comparing means when the sample size is small or variance is unknown
- [027 - z-test](027 - z-test.md) - a test comparing means or proportions using the normal distribution
- [028 - Chi-square Test](028 - Chi-square Test.md) - a test for relationships between categorical variables
- [029 - A/B Testing](029 - A - B Testing.md) - comparing two variants to decide which one performs better
- [030 - Minimum Detectable Effect](030 - Minimum Detectable Effect.md) - the smallest effect size an experiment is powered to detect
- [031 - CUPED / CUPAC](031 - CUPED - CUPAC.md) - variance-reduction techniques that increase experiment sensitivity
- [032 - Ratio Metrics](032 - Ratio Metrics.md) - metrics defined as a ratio of two quantities, and their special testing considerations
- [033 - Test Sensitivity](033 - Test Sensitivity.md) - how reliably an experiment can detect a true effect (mini project)
