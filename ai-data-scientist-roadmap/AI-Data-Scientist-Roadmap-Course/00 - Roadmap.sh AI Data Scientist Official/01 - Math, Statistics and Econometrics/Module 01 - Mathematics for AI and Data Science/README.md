# Module 01 - Mathematics for AI and Data Science

**Course:** 01 - Math, Statistics and Econometrics

This module has 19 lessons from the AI & Data Scientist roadmap (~24 min each, ~7.6 hours total).

## Outcome

Understand the math language behind vectors, optimization, gradients, PCA, neural networks and embeddings.

## Project

Mini project: Gradient Descent from Scratch with MSE loss and a loss curve over epochs.

## Content Groups

- [Linear Algebra Foundations](01-Algebra/README.md) (Lessons 001-007)
- [Calculus Foundations](02-Calc/README.md) (Lessons 008-016)
- [Optimization for Machine Learning](03-Optim/README.md) (Lessons 017-019)

## Lessons


Note: Lesson files are organized in topic subfolders for easier study.

- [001 - Linear Algebra](01-Algebra/001 - Linear Algebra.md) - the math language of vectors, matrices, transformations, and optimization
- [002 - Vector](01-Algebra/002 - Vector.md) - ordered lists of numbers that represent data points, features, and directions
- [003 - Matrix](01-Algebra/003 - Matrix.md) - rectangular tables of numbers used to represent datasets and transformations
- [004 - Dot Product](01-Algebra/004 - Dot Product.md) - the core operation behind similarity, projections, and neural network computations
- [005 - Matrix Multiplication](01-Algebra/005 - Matrix Multiplication.md) - combining data and transforming features; core of neural networks and attention
- [006 - Eigenvalues and Eigenvectors](01-Algebra/006 - Eigenvalues and Eigenvectors.md) - the special directions preserved by a matrix transformation; the basis of PCA
- [007 - Norm, Distance and Similarity](01-Algebra/007 - Norm, Distance and Similarity.md) - measuring vector length, distance, and similarity between data points
- [008 - Calculus](02-Calc/008 - Calculus.md) - how quantities change; the foundation for gradients and optimization
- [009 - Function](02-Calc/009 - Function.md) - rules mapping inputs to outputs: features, predictions, losses, activations
- [010 - Limit](02-Calc/010 - Limit.md) - what a function approaches as its input nears a point; the foundation for derivatives and convergence
- [011 - Derivative](02-Calc/011 - Derivative.md) - measuring rate of change; the basis of how models learn
- [012 - Partial Derivative](02-Calc/012 - Partial Derivative.md) - rate of change with respect to one variable while holding the others fixed
- [013 - Gradient](02-Calc/013 - Gradient.md) - the vector of partial derivatives that tells a model how to update its parameters
- [014 - Chain Rule](02-Calc/014 - Chain Rule.md) - differentiating nested functions; the basis of backpropagation
- [015 - Mathematical Analysis](02-Calc/015 - Mathematical Analysis.md) - limits, continuity, derivatives, and convergence behind model training
- [016 - Differential Calculus](02-Calc/016 - Differential Calculus.md) - studying change; how loss changes as parameters change
- [017 - Mathematics for Machine Learning](03-Optim/017 - Mathematics for Machine Learning.md) - the foundation for representing data, predictions, and training
- [018 - Loss Function](03-Optim/018 - Loss Function.md) - measuring how wrong a model's predictions are
- [019 - Gradient Descent](03-Optim/019 - Gradient Descent.md) - the optimization algorithm that minimizes loss by updating parameters (mini project)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
