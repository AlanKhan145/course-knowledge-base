# Module 06 - Machine Learning

**Course:** 03 - Machine Learning and Deep Learning

This module has 33 lessons from the AI & Data Scientist roadmap.

## Outcome

Train, compare and evaluate supervised and unsupervised ML models with thoughtful feature engineering.

## Project

Mini project: House Price Prediction with EDA, feature engineering, Linear Regression, Random Forest and XGBoost comparison.

## Content Groups

- Supervised Learning (Lessons 001-007)
- Unsupervised Learning (Lessons 008-012)
- Model Evaluation (Lessons 013-024)
- Feature Engineering (Lessons 025-033)

## Lessons

- [001 - Supervised Learning](001 - Supervised Learning.md) - training models on labeled input-output pairs
- [002 - Linear Regression](002 - Linear Regression.md) - predicting a continuous target as a weighted sum of features
- [003 - Logistic Regression](003 - Logistic Regression.md) - predicting class probabilities using a linear model and a sigmoid function
- [004 - Decision Tree](004 - Decision Tree.md) - a model that splits data into branches based on feature thresholds
- [005 - Random Forest](005 - Random Forest.md) - an ensemble of decision trees that reduces variance through averaging
- [006 - Gradient Boosting](006 - Gradient Boosting.md) - building trees sequentially, each correcting the previous ones' errors
- [007 - XGBoost / LightGBM](007 - XGBoost - LightGBM.md) - optimized, production-grade gradient boosting implementations
- [008 - Unsupervised Learning](008 - Unsupervised Learning.md) - finding structure in data without labeled outcomes
- [009 - K-Means](009 - K-Means.md) - partitioning data into k clusters based on distance to centroids
- [010 - Hierarchical Clustering](010 - Hierarchical Clustering.md) - building a tree of nested clusters without choosing k upfront
- [011 - PCA](011 - PCA.md) - reducing dimensionality by projecting data onto directions of maximum variance
- [012 - Dimensionality Reduction](012 - Dimensionality Reduction.md) - shrinking the number of features while preserving structure
- [013 - Model Evaluation](013 - Model Evaluation.md) - measuring how well a model's predictions match reality
- [014 - Accuracy](014 - Accuracy.md) - the proportion of correct predictions out of all predictions
- [015 - Precision](015 - Precision.md) - of predicted positives, the share that are actually positive
- [016 - Recall](016 - Recall.md) - of actual positives, the share the model correctly identifies
- [017 - F1-score](017 - F1-score.md) - the harmonic mean of precision and recall
- [018 - ROC-AUC](018 - ROC-AUC.md) - a threshold-independent measure of classifier separability
- [019 - Confusion Matrix](019 - Confusion Matrix.md) - a table breaking down predictions by true and predicted class
- [020 - MAE](020 - MAE.md) - the average absolute difference between predicted and actual values
- [021 - MSE](021 - MSE.md) - the average squared difference between predicted and actual values
- [022 - RMSE](022 - RMSE.md) - the square root of MSE, expressed in the target's original units
- [023 - R-squared Metric](023 - R-squared Metric.md) - the proportion of variance in the target explained by a regression model
- [024 - Cross-validation](024 - Cross-validation.md) - evaluating a model across multiple train/test splits for a robust estimate
- [025 - Feature Engineering](025 - Feature Engineering.md) - creating and transforming inputs to improve model performance
- [026 - Scaling](026 - Scaling.md) - rescaling features so they share a comparable range
- [027 - Encoding](027 - Encoding.md) - converting categorical features into a numeric representation
- [028 - Binning](028 - Binning.md) - grouping continuous values into discrete intervals
- [029 - Feature Crossing](029 - Feature Crossing.md) - combining two or more features to capture their interaction
- [030 - Date / Time Features](030 - Date - Time Features.md) - extracting cyclical and calendar signals from timestamps
- [031 - Text Features](031 - Text Features.md) - turning raw text into numeric features for modeling
- [032 - Feature Selection](032 - Feature Selection.md) - choosing the most useful features and discarding the rest
- [033 - Model Selection](033 - Model Selection.md) - comparing candidate models to pick the best one for the task (mini project)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
