# Module 07 - Deep Learning

**Course:** 03 - Machine Learning and Deep Learning

This module has 24 lessons from the AI & Data Scientist roadmap.

## Outcome

Understand neural networks, CNNs, RNN/LSTM, Transformers and transfer learning at a practical level.

## Project

Mini project: Image Classification comparing a small CNN and transfer learning with accuracy and confusion matrix.

## Content Groups

- Neural Network Basics (Lessons 001-009)
- Architectures (Lessons 010-012)
- Transformer Concepts (Lessons 013-017)
- Applications (Lessons 018-024)

## Lessons

- [001 - Neural Network Basics](001 - Neural Network Basics.md) - how layers of connected units learn to approximate functions
- [002 - Neuron](002 - Neuron.md) - the basic computing unit that combines weighted inputs and an activation
- [003 - Layer](003 - Layer.md) - a group of neurons that transforms inputs into outputs together
- [004 - Activation Function](004 - Activation Function.md) - a nonlinearity that lets networks model complex relationships
- [005 - Loss Function](005 - Loss Function.md) - measuring how wrong a network's predictions are during training
- [006 - Backpropagation](006 - Backpropagation.md) - computing gradients by propagating error backward through the network
- [007 - SGD](007 - SGD.md) - Stochastic Gradient Descent, updating weights using small batches of data
- [008 - Adam](008 - Adam.md) - an adaptive optimizer combining momentum and per-parameter learning rates
- [009 - Fully Connected Network](009 - Fully Connected Network.md) - a network where every neuron connects to every neuron in the next layer
- [010 - CNN](010 - CNN.md) - Convolutional Neural Network, using filters to detect spatial patterns in images
- [011 - RNN](011 - RNN.md) - Recurrent Neural Network, processing sequences by carrying a hidden state forward
- [012 - LSTM](012 - LSTM.md) - a gated RNN variant designed to retain information over longer sequences
- [013 - Transformer](013 - Transformer.md) - an architecture built on attention instead of recurrence or convolution
- [014 - Attention](014 - Attention.md) - letting a model weigh which parts of the input matter most for each output
- [015 - Self-attention](015 - Self-attention.md) - attention applied within a single sequence to relate its own tokens
- [016 - Positional Encoding](016 - Positional Encoding.md) - injecting order information into an architecture with no built-in sequence notion
- [017 - Encoder / Decoder](017 - Encoder - Decoder.md) - separating input understanding from output generation in sequence models
- [018 - Image Classification](018 - Image Classification.md) - assigning a label to an entire image
- [019 - Object Detection Basics](019 - Object Detection Basics.md) - locating and classifying multiple objects within an image
- [020 - Feature Extraction](020 - Feature Extraction.md) - using a pretrained network's internal representations for a new task
- [021 - Text Sequence](021 - Text Sequence.md) - representing and modeling ordered tokens of text
- [022 - Time Series](022 - Time Series.md) - applying deep learning to sequential, time-ordered data
- [023 - Sentiment Analysis](023 - Sentiment Analysis.md) - classifying the emotional tone of a piece of text
- [024 - Transfer Learning](024 - Transfer Learning.md) - reusing a pretrained model's weights for a new, related task (mini project)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
