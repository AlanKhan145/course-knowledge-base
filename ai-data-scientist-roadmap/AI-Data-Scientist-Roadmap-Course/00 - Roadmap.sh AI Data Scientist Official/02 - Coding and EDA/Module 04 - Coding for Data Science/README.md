# Module 04 - Coding for Data Science

**Course:** 02 - Coding and EDA

This module has 31 lessons from the AI & Data Scientist roadmap (~20 min each, ~10.3 hours total).

## Outcome

Use Python, SQL, data libraries, notebooks and Git to build reproducible data workflows.

## Project

Mini project: SQL + Python Data Analysis with a small sales database and Pandas report.

## Content Groups

- [Python Fundamentals](01-Python/README.md) (Lessons 001-008)
- [Data Science Libraries and Notebooks](02-Libs/README.md) (Lessons 009-013)
- [Data Structures and Algorithms](03-DSA/README.md) (Lessons 014-020)
- [SQL Querying](04-SQL/README.md) (Lessons 021-028)
- [Workflow and Reproducibility](05-Workflow/README.md) (Lessons 029-031)

## Lessons


Note: Lesson files are organized in topic subfolders for easier study.

- [001 - Python Foundation](01-Python/001 - Python Foundation.md) - why Python is central to data science workflows, from raw data to deployment
- [002 - Variables](01-Python/002 - Variables.md) - named references to values stored in memory
- [003 - Data Types](01-Python/003 - Data Types.md) - what kind of value a variable holds and what operations apply to it
- [004 - Functions](01-Python/004 - Functions.md) - reusable blocks of code that perform a specific task
- [005 - Classes](01-Python/005 - Classes.md) - blueprints for objects that combine data (attributes) and behavior (methods)
- [006 - List / Tuple / Dict / Set](01-Python/006 - List - Tuple - Dict - Set.md) - Python's four core collection types for storing groups of values
- [007 - File Handling](01-Python/007 - File Handling.md) - reading and writing files such as datasets, configs, and logs
- [008 - Error Handling](01-Python/008 - Error Handling.md) - detecting, managing, and responding to runtime problems
- [009 - NumPy](02-Libs/009 - NumPy.md) - fast, memory-efficient numerical arrays and vectorized operations
- [010 - Pandas](02-Libs/010 - Pandas.md) - a library for working with structured, tabular data
- [011 - Matplotlib](02-Libs/011 - Matplotlib.md) - a library for creating static and interactive data visualizations
- [012 - Seaborn](02-Libs/012 - Seaborn.md) - a high-level statistical visualization library built on Matplotlib
- [013 - Jupyter Notebook](02-Libs/013 - Jupyter Notebook.md) - an interactive environment combining code, text, and output
- [014 - Data Structures and Algorithms](03-DSA/014 - Data Structures and Algorithms.md) - how data is organized and processed efficiently
- [015 - Array](03-DSA/015 - Array.md) - an ordered structure for storing multiple values under one name
- [016 - Hash Map](03-DSA/016 - Hash Map.md) - a key-value data structure for fast lookups
- [017 - Stack and Queue](03-DSA/017 - Stack and Queue.md) - LIFO and FIFO structures for controlling processing order
- [018 - Sorting](03-DSA/018 - Sorting.md) - arranging values into a specific order
- [019 - Searching](03-DSA/019 - Searching.md) - finding a target value, record, or pattern within a collection
- [020 - Big O Notation](03-DSA/020 - Big O Notation.md) - describing how runtime or memory scales with input size
- [021 - SQL](04-SQL/021 - SQL.md) - the language for retrieving, filtering, joining, and aggregating relational data
- [022 - SELECT](04-SQL/022 - SELECT.md) - the foundational SQL statement for retrieving and shaping columns
- [023 - WHERE](04-SQL/023 - WHERE.md) - filtering rows in a SQL query based on a condition
- [024 - GROUP BY](04-SQL/024 - GROUP BY.md) - combining rows with matching values for aggregate calculations
- [025 - JOIN](04-SQL/025 - JOIN.md) - combining rows from two or more tables using a related column
- [026 - Subquery](04-SQL/026 - Subquery.md) - a SQL query nested inside another query
- [027 - Window Function](04-SQL/027 - Window Function.md) - calculations across related rows without collapsing them into one
- [028 - CTE](04-SQL/028 - CTE.md) - a temporary named result set that breaks a complex query into readable steps
- [029 - Git / GitHub](05-Workflow/029 - Git - GitHub.md) - version control and collaboration for code, notebooks, and pipelines
- [030 - Notebook Workflow](05-Workflow/030 - Notebook Workflow.md) - organizing notebooks for reproducible exploratory and training work
- [031 - Reproducible Environment](05-Workflow/031 - Reproducible Environment.md) - a setup that lets others rerun your code with the same dependencies and results (mini project)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
