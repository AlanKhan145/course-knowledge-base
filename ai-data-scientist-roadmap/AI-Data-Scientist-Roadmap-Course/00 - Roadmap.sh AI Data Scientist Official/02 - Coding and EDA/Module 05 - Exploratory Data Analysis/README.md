# Module 05 - Exploratory Data Analysis

**Course:** 02 - Coding and EDA

This module has 21 lessons from the AI & Data Scientist roadmap.

## Outcome

Understand, clean, visualize and explain datasets with business-oriented insights.

## Project

Mini project: Customer Churn EDA with cleaning, churn analysis, related features and an insight report.

## Content Groups

- Data Understanding (Lessons 001-006)
- Data Cleaning (Lessons 007-012)
- Visualization (Lessons 013-018)
- Insight Reporting (Lessons 019-021)

## Lessons

- [001 - Data Understanding](001 - Data Understanding.md) - connecting dataset fields to the business question before any modeling
- [002 - Dataset Schema](002 - Dataset Schema.md) - the structure, column names, and types that define a dataset
- [003 - Data Dictionary](003 - Data Dictionary.md) - documentation describing what each column means and how it's used
- [004 - Target Variable](004 - Target Variable.md) - the outcome a model or analysis is trying to explain or predict
- [005 - Feature Type](005 - Feature Type.md) - classifying columns as numerical, categorical, ordinal, or text
- [006 - Business Question](006 - Business Question.md) - translating a stakeholder need into an answerable data question
- [007 - Data Cleaning](007 - Data Cleaning.md) - fixing errors, inconsistencies, and gaps before analysis
- [008 - Missing Value Handling](008 - Missing Value Handling.md) - detecting and treating gaps in a dataset
- [009 - Duplicate Handling](009 - Duplicate Handling.md) - finding and removing redundant records
- [010 - Outlier Detection](010 - Outlier Detection.md) - identifying values that deviate sharply from the rest of the data
- [011 - Data Type Conversion](011 - Data Type Conversion.md) - casting columns to the correct type for analysis
- [012 - Encoding Categorical Variables](012 - Encoding Categorical Variables.md) - turning categories into a numeric form models can use
- [013 - Histogram](013 - Histogram.md) - visualizing the distribution of a single numeric variable
- [014 - Boxplot](014 - Boxplot.md) - visualizing spread, median, and outliers via quartiles
- [015 - Scatter Plot](015 - Scatter Plot.md) - visualizing the relationship between two numeric variables
- [016 - Bar Chart](016 - Bar Chart.md) - comparing values across categories
- [017 - Heatmap](017 - Heatmap.md) - visualizing a matrix of values, often correlations, with color
- [018 - Pairplot](018 - Pairplot.md) - visualizing pairwise relationships across multiple variables at once
- [019 - Insight Writing](019 - Insight Writing.md) - turning a chart or statistic into a clear, actionable statement
- [020 - Observation -> Explanation -> Impact -> Recommendation](020 - Observation - Explanation - Impact - Recommendation.md) - a structure for writing business insights
- [021 - Business Recommendation](021 - Business Recommendation.md) - proposing a concrete action based on data findings (mini project)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
