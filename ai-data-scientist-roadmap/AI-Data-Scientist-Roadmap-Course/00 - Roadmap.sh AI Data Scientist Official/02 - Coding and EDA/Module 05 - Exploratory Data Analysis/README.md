# Module 05 - Exploratory Data Analysis

**Course:** 02 - Coding and EDA

This module has 21 lessons from the AI & Data Scientist roadmap.

## Outcome

Understand, clean, visualize and explain datasets with business-oriented insights.

## Project

Mini project: Customer Churn EDA with cleaning, churn analysis, related features and an insight report.

## Content Groups

- [Data Understanding and Business Context](01-Understand/README.md) (Lessons 001-006)
- [Data Cleaning and Preparation](02-CleanPrep/README.md) (Lessons 007-012)
- [Visualization Patterns](03-Viz/README.md) (Lessons 013-018)
- [Insight and Recommendation Writing](04-Insights/README.md) (Lessons 019-021)

## Lessons


Note: Lesson files are organized in topic subfolders for easier study.

- [001 - Data Understanding](01-Understand/001 - Data Understanding.md) - connecting dataset fields to the business question before any modeling
- [002 - Dataset Schema](01-Understand/002 - Dataset Schema.md) - the structure, column names, and types that define a dataset
- [003 - Data Dictionary](01-Understand/003 - Data Dictionary.md) - documentation describing what each column means and how it's used
- [004 - Target Variable](01-Understand/004 - Target Variable.md) - the outcome a model or analysis is trying to explain or predict
- [005 - Feature Type](01-Understand/005 - Feature Type.md) - classifying columns as numerical, categorical, ordinal, or text
- [006 - Business Question](01-Understand/006 - Business Question.md) - translating a stakeholder need into an answerable data question
- [007 - Data Cleaning](02-CleanPrep/007 - Data Cleaning.md) - fixing errors, inconsistencies, and gaps before analysis
- [008 - Missing Value Handling](02-CleanPrep/008 - Missing Value Handling.md) - detecting and treating gaps in a dataset
- [009 - Duplicate Handling](02-CleanPrep/009 - Duplicate Handling.md) - finding and removing redundant records
- [010 - Outlier Detection](02-CleanPrep/010 - Outlier Detection.md) - identifying values that deviate sharply from the rest of the data
- [011 - Data Type Conversion](02-CleanPrep/011 - Data Type Conversion.md) - casting columns to the correct type for analysis
- [012 - Encoding Categorical Variables](02-CleanPrep/012 - Encoding Categorical Variables.md) - turning categories into a numeric form models can use
- [013 - Histogram](03-Viz/013 - Histogram.md) - visualizing the distribution of a single numeric variable
- [014 - Boxplot](03-Viz/014 - Boxplot.md) - visualizing spread, median, and outliers via quartiles
- [015 - Scatter Plot](03-Viz/015 - Scatter Plot.md) - visualizing the relationship between two numeric variables
- [016 - Bar Chart](03-Viz/016 - Bar Chart.md) - comparing values across categories
- [017 - Heatmap](03-Viz/017 - Heatmap.md) - visualizing a matrix of values, often correlations, with color
- [018 - Pairplot](03-Viz/018 - Pairplot.md) - visualizing pairwise relationships across multiple variables at once
- [019 - Insight Writing](04-Insights/019 - Insight Writing.md) - turning a chart or statistic into a clear, actionable statement
- [020 - Observation -> Explanation -> Impact -> Recommendation](04-Insights/020 - Observation - Explanation - Impact - Recommendation.md) - a structure for writing business insights
- [021 - Business Recommendation](04-Insights/021 - Business Recommendation.md) - proposing a concrete action based on data findings (mini project)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
