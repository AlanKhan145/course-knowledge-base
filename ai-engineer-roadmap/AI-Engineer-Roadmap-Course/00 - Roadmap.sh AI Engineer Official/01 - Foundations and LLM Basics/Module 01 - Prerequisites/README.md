# Module 01 - Prerequisites

**Hoc phan:** 01 - Foundations and LLM Basics

Module nay gom 9 bai tu AI Engineer roadmap.

## Outcome

Prepare the web, backend and programming foundations needed before building AI applications.

## Project

Setup a minimal FastAPI or Node.js API with Git, REST endpoint, database connection and Docker basics.
