# 035 - Visual Novels - Main Menu Functions

## Module

Module 06 - Main Menu Scene

## Thời lượng

17 phút 29 giây

## Nội dung bài học

Tạo script menu, gắn sự kiện `onClick`, bắt đầu game, chuyển scene bằng transition manager, mở website bên ngoài, thoát ứng dụng và quản lý trạng thái các nút.

## Việc cần làm

- [ ] Tạo script `MainMenu`.
- [ ] Gắn `onClick` cho Start.
- [ ] Gắn `onClick` cho Load hoặc Instructions.
- [ ] Gọi transition manager khi Start.
- [ ] Dùng `Application.OpenURL` cho website.
- [ ] Dùng `Application.Quit` cho Quit.
