# Learning Plan - 6 Weeks

## Tuần 1 - Concept, plot và setup Unity

- Học module 01.
- Vẽ flowchart story trước khi mở Unity.
- Học module 02 và tạo project Unity 2D.
- Tổ chức thư mục `Scripts`, `Prefabs`, `Textures`, `Audio`, `DialogueData`.

## Tuần 2 - Dialogue data và UI nền

- Học bài 007-014.
- Tạo `DialogueLine`, `DialogueNode`, choice data.
- Thiết kế Canvas, dialogue box, speaker name, text field và choice panel.
- Tạo choice button prefab.

## Tuần 3 - DialogueManager lõi

- Học bài 015-024.
- Hoàn thiện logic hiển thị line, typewriter, audio, progress button và choices.
- Kết nối animation enum với Animator trigger.
- Test nhiều node liên tiếp.

## Tuần 4 - Animation và transition

- Học module 04 và 05.
- Tạo enter/exit/jump/shake/scale/rotate/float.
- Sửa alpha để sprite không nhấp nháy.
- Tạo `SceneTransitionManager` và chuyển scene bằng fade.

## Tuần 5 - Main menu, nội dung thật và audio

- Học module 06 và 07.
- Tạo main menu có Start, Load, website, Quit.
- Điền nội dung dialogue thật vào các node.
- Thêm background music và Audio Mixer.
- Sửa lỗi typewriter/progress/placeholder.

## Tuần 6 - Save/load và build

- Học module 08 và 09.
- Tạo `GameProgress`, `SaveData`, save/load JSON.
- Test continue game từ nhiều scene.
- Build WebGL, nén ZIP và chuẩn bị upload itch.io.

## Nhịp học khuyến nghị

- Mỗi buổi học xong phải chạy Play Mode ít nhất một lần.
- Sau mỗi module lớn, tạo một bản sao project hoặc commit git.
- Luôn ghi lại tên scene, node, trigger và save key để tránh lỗi typo.
