# 005 - Visual Novels - Unity Overview

## Module

Module 02 - Unity Basics and Import Assets

## Thời lượng

15 phút 8 giây

## Nội dung bài học

Bài học giới thiệu Unity Hub, tạo project Unity 2D và làm quen các cửa sổ Project, Hierarchy, Scene View, Inspector và Game View.

## Mục tiêu sau bài học

- Tạo được Unity 2D project cho visual novel.
- Biết dùng các panel cơ bản của Unity Editor.
- Chạy thử game bằng Game View.

## Việc cần làm trong Unity

- [ ] Cài hoặc mở Unity Hub.
- [ ] Tạo project 2D.
- [ ] Kiểm tra Project window.
- [ ] Kiểm tra Hierarchy và Inspector.
- [ ] Vào Play Mode để xác nhận project chạy.
