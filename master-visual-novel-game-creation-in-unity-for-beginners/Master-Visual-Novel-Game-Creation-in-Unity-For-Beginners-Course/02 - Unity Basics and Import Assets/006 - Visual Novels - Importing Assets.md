# 006 - Visual Novels - Importing Assets

## Module

Module 02 - Unity Basics and Import Assets

## Thời lượng

5 phút 50 giây

## Nội dung bài học

Bài học nhập tài nguyên khóa học vào Unity, tạo thư mục cho textures, UI, backgrounds, character sprites, scripts và prefabs.

## Mục tiêu sau bài học

- Import asset đúng cách.
- Tổ chức thư mục Unity project rõ ràng.
- Chuẩn bị tài nguyên cho dialogue system.

## Việc cần làm trong Unity

- [ ] Tạo thư mục `Textures`.
- [ ] Thêm thư mục UI.
- [ ] Thêm backgrounds và character sprites.
- [ ] Tạo thư mục `Scripts`.
- [ ] Tạo thư mục `Prefabs`.
- [ ] Kiểm tra import settings của sprite nếu cần.
