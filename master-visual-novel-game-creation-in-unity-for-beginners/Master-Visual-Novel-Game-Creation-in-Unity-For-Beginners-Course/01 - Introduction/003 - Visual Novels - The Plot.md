# 003 - Visual Novels - The Plot

## Module

Module 01 - Introduction

## Thời lượng

11 phút 11 giây

## Nội dung bài học

Bài học xây một cốt truyện visual novel ngắn, chia câu chuyện thành các hồi, xác định nhân vật, mục tiêu, lựa chọn của người chơi và danh sách scene/hội thoại.

## Mục tiêu sau bài học

- Viết được plot đủ ngắn để triển khai trong khóa.
- Chia câu chuyện thành scene có mở đầu, xung đột và kết quả.
- Xác định điểm phân nhánh trước khi tạo dialogue node.

## Việc cần làm

- [ ] Viết premiss câu chuyện.
- [ ] Chia plot thành act.
- [ ] Liệt kê các scene từ khu lều đến khu đốt lửa/tìm thức ăn.
- [ ] Ghi các lựa chọn có thể thay đổi diễn biến.

## Kiểm tra nhanh

- [ ] Mỗi scene có mục đích rõ.
- [ ] Mỗi choice dẫn tới node hoặc scene tiếp theo.
- [ ] Plot đủ nhỏ để test trong Unity Play Mode nhiều lần.
