## Nội dung bài học

Giới thiệu project visual novel sẽ xây trong Unity: dialogue system, ScriptableObject, save/load, chuyển scene, animation nhân vật, âm thanh, voice, sound effect và lựa chọn phân nhánh.

## Mục tiêu sau bài học

- Hiểu khóa học tập trung vào tự viết hệ thống bằng C#.
- Nắm các thành phần chính của project cuối khóa.
- Biết rằng graphics/nội dung trong khóa chủ yếu là placeholder để học kỹ thuật.

## Việc cần làm

- [ ] Ghi lại danh sách hệ thống sẽ xây.
- [ ] Xác định phần nào là dữ liệu truyện và phần nào là code engine.
- [ ] Tạo một checklist riêng cho dialogue, UI, animation, save/load và build.
