# 004 - Visual Novels - The Flow Chart

## Module

Module 01 - Introduction

## Thời lượng

9 phút 9 giây

## Nội dung bài học

Bài học biểu diễn cốt truyện bằng sơ đồ, chia thành scene/act, tạo node quyết định, xác định điểm lưu game và theo dõi tiến trình bằng Boolean/dictionary.

## Mục tiêu sau bài học

- Biến plot thành flowchart có thể triển khai bằng `DialogueNode`.
- Xác định node nào cần save progress.
- Biết trạng thái nào nên lưu bằng Boolean, int hoặc string.

## Gợi ý cấu trúc

```text
Camp Scene
  -> Choice: stay / search for food
  -> Bonfire Scene
  -> Save point
```

## Việc cần làm

- [ ] Vẽ node bắt đầu.
- [ ] Vẽ node quyết định.
- [ ] Ghi scene tiếp theo cho từng nhánh.
- [ ] Đánh dấu save point.
- [ ] Ghi các flag cần lưu.
