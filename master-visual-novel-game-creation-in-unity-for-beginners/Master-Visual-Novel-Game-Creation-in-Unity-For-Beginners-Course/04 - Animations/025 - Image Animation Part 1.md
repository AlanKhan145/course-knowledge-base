Module 04 - Animations

## Thời lượng

## Nội dung bài học

Tạo object cha rỗng cho sprite, điều chỉnh pivot bằng cấu trúc cha-con, chuẩn bị nhân vật trái/giữa/phải, làm animation trong local space, thay đổi alpha và chuẩn bị animation clips.

## Việc cần làm

- [ ] Tạo parent object cho character image.
- [ ] Đặt sprite làm object con.
- [ ] Chuẩn bị left/center/right targets.
- [ ] Tạo clip animation đầu tiên.
- [ ] Kiểm tra local position và alpha.
