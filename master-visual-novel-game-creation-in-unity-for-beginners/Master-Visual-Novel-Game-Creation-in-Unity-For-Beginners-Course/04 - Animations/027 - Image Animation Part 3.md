# 027 - Image Animation - Part 3

## Module

Module 04 - Animations

## Thời lượng

14 phút 56 giây

## Nội dung bài học

Tạo animation nhân vật rời màn hình, sao chép và đảo keyframe, căn thời gian enter/exit, tạo hiệu ứng nổi cho nhân vật giữa và quản lý nhiều clip cho cùng một image.

## Việc cần làm

- [ ] Tạo exit-left và exit-right.
- [ ] Đảo keyframe từ animation enter nếu phù hợp.
- [ ] Căn duration giữa enter và exit.
- [ ] Tạo clip float cho character center.
- [ ] Đặt tên clip rõ ràng.
