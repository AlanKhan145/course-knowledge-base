# 029 - Visual Novels - Animator Setup

## Module

Module 04 - Animations

## Thời lượng

13 phút 9 giây

## Nội dung bài học

Thêm Animator Component, dùng Animator như state machine, tạo state cho nhân vật trái/phải, tạo trigger, transition và các trạng thái enter, exit, jump, rotate, scale, shake, float.

## Việc cần làm

- [ ] Thêm Animator Component.
- [ ] Tạo Animator Controller.
- [ ] Tạo states cho từng animation.
- [ ] Tạo triggers.
- [ ] Tạo transitions từ Any State nếu phù hợp.
- [ ] Test trigger từ Inspector hoặc code.
