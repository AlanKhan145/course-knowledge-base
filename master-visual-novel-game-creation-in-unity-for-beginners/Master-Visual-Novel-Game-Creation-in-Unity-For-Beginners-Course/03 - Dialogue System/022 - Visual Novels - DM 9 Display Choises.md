# 022 - Visual Novels - DM #9 Display Choises

## Module

Module 03 - Dialogue System

## Thời lượng

15 phút 27 giây

## Nội dung bài học

Kiểm tra node có lựa chọn hay không, sinh choice button, đưa nội dung lựa chọn lên UI, gắn callback cho từng lựa chọn, chuyển đến node tương ứng và xóa các nút cũ sau khi người chơi chọn.

Ghi chú: "Choises" là lỗi chính tả trong tiêu đề gốc; từ đúng là "Choices".

## Việc cần làm

- [ ] Kiểm tra danh sách choices trong node.
- [ ] Instantiate choice button prefab.
- [ ] Gán text cho button.
- [ ] Gắn callback đến next node.
- [ ] Xóa button cũ sau khi chọn.

## Kiểm tra nhanh

- [ ] Mỗi lựa chọn dẫn đúng node.
- [ ] Không còn button cũ sau khi chuyển node.
- [ ] Choice panel ẩn khi node không có choices.
