# 024 - Visual Novels - DM #11 Play Animations

## Module

Module 03 - Dialogue System

## Thời lượng

8 phút 34 giây

## Nội dung bài học

Tạo enum cho các kiểu animation, đọc animation type từ `DialogueLine`, gửi trigger đến Animator và chạy animation trên image mục tiêu.

## Animation hỗ trợ

```text
Enter
Exit
Jump
Shake
Scale
Rotate
Float
```

## Việc cần làm

- [ ] Tạo `DialogueAnimationType`.
- [ ] Thêm animation type vào `DialogueLine`.
- [ ] Thêm Animator reference cho image mục tiêu.
- [ ] Gọi trigger từ `DialogueManager`.
- [ ] Test từng kiểu animation với line riêng.
