# 019 - Visual Novels - DM #6 Testing Type Writer

## Module

Module 03 - Dialogue System

## Thời lượng

10 phút 37 giây

## Nội dung bài học

Kiểm thử coroutine hiển thị hội thoại, line hiện tại, sprite mục tiêu, tag màu TextMesh Pro và lỗi khi typewriter gặp rich text.

## Mục tiêu sau bài học

- Xác nhận typewriter chạy ổn trong Play Mode.
- Phát hiện lỗi do rich text hoặc sprite target.
- Biết cách debug thứ tự gọi coroutine.

## Việc cần làm

- [ ] Tạo line test có text thường.
- [ ] Tạo line test có thẻ màu TextMesh Pro.
- [ ] Test line có sprite.
- [ ] Test line không có sprite.
- [ ] Kiểm tra không có coroutine bị chạy lặp ngoài ý muốn.
