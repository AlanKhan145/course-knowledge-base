# 016 - Visual Novels - DM #3

## Module

Module 03 - Dialogue System

## Thời lượng

15 phút 30 giây

## Nội dung bài học

Udemy không công khai mô tả chi tiết. Đây là phần tiếp nối quá trình xử lý dòng hội thoại, hình ảnh và trạng thái của dialogue manager.

## Mục tiêu sau bài học

- Hiển thị đúng speaker name và dialogue text.
- Cập nhật sprite nhân vật đúng vị trí.
- Ẩn image mục tiêu khi line không có sprite.

## Việc cần làm

- [ ] Viết hàm cập nhật speaker name.
- [ ] Viết hàm cập nhật dialogue text.
- [ ] Viết hàm chọn image left/center/right.
- [ ] Kiểm tra line có sprite hoặc không có sprite.
