# 021 - Visual Novels - DM #8 Progress Button

## Module

Module 03 - Dialogue System

## Thời lượng

8 phút 36 giây

## Nội dung bài học

Tạo nút tiếp tục, bỏ qua hiệu ứng chạy chữ khi người chơi bấm, hiển thị ngay toàn bộ câu thoại, dừng âm thanh hiện tại, chuyển đến line tiếp theo và chuyển node khi node hiện tại kết thúc.

## Mục tiêu sau bài học

- Người chơi có thể điều khiển nhịp đọc.
- Nút progress xử lý đúng hai trạng thái: đang type và đã type xong.
- Node kết thúc chuyển tiếp đúng.

## Việc cần làm

- [ ] Tạo progress button.
- [ ] Gắn onClick vào `DialogueManager`.
- [ ] Nếu đang type, hiển thị full text.
- [ ] Nếu đã xong line, chuyển line tiếp theo.
- [ ] Nếu hết node, gọi choices hoặc node/scene kế tiếp.
