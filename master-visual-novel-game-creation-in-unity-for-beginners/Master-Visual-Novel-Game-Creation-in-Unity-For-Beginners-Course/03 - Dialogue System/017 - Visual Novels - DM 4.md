# 017 - Visual Novels - DM #4

## Module

Module 03 - Dialogue System

## Thời lượng

14 phút 33 giây

## Nội dung bài học

Udemy không công khai mô tả chi tiết. Bài này nằm ngay trước phần triển khai hiệu ứng typewriter, nên trọng tâm là hoàn thiện luồng dialogue manager để có thể thay cách hiển thị text bằng coroutine.

## Mục tiêu sau bài học

- Hoàn thiện luồng chuyển line trong node.
- Chuẩn bị biến trạng thái cho typewriter.
- Đảm bảo manager biết khi nào node đã kết thúc.

## Việc cần làm

- [ ] Viết logic next line.
- [ ] Kiểm tra điều kiện hết line.
- [ ] Chuẩn bị gọi choices hoặc next node sau khi hết line.
- [ ] Chạy Play Mode với nhiều line liên tiếp.
