# 015 - Visual Novels - DM #2

## Module

Module 03 - Dialogue System

## Thời lượng

7 phút 35 giây

## Nội dung bài học

Udemy không hiển thị mô tả chi tiết riêng cho bài này. Dựa trên trình tự chương trình, bài tiếp tục triển khai logic bên trong `DialogueManager`.

## Mục tiêu sau bài học

- Tiếp tục kết nối dữ liệu `DialogueNode` với UI.
- Chuẩn bị luồng đọc từng `DialogueLine`.
- Giữ index dòng hiện tại trong node.

## Việc cần làm

- [ ] Tạo biến node hiện tại.
- [ ] Tạo biến index line hiện tại.
- [ ] Viết hàm bắt đầu dialogue.
- [ ] Viết hàm hiển thị line hiện tại.
