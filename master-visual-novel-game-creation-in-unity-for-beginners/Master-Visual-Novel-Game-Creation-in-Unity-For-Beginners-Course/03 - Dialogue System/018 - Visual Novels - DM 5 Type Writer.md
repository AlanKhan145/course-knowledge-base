# 018 - Visual Novels - DM #5 Type Writer

## Module

Module 03 - Dialogue System

## Thời lượng

15 phút 44 giây

## Nội dung bài học

Tạo hiệu ứng chữ xuất hiện lần lượt bằng coroutine, điều chỉnh tốc độ hiển thị, ẩn image mục tiêu khi không có sprite và hỗ trợ rich-text tag của TextMesh Pro để thẻ màu không làm hỏng hiệu ứng chạy chữ.

## Điểm code cần giữ chắc

- Coroutine chạy theo từng ký tự hoặc ký tự hiển thị.
- Rich text cần được xử lý để tag không hiện từng phần lạ trên màn hình.
- Cần biến trạng thái để biết text đang chạy.

## Việc cần làm

- [ ] Tạo coroutine typewriter.
- [ ] Thêm tốc độ chạy chữ.
- [ ] Xử lý rich-text tag.
- [ ] Cho phép hiển thị toàn bộ text khi cần skip.
