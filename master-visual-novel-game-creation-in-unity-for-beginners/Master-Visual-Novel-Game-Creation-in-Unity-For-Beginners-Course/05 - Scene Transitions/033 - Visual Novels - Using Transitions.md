# 033 - Visual Novels - Using Transitions

## Module

Module 05 - Scene Transitions

## Thời lượng

13 phút 48 giây

## Nội dung bài học

Dọn dẹp dialogue system, kết nối dialogue node với tên scene, chuyển scene khi node kết thúc, tổ chức game theo act và dùng fade khi chuyển giữa các phần truyện.

## Việc cần làm

- [ ] Thêm next scene vào `DialogueNode`.
- [ ] Khi dialogue kết thúc, gọi transition manager.
- [ ] Đảm bảo scene có trong Build Settings.
- [ ] Tổ chức scene theo act.
- [ ] Test chuyển từ scene hội thoại sang scene tiếp theo.
