# 043 - Visual Novels - Loading

## Module

Module 08 - Save and Load Game Progress

## Thời lượng

7 phút 49 giây

## Nội dung bài học

Kiểm tra game có save hay không, bật/tắt nút Load, đọc tiến trình, tìm scene cuối cùng, tải lại scene đã lưu và tiếp tục từ điểm dừng gần nhất.

## Việc cần làm

- [ ] Kiểm tra save tồn tại ở main menu.
- [ ] Disable Load button nếu chưa có save.
- [ ] Khi bấm Load, gọi load progress.
- [ ] Lấy scene đã lưu.
- [ ] Chuyển đến scene bằng transition manager.
- [ ] Test load sau khi thoát Play Mode nếu phù hợp.
