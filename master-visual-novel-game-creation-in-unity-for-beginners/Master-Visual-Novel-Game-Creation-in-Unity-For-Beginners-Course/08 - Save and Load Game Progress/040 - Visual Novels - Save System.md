# 040 - Visual Novels - Save System

## Module

Module 08 - Save and Load Game Progress

## Thời lượng

16 phút 40 giây

## Nội dung bài học

Tạo lớp save tĩnh, cấu trúc `SaveData`, đánh dấu `[Serializable]`, chuyển dữ liệu thành JSON, lưu flags/variables/names, dùng `System.IO` và xác định đường dẫn file save.

## Việc cần làm

- [ ] Tạo `SaveData`.
- [ ] Đánh dấu `[Serializable]`.
- [ ] Tạo static save system.
- [ ] Convert progress thành JSON.
- [ ] Ghi file bằng `System.IO`.
- [ ] Log đường dẫn save để debug.
