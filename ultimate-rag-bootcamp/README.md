# Ultimate RAG Bootcamp Using LangChain, LangGraph & LangSmith

Structured markdown study notes for the Ultimate RAG Bootcamp — a comprehensive course covering Traditional RAG, Advanced RAG, Multimodal RAG, Agentic RAG, Graph RAG, Evaluation, LangGraph, LangSmith, and an end-to-end project.

## Course Stats

- Modules: 29
- Lessons: 141
- Language: English
- Format: Markdown lesson notes, module README files, course index, and syllabus

## How To Use

1. Start with `COURSE_INDEX.md` for the full table of contents.
2. Follow the 7-phase learning path in `SYLLABUS.md`.
3. Open each module folder in order.
4. Use lesson notes as watch-along scaffolds — add your own code and experiments.

## 7-Phase Learning Path

| Phase | Modules | Focus |
|---|---|---|
| 1 — Nền tảng RAG | 1–4 | RAG concepts, pipeline, environment |
| 2 — Data + Embedding + Vector DB | 5–7 | Ingestion, parsing, embedding, ChromaDB/FAISS/Pinecone |
| 3 — Advanced Retrieval | 8–10 | Semantic chunking, hybrid search, query enhancement |
| 4 — Multimodal + Agentic AI | 11–15 | Multimodal RAG, LangChain v1, LangGraph, ReAct |
| 5 — Advanced Agentic RAG | 16–20 | Agentic/Autonomous/Multi-Agent/Corrective/Adaptive RAG |
| 6 — Production RAG | 21–25 | Memory, caching, guardrails, evaluation |
| 7 — Graph RAG + Project | 26–29 | Neo4j, GraphDB, end-to-end project |
