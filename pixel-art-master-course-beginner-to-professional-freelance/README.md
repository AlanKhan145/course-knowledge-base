## Cách học

1. Mở [COURSE_INDEX.md](Pixel-Art-Master-Course-Beginner-to-Professional-Freelance-Course/COURSE_INDEX.md) để xem toàn bộ khóa.
2. Học theo thứ tự Beginner -> Intermediate -> Advanced để kỹ năng line, shape, lighting, material và animation chồng lên nhau tự nhiên.
3. Với mỗi bài, mở file lesson tương ứng và ghi lại canvas size, palette, tool setup và nhận xét readability.
4. Dùng [LEARNING_PLAN_12_WEEKS.md](Pixel-Art-Master-Course-Beginner-to-Professional-Freelance-Course/LEARNING_PLAN_12_WEEKS.md) nếu muốn học đều trong 12 tuần.
5. Dùng [PORTFOLIO_TRACKER.md](Pixel-Art-Master-Course-Beginner-to-Professional-Freelance-Course/PORTFOLIO_TRACKER.md) để chọn bài đưa vào portfolio.
