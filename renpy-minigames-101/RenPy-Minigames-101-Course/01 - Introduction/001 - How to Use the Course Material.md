## Nội dung bài học

Giới thiệu cấu trúc tài liệu thực hành, cách tải project rhythm game hoàn chỉnh, truy cập mã nguồn GitHub, dùng mã nguồn tương ứng với từng bài, chạy thử project trước khi chỉnh sửa và so sánh code của mình với phiên bản hoàn chỉnh.

## Việc cần làm

- [ ] Tải project hoàn chỉnh.
- [ ] Mở repository GitHub của khóa học.
- [ ] Chạy thử rhythm game trước khi code.
- [ ] Xác định file chính: `rhythm_game_displayable.rpy`, `screens.rpy`, `script.rpy`.
- [ ] Ghi cách so sánh code theo từng bài.
