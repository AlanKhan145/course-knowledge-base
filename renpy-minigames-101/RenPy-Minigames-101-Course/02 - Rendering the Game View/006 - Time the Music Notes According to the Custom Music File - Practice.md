# 006 - Time the Music Notes According to the Custom Music File

## Module

Module 02 - Rendering the Game View

## Thời lượng

5 phút 10 giây

## Nội dung bài học

Sử dụng file nhạc riêng, xác định thời điểm beat/onset, chuyển thành dữ liệu nốt, tính thời gian nốt cần xuất hiện trước beat, đảm bảo nốt đến vùng bấm đúng lúc và điều chỉnh offset nếu âm thanh/hình ảnh lệch.

## Luồng xử lý

```text
File nhạc
  -> Phân tích onset
  -> Danh sách thời gian
  -> Gán mỗi thời gian vào track
  -> Sinh nốt sớm hơn thời điểm cần bấm
  -> Nốt tới vùng hit đúng theo nhạc
```

## Việc cần làm

- [ ] Chọn file nhạc.
- [ ] Xác định onset times.
- [ ] Tạo beat times.
- [ ] Tính spawn time dựa trên travel time.
- [ ] Điều chỉnh offset.
