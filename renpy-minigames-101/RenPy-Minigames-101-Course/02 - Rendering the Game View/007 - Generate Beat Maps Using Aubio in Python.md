# 007 - Generate Beat Maps Using Aubio in Python

## Module

Module 02 - Rendering the Game View

## Thời lượng

4 phút 3 giây

## Nội dung bài học

Cài Aubio, đọc file MP3/WAV, phân tích frame âm thanh, phát hiện onset, chuyển onset thành thời gian tính bằng giây, lưu danh sách thời gian vào file `.beatmap.txt` và dùng file này trong Ren'Py.

## Cấu trúc beat map

```text
0.4532
0.9178
1.3821
1.8465
2.2974
```

## Việc cần làm

- [ ] Cài Aubio nếu dùng workflow này.
- [ ] Chạy script `generate_beatmap_aubio.py`.
- [ ] Tạo file `.beatmap.txt`.
- [ ] Kiểm tra mỗi dòng là một timestamp.
- [ ] Đưa beat map vào thư mục audio/game.
