# Module 08 - Product Metrics — Chỉ số sản phẩm

## Mục tiêu module
Biết chọn metric, đọc dữ liệu, thiết kế thử nghiệm và tạo feedback loop.

## Thực hành trọng tâm
Xây metrics tree từ North Star Metric xuống input metrics và đề xuất một A/B test.

## Output sau module
- Metrics tree, dashboard spec and experiment note
- Ghi chú quyết định hoặc insight có thể chia sẻ với stakeholder
- Danh sách câu hỏi còn mở cho research, strategy hoặc execution
