# Module 06 - Product Design — Thiết kế sản phẩm

## Mục tiêu module
Biết phối hợp với design để prototype, test và cải thiện trải nghiệm người dùng.

## Thực hành trọng tâm
Tạo wireframe/prototype thô, chạy usability test với 2-3 người và ghi lại friction chính.

## Output sau module
- Wireframe, prototype test script and usability findings note
- Ghi chú quyết định hoặc insight có thể chia sẻ với stakeholder
- Danh sách câu hỏi còn mở cho research, strategy hoặc execution

## Checklist hoàn thành
- [ ] Đọc toàn bộ bài học trong module
- [ ] Tạo ít nhất một artifact thực hành
- [ ] Liên hệ nội dung với một sản phẩm thật
- [ ] Ghi lại 3 điều sẽ áp dụng trong công việc PM
