# Section 03 - Show, Don't Tell

- Listed: 12 lessons (14 items), 1hr 22min

## Purpose
This section covers the technique of dramatizing scenes through sensory detail, action, and restraint instead of stating facts and emotions directly — including setting, symbolism, and how to handle action and romantic scenes.
