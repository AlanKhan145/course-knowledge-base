# Section 01 - The Character

- Listed: 21 lessons (31 items incl. exercises), 2hr 16min

## Purpose
This section builds the craft of character creation: desire, motivation, secrets, flaws, contradictions, the internal lie, and the transformation arc that will drive the rest of the novel.
