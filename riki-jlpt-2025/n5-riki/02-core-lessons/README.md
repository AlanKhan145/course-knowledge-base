## Cách hoàn thiện lesson scaffold

1. Tách tên video/file thật thành module con.
2. Gắn `source_url` và `asset_type` trong manifest.
3. Chỉ viết ví dụ/transcript khi đã có nguồn tương ứng.
4. Đổi trạng thái từ `scaffold` sang `confirmed` hoặc `partial`.
