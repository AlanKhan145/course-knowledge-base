# N3 — TAISAKU

TAISAKU là chặng chuyển từ học kiến thức sang xử lý dạng bài JLPT.

| # | Module | Nội dung |
|---:|---|---|
| 07 | Taisaku — Từ vựng và Kanji | Nhận diện, phân biệt và áp dụng từ/Kanji |
| 08 | Taisaku — Ngữ pháp | Chiến thuật chọn và loại đáp án |
| 09 | Taisaku — Đọc hiểu | Đọc theo dạng câu hỏi, từ nối và ý chính |
| 10 | Taisaku — Nghe hiểu | Bắt từ khóa, quan hệ ý và đáp án |
| 11 | Tài liệu tham khảo — Tip luyện thi | Tài liệu và chiến thuật bổ trợ |

## Cách học

1. Hoàn thành phần tương ứng trong JUNBI.
2. Học chiến thuật của TAISAKU.
3. Làm một set câu hỏi có bấm giờ.
4. Ghi lỗi theo kỹ năng và quay về đúng module JUNBI.
