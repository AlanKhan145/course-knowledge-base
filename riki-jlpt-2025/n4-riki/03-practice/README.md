# N4 — Bài tập

## Phạm vi

Bài tập N4 là track luyện tập sau Core/Zoom, được giữ riêng với lesson note để có thể liên kết nhiều bài vào cùng một set bài tập.

| Nhóm | Nội dung | Trạng thái |
|---|---|---|
| Từ vựng | Ôn từ theo Bài 26–50 | `partial` |
| Kanji | Viết/đọc và nhận diện chữ | `partial` |
| Ngữ pháp | Củng cố mẫu câu theo bài | `partial` |
| Đọc hiểu | Bài đọc ngắn và câu hỏi | `partial` |
| Nghe hiểu | Nghe và chọn đáp án | `partial` |
| Kaiwa | Thực hành nói với giáo viên/bạn học | `partial` |

## Cách tổ chức record

```text
Practice Set → Section → Question → Answer/Explanation
```

Chưa có nội dung câu hỏi trong dữ liệu hiện tại; không tạo đáp án giả.
