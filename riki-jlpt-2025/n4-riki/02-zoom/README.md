# N4 — Zoom

Zoom N4 có khoảng hơn 50 buổi. Chuỗi nội dung đi từ Bài 26 đến Bài 50, xen kẽ các kỹ năng và có test giữa/cuối khóa.

## Progression

```text
Từ vựng → Ngữ pháp → Hán tự → Đọc → Nghe → Kaiwa
→ Ôn tập → Test giữa khóa → Test cuối khóa
```

## Record convention

Tên buổi chưa được liệt kê đầy đủ trong nguồn hiện tại. Khi cào lại Drive, mỗi video cần có: `session_no`, `title`, `modules`, `related_lessons`, `asset_type`, `source_status`.

| Trạng thái | Ý nghĩa |
|---|---|
| `partial` | Đã biết chuỗi và kỹ năng nhưng thiếu tên/URL một số buổi |
| `confirmed` | Đã có tên hoặc mốc buổi từ nguồn |
