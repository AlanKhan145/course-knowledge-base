## Main Idea

Introduces the Alias collection: a semantic layer that references Brand primitives by role (e.g. primary, neutral) instead of by raw value.

## Key Topics Mentioned

* Why a semantic layer sits between primitives and components

## Summary

Introduces the Alias collection: a semantic layer that references Brand primitives by role (e.g. primary, neutral) instead of by raw value. This lesson is one building block toward the module's goal: Builds the foundation layer of the token system: primitive Brand values (color scales, font and spacing scales) and the first Alias layer that gives those primitives semantic names.
