## Summary

Introduces design tokens as the single source of truth for color, type, spacing, and sizing, and previews the Figma variable collections that will hold them. This lesson is one building block toward the module's goal: Builds the foundation layer of the token system: primitive Brand values (color scales, font and spacing scales) and the first Alias layer that gives those primitives semantic names.
