Creates the Brand variable collection in Figma, the raw/primitive layer holding literal hex colors and base numbers that every other token will reference. This lesson is one building block toward the module's goal: Builds the foundation layer of the token system: primitive Brand values (color scales, font and spacing scales) and the first Alias layer that gives those primitives semantic names.
