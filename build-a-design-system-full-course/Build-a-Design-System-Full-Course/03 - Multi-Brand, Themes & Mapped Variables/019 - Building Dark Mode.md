# 019 - Building Dark Mode

## Module

Multi-Brand, Themes & Mapped Variables

## Video Timestamp

51:32 (start time in the full-length course video)

## Main Idea

Adds a Dark mode to the Mapped collection so every semantic token (text, icon, surface, border) flips automatically without touching components.

## Key Topics Mentioned

* Adding a mode to a variable collection
* Re-pointing Mapped tokens per mode
* Testing components against both modes

## Summary

Adds a Dark mode to the Mapped collection so every semantic token (text, icon, surface, border) flips automatically without touching components. This lesson is one building block toward the module's goal: Extends the token system to support multiple brands and light/dark themes by adding a Mapped collection of purpose-based tokens (text, icon, surface, border) that swap per mode.
