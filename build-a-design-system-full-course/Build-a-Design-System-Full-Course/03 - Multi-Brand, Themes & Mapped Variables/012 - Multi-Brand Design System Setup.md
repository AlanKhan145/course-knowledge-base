Configures Figma variable modes so a single set of collections can serve multiple brands, each with its own set of primitive values. This lesson is one building block toward the module's goal: Extends the token system to support multiple brands and light/dark themes by adding a Mapped collection of purpose-based tokens (text, icon, surface, border) that swap per mode.
