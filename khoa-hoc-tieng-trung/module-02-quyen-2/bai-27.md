# Module 02 — Giáo trình Hán Ngữ Quyển 2

## Bài 27 — 玛丽都哭了 — Mary khóc rồi

**Trạng thái:** Đã xác định từ metadata.

### Tóm tắt

Luyện cách nhấn mạnh phạm vi/toàn bộ bằng `都` và sự thay đổi trạng thái bằng `了`.

### Mục tiêu

- Dùng `都` sau chủ thể/phạm vi phù hợp.
- Hiểu `哭了` là trạng thái “đã khóc/khóc rồi” trong ngữ cảnh.
- Kết hợp chủ ngữ riêng với phó từ và trợ từ.

### Từ vựng

| Pinyin | Chữ Hán | Nghĩa |
|---|---|---|
| Mǎlì | 玛丽 | Mary |
| kū | 哭 | khóc |
| dōu | 都 | đều, hết |
| lèi | 累 | mệt |
| shēngqì | 生气 | tức giận |

### Ngữ pháp

- `Chủ thể/phạm vi + 都 + động từ`.
- `Động từ + 了` để nêu sự hoàn tất hoặc thay đổi tình huống.

### Ví dụ

- 玛丽都哭了。— Mary khóc rồi.
- 他们都回家了。— Họ đều về nhà rồi.

### Bài tập

Viết bốn câu với `都` và bốn câu với `……了`, sau đó giải thích sắc thái bằng tiếng Việt.
