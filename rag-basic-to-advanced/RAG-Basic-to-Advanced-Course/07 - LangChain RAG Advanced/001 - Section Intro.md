# 001 - Section Intro

## Section

LangChain / RAG Advanced

## Duration

1 minute

## Main Idea

Introduces the advanced RAG techniques section. At this point students have a working RAG pipeline; now they learn the methods that improve retrieval quality and recall, which are the key levers for production-grade RAG systems.

## Learning Objectives

By the end of this lesson, you should be able to:

- Understand why a basic RAG pipeline often falls short in production.
- Know that the section covers advanced chunking, re-ranking, and query expansion.

## Summary

A basic RAG pipeline retrieves naively — fixed chunks, single query, no re-ranking. This section adds techniques that significantly improve answer quality: smarter splitting, re-ranking retrieved chunks by actual relevance, and query expansion to increase recall.
