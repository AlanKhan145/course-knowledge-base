# Section 04 - VS Code & GitHub Repo Setup

- Lessons: 3
- Duration: 4min

## Purpose

Gets the development environment ready so students can follow along with every code demo in the course. Covers Python, VS Code, Git, and cloning the course repository.

## Lessons

- [001 - Downloading Python, VS Code, Git and more](001 - Downloading Python, VS Code, Git and more.md) - 2min
- [002 - Cloning and accessing all Projects](002 - Cloning and accessing all Projects.md) - 2min
- [003 - PDF for entire course](003 - PDF for entire course.md) - 1min

## Prerequisites

- A machine running Windows, macOS, or Linux
- Internet access to download tools and clone the repo

## Study Checklist

- [ ] Install Python 3.10+ and confirm `python --version` works.
- [ ] Install VS Code and the Python extension.
- [ ] Install Git and confirm `git --version` works.
- [ ] Clone the course GitHub repo and open it in VS Code.
- [ ] Download the course PDF for offline reference.
