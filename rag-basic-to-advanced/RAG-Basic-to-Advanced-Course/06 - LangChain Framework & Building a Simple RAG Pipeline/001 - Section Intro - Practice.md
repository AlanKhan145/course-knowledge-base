# 001 - Section Intro

## Section

LangChain Framework & Building a Simple RAG Pipeline

## Duration

1 minute

## Main Idea

Introduces LangChain as the orchestration framework that glues together all the RAG components — loaders, splitters, embeddings, vector stores, retrievers, and LLMs — into a coherent pipeline.

## Learning Objectives

By the end of this lesson, you should be able to:

- Understand what LangChain does in a RAG system.
- Know what projects will be built in this section: Website Chatbot, Website Chatbot with Memory, and CSV Chatbot.

## Summary

LangChain provides ready-made abstractions for every component of a RAG pipeline. Instead of wiring together loaders, embeddings, and LLMs manually, LangChain chains these components into a clean, composable pipeline. This section builds that pipeline from scratch.
