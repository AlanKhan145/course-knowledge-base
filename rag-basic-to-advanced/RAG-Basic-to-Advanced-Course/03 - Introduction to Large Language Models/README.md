# Section 03 - Introduction to Large Language Models

- Lessons: 6
- Duration: 31min

## Purpose

Introduces LLMs as the generation component of RAG. Covers the difference between open-source and closed-source models, their trade-offs, and how RAG enhances LLM output quality. Ends with a hands-on lesson running a local LLM with Ollama.

## Key Concepts

- Transformer architecture, GPT-style models, few-shot learning
- Closed-source: OpenAI, Claude, Gemini — easy API, higher cost
- Open-source: Llama, Mistral, Gemma — local control, setup overhead
- Ollama as local LLM runner
