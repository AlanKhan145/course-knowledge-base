# Section 05 - Vector Databases & Embeddings

- Lessons: 7
- Duration: 37min

## Purpose

The core technical section of the course. Explains vectors, embeddings, and how they enable semantic search. Covers multiple modalities (text, image, audio, graph) and sets up Pinecone as the vector database with hands-on indexing practice.

## Key Concepts

- Vector as a numeric representation capturing semantic meaning
- Embedding models: Word2Vec, Sentence Transformers, ResNet, Node2Vec, Librosa
- ANN / HNSW approximate nearest neighbor search
- Pinecone index creation, upsert, and query
