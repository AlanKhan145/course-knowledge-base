# Module 05 - Creative Modeling with Modifiers

- Số bài học: 8
- Tổng thời lượng: 53 phút

## Mục tiêu module

Module khám phá cách kết hợp sáng tạo các modifier để tạo hình dạng phức tạp mà không cần chỉnh sửa mesh thủ công nhiều: Array kết hợp Simple Deform, Array kết hợp Screw theo dạng xuyên tâm (cầu thang xoắn), Array bám theo Curve (dây thừng, xúc tu), Screw Modifier (đinh vít, đai ốc, lò xo), Shrinkwrap kết hợp Solidify (băng quấn, vật trang trí bám bề mặt), Wireframe Modifier (thùng rác, microphone dạng khung dây), Skin Modifier (tạo thể tích nhanh cho cây và base mesh nhân vật), và Surface Deform Modifier (biến dạng mesh theo bề mặt khác, kết hợp cloth simulation).
