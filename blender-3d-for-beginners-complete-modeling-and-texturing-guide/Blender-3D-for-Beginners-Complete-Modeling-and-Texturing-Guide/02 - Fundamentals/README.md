# Module 02 - Fundamentals

- Số bài học: 16
- Tổng thời lượng: 1 giờ 25 phút

## Mục tiêu module

Module nền tảng trang bị toàn bộ kỹ năng thao tác cơ bản với Blender: giao diện và các workspace, điều hướng viewport, overlays và viewport shading, lựa chọn/ẩn hiện/tổ chức đối tượng bằng Collections, tạo và biến đổi đối tượng, làm việc trong Edit Mode với các công cụ dựng hình chính (Extrude, Inset, Bevel, Loop Cut, Knife, Slide, Rip Region, Grid Fill, Triangulate, Merge by Distance, Bridge Edge Loops), giới thiệu hệ thống Modifier (Array, Bevel, Subdivision Surface, Mirror), các add-on quan trọng (F2, LoopTools, Node Wrangler), tùy chỉnh phím tắt/giao diện, tài liệu online, kiến thức vật liệu cơ bản và khép lại bằng việc dựng một scene hoàn chỉnh để render mô hình. Đây là module dài và quan trọng nhất về mặt kỹ năng nền tảng, làm bệ phóng cho toàn bộ các module thực hành tiếp theo.
