# Module 04 - Statistics Basics - Thống kê cơ bản

## Mục tiêu module
Nắm thống kê nền tảng để mô tả dữ liệu, kiểm định giả thuyết và tránh kết luận sai.

## Thực hành trọng tâm
Tạo một dataset nhỏ, tính descriptive statistics và viết nhận xét tránh nhầm correlation với causation.

## Output sau module
- Statistics cheat sheet and hypothesis testing note
- Ghi chú decision/report có thể chia sẻ với stakeholder
- Danh sách câu hỏi dữ liệu, rủi ro metric hoặc việc cần phân tích tiếp
