# Module 11 - BI Techniques - Kỹ thuật BI nâng cao

## Mục tiêu module
Biết dùng time series, A/B testing, cohort, forecasting và ML cơ bản trong BI.

## Thực hành trọng tâm
Tạo một analysis brief cho forecasting, cohort hoặc A/B test trong bối cảnh kinh doanh.

## Output sau module
- Advanced analysis notebook or experiment brief
- Ghi chú decision/report có thể chia sẻ với stakeholder
- Danh sách câu hỏi dữ liệu, rủi ro metric hoặc việc cần phân tích tiếp
