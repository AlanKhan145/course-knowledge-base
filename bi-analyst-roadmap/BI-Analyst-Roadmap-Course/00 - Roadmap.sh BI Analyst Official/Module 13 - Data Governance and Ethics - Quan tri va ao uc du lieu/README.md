# Module 13 - Data Governance & Ethics - Quản trị và đạo đức dữ liệu

## Mục tiêu module
Hiểu data quality, ethical use, regulation và algorithmic bias.

## Thực hành trọng tâm
Review một dataset theo data quality, privacy, lineage và bias risk.

## Output sau module
- Data quality checklist and ethics review note
- Ghi chú decision/report có thể chia sẻ với stakeholder
- Danh sách câu hỏi dữ liệu, rủi ro metric hoặc việc cần phân tích tiếp

- [ ] Đọc toàn bộ bài học trong module
- [ ] Tạo ít nhất một artifact thực hành
- [ ] Liên hệ nội dung với một business question thật
- [ ] Ghi lại 3 điều sẽ áp dụng trong công việc BI Analyst
