# Module 05 - What is Data? - Hiểu về dữ liệu

## Mục tiêu module
Hiểu loại dữ liệu, nguồn dữ liệu và format phổ biến khi làm BI.

## Thực hành trọng tâm
Lập inventory nguồn dữ liệu cho một business domain và phân loại structured/semi-structured/unstructured.

## Output sau module
- Data source inventory and format comparison note
- Ghi chú decision/report có thể chia sẻ với stakeholder
- Danh sách câu hỏi dữ liệu, rủi ro metric hoặc việc cần phân tích tiếp
