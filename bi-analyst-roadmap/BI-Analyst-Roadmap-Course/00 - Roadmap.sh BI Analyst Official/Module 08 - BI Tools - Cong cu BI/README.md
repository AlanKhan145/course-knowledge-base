# Module 08 - BI Tools - Công cụ BI

## Mục tiêu module
Biết dùng Excel, BI platforms và Python/R ở mức phù hợp với BI Analyst.

## Thực hành trọng tâm
Tạo dashboard nhỏ bằng Excel, Power BI/Tableau/Looker hoặc notebook Python/R.

## Output sau module
- Tool comparison matrix and small dashboard prototype
- Ghi chú decision/report có thể chia sẻ với stakeholder
- Danh sách câu hỏi dữ liệu, rủi ro metric hoặc việc cần phân tích tiếp
