## Main Idea

With the CLAUDE.md context in place, the instructor asks Claude Code to "integrate OpenAI" so the
hero section's text field and submit button can actually do something. Claude Code breaks the
request into concrete tasks: install the OpenAI SDK, create an API route, set up the required
environment variable, and update the UI to display the AI-generated business ideas — though the UI
piece is treated as a rough placeholder for now, since no design exists yet for the results screen.
He approves the plan (yes, don't ask again) and lets it run through each task, including creating
the API route that will call OpenAI.
