# 009 - Reviewing the First Generated UI and Requesting Fixes

## Section

From Figma to Cursor & Claude Code with MCP — Building Sidebling.com

## Duration

2:34

## Main Idea

With MCP access restored, the agent installs Tailwind CSS and generates HTML markup with Tailwind
classes based on the Figma selection. The first result isn't pixel-perfect, but it does deliver
what was explicitly requested: the floating label works correctly, and the footer cards are indeed
now bound to the bottom. Problems the instructor spots by eye: the navbar isn't centered, the logo
was auto-generated incorrectly (the AI invented its own logo rather than waiting for the real
asset), and too many placeholder footer cards are causing the layout to overflow with scrollbars.
He notes the overflow issue will be handled later by trimming placeholders until real data exists.

## Key Topics Mentioned

* Installing Tailwind CSS via the agent
* Generating HTML + Tailwind markup from the Figma selection
* Confirms floating label and footer-bottom binding both worked as requested
* Visual defects found: uncentered navbar, incorrect auto-generated logo, footer overflow from too
  many placeholder cards
* Plan to reduce placeholder cards until real data is wired up later

## Review Questions

1. What is the main purpose of reviewing generated output against the original design requests?
2. How would you apply the "trim placeholders for now" approach to your own placeholder data?
3. What are the specific defects called out in this first-pass review?
4. What risk is there in an AI inventing assets (like a logo) that weren't part of the request?

## Summary

Walks through evaluating the first AI-generated UI pass: confirming the explicitly requested
behaviors worked (floating label, footer binding) while identifying visual issues that still need
follow-up prompts (navbar alignment, an incorrect placeholder logo, and footer overflow from
excess placeholder cards). This lesson is one building block toward the section's goal of
iterative, prompt-by-prompt refinement rather than expecting a perfect first result.
