# 001 - Recap: Where the Sidebling Project Stands

## Section

From Figma to Cursor & Claude Code with MCP — Building Sidebling.com

## Duration

0:48

## Main Idea

Opens the third video in a build-in-public series for Sidebling.com, an AI tool where a visitor
types in a hobby or interest and gets ideas for turning it into money. Video 1 covered the concept;
video 2 covered the custom logo and the Figma UI design. This video is where the design finally
gets wired into code using Cursor, Claude Code, and the Figma MCP server.

## Key Topics Mentioned

* Sidebling.com concept: enter a hobby/interest, AI suggests ways to monetize it
* Series recap: video 1 = idea, video 2 = logo + Figma UI design
* This video's goal: translate the Figma design into a real browser app using Cursor + Claude Code
  + Figma MCP server

## Review Questions

1. What is the main purpose of this recap in the context of the overall Sidebling build series?
2. Why does the instructor split "design" and "code" into separate videos instead of one long one?
3. What are the three previous milestones this video builds on?
4. What risk is there in jumping straight to code without first nailing down the idea and design?

## Summary

Recaps the Sidebling.com project (an AI hobby-to-income idea generator) and frames this video as
the moment the Figma design gets translated into working code via Cursor, Claude Code, and the
Figma MCP server. This lesson sets the stage for the section's goal: showing a realistic,
step-by-step workflow for turning a Figma design into a functioning Nuxt.js app with AI coding
tools.
