## Section

## Duration

## Main Idea

Now that there's an actual project to describe, the instructor runs Claude Code's `/init` command,
which analyzes the codebase's structure and architecture and writes a `CLAUDE.md` file summarizing
it. Notably, Claude Code is able to infer the app's overall purpose just from the homepage content,
without being told explicitly. This file becomes the project's persistent context: any new Claude
Code session automatically reads it first, so the assistant doesn't need the project re-explained
every time.

## Key Topics Mentioned

* Claude Code's `/init` command
* Auto-generated `CLAUDE.md` markdown file summarizing structure and architecture
* Claude inferring the app's purpose from homepage content alone
* `CLAUDE.md` as persistent, automatically-loaded project context for future sessions
* Editing `CLAUDE.md` manually, or via further prompts in the terminal

## Summary

Introduces Claude Code's `/init` command and the resulting `CLAUDE.md` project-overview file,
which is automatically consulted at the start of every future session so the assistant retains
context about the codebase without re-explanation. This lesson is one building block toward the
section's goal of a maintainable, context-aware AI-coding workflow as the project grows.
