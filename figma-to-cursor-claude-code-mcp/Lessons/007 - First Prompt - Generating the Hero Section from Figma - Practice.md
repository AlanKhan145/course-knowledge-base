# 007 - First Prompt: Generating the Hero Section from Figma

## Section

From Figma to Cursor & Claude Code with MCP — Building Sidebling.com

## Duration

2:36

## Main Idea

With the desktop frame selected in Figma and Cursor's agent chat set to Claude 4 Sonnet, the
instructor writes the first design-generation prompt: "I've selected a layout in Figma. Use the
Figma MCP server to accurately create the selected design." He then layers on specific,
non-obvious behavior the AI couldn't infer from a static design alone, referencing exact Figma
layer names (Hero, HeroCTA, CTA container, text field): the hobby/interest input's label should be
a floating label (shrinks and animates above the field on focus), and the footer cards should stay
bound to the bottom of the viewport across devices.

## Key Topics Mentioned

* Selecting the full desktop frame in Figma before prompting
* Cursor agent chat using Claude 4 Sonnet
* Prompt: "I've selected a layout in Figma. Use the Figma MCP server to accurately create the
  selected design."
* Referencing actual Figma layer names (Hero, HeroCTA, CTA container, text field) for precision
* Explicit floating-label behavior spec (shrink + animate above field on focus)
* Explicit instruction to bind footer cards to the bottom of the viewport

## Review Questions

1. What is the main purpose of referencing exact Figma layer names in the prompt?
2. How would you apply the floating-label instruction to a component the AI can't infer from a
   static screenshot?
3. What are the key pieces of this prompt, and why are they separated (design pull vs. behavior)?
4. What risk is there in prompting purely from a screenshot instead of the live Figma selection?

## Summary

Documents the first substantial generation prompt: pulling the exact Figma selection through MCP,
then adding explicit interaction behavior (floating label) and layout constraints (footer cards
pinned to viewport bottom) that a static design alone wouldn't communicate. This lesson is one
building block toward the section's goal of getting an accurate, behavior-complete first pass at
the UI in one well-scoped prompt.
