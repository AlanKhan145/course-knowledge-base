# 003 - Starting a Fresh Cursor Project and Installing Claude Code

## Section

From Figma to Cursor & Claude Code with MCP — Building Sidebling.com

## Duration

0:59

## Main Idea

Sets up the coding environment from a completely empty folder named "sidebling" opened in Cursor.
The instructor opens Cursor's terminal, finds Claude Code's install command, copies it, and runs
it, which adds the necessary packages. Typing `claude` afterward launches Claude Code's terminal
UI; accepting the "trust files in this folder" prompt lands on the "Welcome to Claude Code" screen,
which is the actual starting point for the build.

## Key Topics Mentioned

* Empty project folder as the starting point (no scaffolding yet)
* Cursor's integrated terminal
* Claude Code install command (copy from Claude's own instructions, paste into terminal)
* Running `claude` to launch the tool
* Trusting files in the current folder on first run
