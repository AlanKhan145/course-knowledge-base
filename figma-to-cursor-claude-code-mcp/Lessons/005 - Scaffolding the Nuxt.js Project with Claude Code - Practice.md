# 005 - Scaffolding the Nuxt.js Project with Claude Code

## Section

From Figma to Cursor & Claude Code with MCP — Building Sidebling.com

## Duration

1:47

## Main Idea

The first real prompt to Claude Code: "Create a Nuxt.js project in the root of the project." Claude
Code responds with a series of follow-up questions (whether to proceed, whether to move generated
files into the project root); the instructor answers yes to both and tells it not to ask again for
similar future confirmations. Claude Code then scaffolds a Next-style app folder, confirms the
Nuxt.js files should be moved to the root, and the project is ready to run.

## Key Topics Mentioned

* Prompt: "Create a Nuxt.js project in the root of the project"
* Claude Code's confirmation prompts before running install commands
* Answering "yes, and don't ask again" to streamline repeated permission prompts
* Moving generated Nuxt files into the project root

## Review Questions

1. What is the main purpose of this scaffolding step in the context of the overall build?
2. How would you apply the "yes, don't ask again" pattern safely in your own projects?
3. What are the key steps Claude Code walks through when scaffolding a new framework project?
4. What risk is there in blanket-approving future confirmations without reviewing what they cover?

## Summary

Covers the single, deliberately narrow prompt used to scaffold the Nuxt.js project, plus how to
handle Claude Code's setup confirmation questions efficiently. This lesson is one building block
toward the section's goal of establishing a real, running codebase before any design translation
work begins.
