- Format: mỗi module có README riêng và mỗi bài học/quiz là một file Markdown

## How To Use

1. Mở [COURSE_INDEX.md](<Learn-Japanese-for-Beginners-Course/COURSE_INDEX.md>) để xem toàn bộ mục lục.
2. Học các module theo thứ tự; mỗi module tập trung vào một chủ đề nhỏ.
3. Đọc file bài học tương ứng và tự bổ sung ví dụ, từ vựng, ghi âm.
4. Làm các file Review Questions sau mỗi nhóm bài.
5. Dùng checklist để theo dõi tiến độ.
