## How This Course Is Structured

The course does not teach traditional line-by-line coding. Instead it teaches how to **direct AI tools** to generate Flutter apps, then debug, extend, connect APIs, and wire up Firebase -- following a repeatable loop:

```text
Design in Figma (AI-assisted) -> Export .fig -> Connect to Cursor -> Generate/prompt code -> Run & test -> Fix errors with AI -> Iterate
```

It has two parallel tracks that interleave through the sections:

1. **Build track** -- full app builds in Cursor (Expense Tracker, Calculator, Notes, Weather, AI Meal Planner, WhatsApp Clone, E-Commerce Store).
2. **Design track** -- standalone Figma UI design projects for a portfolio (Fitness, E-Commerce, Chatbot, Travel/Hotel, Food Delivery, Finance, Restaurant, Banking, Grocery).
