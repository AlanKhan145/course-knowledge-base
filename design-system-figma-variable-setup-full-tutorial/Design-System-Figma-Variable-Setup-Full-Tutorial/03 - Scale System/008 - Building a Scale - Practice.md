# 008 - Building a Scale

## Module

Scale System

## Video Timestamp

31:45 (start time in the full-length course video)

## Main Idea

Hands-on build of a numeric scale as Figma variables, usable for spacing, sizing, or radius.

## Key Topics Mentioned

* Choosing a step progression (linear, geometric, or custom)
* Naming scale steps consistently
* Structuring the scale so it can be aliased later
