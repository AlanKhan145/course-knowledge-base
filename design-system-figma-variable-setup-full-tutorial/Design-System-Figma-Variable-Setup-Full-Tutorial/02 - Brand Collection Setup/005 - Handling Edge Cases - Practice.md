# 005 - Handling Edge Cases

## Module

Brand Collection Setup

## Video Timestamp

22:10 (start time in the full-length course video)

## Main Idea

Addresses edge cases that arise when building color scales, such as uneven contrast steps or brand colors that don't scale cleanly.

## Key Topics Mentioned

* Fixing scales that produce muddy or inconsistent steps
* Adjusting hue/saturation/lightness manually where automation falls short
* Deciding when to hand-pick a step vs generate it algorithmically
