# Design System & Figma Variable Set Up - Full Tutorial

Setting up a full Figma Variables system for a design system -- from Brand primitives and a
numeric scale, through an Alias semantic layer, multi-brand support, a purpose-based Mapped
Collection (text, icon, surface, border), dark mode, and a Responsive Collection for
typography and spacing.

## What You Will Learn

- Understand Figma Variables and Design Token architecture (Brand -> Alias -> Mapped -> Responsive)
- Build a Brand Collection with color scales, edge-case handling, and font variables
- Build a generic numeric Scale system for spacing, sizing, and radius
- Build an Alias Collection for semantic reuse (border width/radius, font)
- Support multiple brands with a multi-brand token approach
- Build a Mapped Collection covering text, icon, surface, and border variables, including status
  and subtle variants
- Set up Dark Mode variables across the Mapped Collection
- Build a Responsive Collection with desktop/mobile type scales, line-height, and paragraph
  spacing
- Identify and build spacing/jumper variables to complete the system
