# Module 04 - Interactive Map and Separate Storylines

Bản đồ tương tác và các tuyến truyện riêng biệt - 23 bài, 2 giờ 13 phút.

## Mục tiêu

Module này xây visual novel lớn hơn với bản đồ tương tác, imagebutton, event system, tuyến truyện song song, ngày đêm, ending và export game.

- Bản đồ tương tác
- imagebutton
- Hover và focus mask
- List trong Python
- Hệ thống sự kiện
- Lịch và số ngày trong game
- Chu kỳ ngày đêm
- Các tuyến truyện song song

- Nhiều ending
- Chỉnh sửa bản đồ bằng GIMP

## Bài tập thực hành

- Xây screen bản đồ và imagebutton
- Kiểm tra hover/focus mask từng địa điểm
- Cập nhật event list và day/night state
- Chạy thử các tuyến truyện độc lập đến ending

## Điều kiện hoàn thành

- Có thể chạy project/module từ Ren'Py Launcher không lỗi.
- Những thay đổi trong bài học được test bằng ít nhất một lần chơi thử.
- Các lựa chọn, biến hoặc asset mới được đặt tên rõ ràng.
- Ghi chú cá nhân đủ để ôn lại mà không cần xem lại toàn bộ video.
