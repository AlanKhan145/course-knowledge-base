# Module 02 - Creating a Basic Visual Novel Using RenPy Script

Tạo visual novel cơ bản bằng Ren'Py Script - 8 bài, 59 phút.

## Mục tiêu

Module này chuyển từ game văn bản sang visual novel có nhân vật, background, lời thoại, chuyển cảnh, nhạc và tài nguyên.

## Kiến thức chính

- Khai báo nhân vật
- Hiển thị sprite và background
- Điều chỉnh vị trí nhân vật
- Hệ thống hội thoại
- Hiệu ứng chuyển cảnh
- Nhạc nền và âm thanh
- Tùy chỉnh màu giao diện
- Quản lý tài nguyên visual novel

## Bài tập thực hành

- Thêm asset vào đúng thư mục
- Khai báo character và image
- Chạy từng cảnh để kiểm tra vị trí/transition/audio
- Ghi chú quy ước đặt tên asset

## Điều kiện hoàn thành

- Có thể chạy project/module từ Ren'Py Launcher không lỗi.
- Những thay đổi trong bài học được test bằng ít nhất một lần chơi thử.
- Các lựa chọn, biến hoặc asset mới được đặt tên rõ ràng.
- Ghi chú cá nhân đủ để ôn lại mà không cần xem lại toàn bộ video.
