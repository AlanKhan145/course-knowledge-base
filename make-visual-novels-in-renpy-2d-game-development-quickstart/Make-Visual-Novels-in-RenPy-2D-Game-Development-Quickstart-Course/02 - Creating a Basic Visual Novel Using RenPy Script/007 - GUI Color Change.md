# 007 - GUI Color Change

## Module

Module 02 - Creating a Basic Visual Novel Using RenPy Script

## Thời lượng

40 giây

## Nội dung bài học

Thay đổi bảng màu giao diện và tạo lại tài nguyên GUI.

## Vai trò của bài học

Bài này thuộc dự án **Basic Visual Novel**. Dùng bài này như ghi chú học kèm video: nắm ý chính, thực hành ngay trong Ren'Py, rồi ghi lại lỗi, lựa chọn thiết kế hoặc đoạn script quan trọng.

## Mục tiêu sau bài học

- Hiểu bài **GUI Color Change** đang đóng góp gì cho visual novel trong module này.
- Thực hiện được thao tác hoặc đoạn script chính theo video.
- Chạy thử game từ Ren'Py Launcher và xác nhận hành vi mới hoạt động đúng.
- Ghi lại ít nhất một ghi chú cá nhân: lỗi gặp phải, biến đã thêm, asset đã dùng, hoặc điều cần ôn lại.

## Kiến thức nền của module

- Khai báo nhân vật
- Hiển thị sprite và background
- Điều chỉnh vị trí nhân vật
- Hệ thống hội thoại
- Hiệu ứng chuyển cảnh
- Nhạc nền và âm thanh
- Tùy chỉnh màu giao diện
- Quản lý tài nguyên visual novel

## Việc cần làm trong Ren'Py

- [ ] Thêm asset vào đúng thư mục

- [ ] Chạy từng cảnh để kiểm tra vị trí/transition/audio
