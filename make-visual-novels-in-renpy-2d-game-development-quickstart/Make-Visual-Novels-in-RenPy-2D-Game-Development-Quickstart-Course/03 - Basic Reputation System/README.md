## Kiến thức chính

- Biến Python trong Ren'Py
- Kiểu dữ liệu cơ bản
- Biến cờ
- Toán tử số học và so sánh
- Điều kiện if, elif, else
- Toán tử logic
- Nhập tên người chơi
- Điểm thiện cảm của từng nhân vật
- Kết thúc phụ thuộc vào lựa chọn

## Bài tập thực hành

- Tạo biến mặc định cho trạng thái game
- Test từng lựa chọn và nhánh hội thoại
- In/quan sát giá trị reputation khi cần debug
- Ghi lại điều kiện dẫn đến từng ending

## Điều kiện hoàn thành

- Có thể chạy project/module từ Ren'Py Launcher không lỗi.
- Những thay đổi trong bài học được test bằng ít nhất một lần chơi thử.
- Các lựa chọn, biến hoặc asset mới được đặt tên rõ ràng.
- Ghi chú cá nhân đủ để ôn lại mà không cần xem lại toàn bộ video.
