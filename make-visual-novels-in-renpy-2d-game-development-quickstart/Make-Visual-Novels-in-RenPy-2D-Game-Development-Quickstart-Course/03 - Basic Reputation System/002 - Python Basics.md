## Module

Module 03 - Basic Reputation System

## Thời lượng

10 phút 7 giây

## Nội dung bài học

Những kiến thức Python cơ bản phục vụ phát triển game.

## Vai trò của bài học

Bài này thuộc dự án **Reputation System**. Dùng bài này như ghi chú học kèm video: nắm ý chính, thực hành ngay trong Ren'Py, rồi ghi lại lỗi, lựa chọn thiết kế hoặc đoạn script quan trọng.

## Mục tiêu sau bài học

- Hiểu bài **Python Basics** đang đóng góp gì cho visual novel trong module này.
- Thực hiện được thao tác hoặc đoạn script chính theo video.
- Chạy thử game từ Ren'Py Launcher và xác nhận hành vi mới hoạt động đúng.
- Ghi lại ít nhất một ghi chú cá nhân: lỗi gặp phải, biến đã thêm, asset đã dùng, hoặc điều cần ôn lại.

## Kiến thức nền của module

- Biến Python trong Ren'Py
- Kiểu dữ liệu cơ bản
- Biến cờ
- Toán tử số học và so sánh
- Điều kiện if, elif, else
- Toán tử logic
- Nhập tên người chơi
- Điểm thiện cảm của từng nhân vật
- Kết thúc phụ thuộc vào lựa chọn

## Việc cần làm trong Ren'Py

- [ ] Tạo biến mặc định cho trạng thái game
- [ ] Test từng lựa chọn và nhánh hội thoại
- [ ] In/quan sát giá trị reputation khi cần debug
- [ ] Ghi lại điều kiện dẫn đến từng ending
