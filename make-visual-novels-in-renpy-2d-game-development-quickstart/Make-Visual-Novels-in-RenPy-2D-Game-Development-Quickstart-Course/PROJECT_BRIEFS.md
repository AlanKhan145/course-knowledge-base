# Project Briefs

## Text-Based Game

Mục tiêu sản phẩm:

- Người chơi đọc truyện và chọn nhánh bằng menu.
- Lựa chọn dẫn đến nhiều kết thúc.
- Script có label rõ ràng và comment đủ để đọc lại.

Kỹ năng trọng tâm:

- Label, jump/call, menu, branching, ending, comment.

Bài tập mở rộng:

- Thêm một lựa chọn quay lại nhánh cũ.
- Thêm ending ẩn nếu người chơi chọn đúng chuỗi lựa chọn.

## Basic Visual Novel

Mục tiêu sản phẩm:

- Có nhân vật, background, lời thoại, transition, nhạc và sound effect.
- GUI có màu phù hợp với tone truyện.

Kỹ năng trọng tâm:

- Character definition, show/hide scene, position, transition, audio.

Bài tập mở rộng:

- Thêm biểu cảm khác nhau cho một nhân vật.
- Thêm cảnh mở đầu ngắn trước title choice đầu tiên.

## Reputation System

Mục tiêu sản phẩm:

- Người chơi nhập tên.
- Lựa chọn cập nhật điểm thiện cảm.
- Ending hoặc dialogue thay đổi theo điểm và flag.

Kỹ năng trọng tâm:

- Python variable, flag, arithmetic, comparison, logical operator, if/elif/else.

Bài tập mở rộng:

- Thêm màn debug tạm hiển thị reputation.
- Tạo ending riêng cho từng nhân vật khi đủ điểm.

## Tales of the Village

Mục tiêu sản phẩm:

- Visual novel có bản đồ tương tác nhiều địa điểm.
- Event thay đổi theo ngày, thời điểm và tiến độ tuyến truyện.
- Có nhiều ending và bản export chạy được.

Kỹ năng trọng tâm:

- Screen Language, imagebutton, focus mask, list, event system, day/night cycle, export.

Bài tập mở rộng:

- Thêm một địa điểm mới có sprite hover riêng.
- Thêm một tuyến truyện phụ kéo dài ít nhất 3 ngày.
