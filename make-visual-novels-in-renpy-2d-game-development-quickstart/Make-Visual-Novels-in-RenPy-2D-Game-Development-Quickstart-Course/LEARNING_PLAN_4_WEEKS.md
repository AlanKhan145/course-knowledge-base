# Learning Plan 4 Weeks

## Cách dùng

Lịch này giả định bạn học 4-5 buổi mỗi tuần, mỗi buổi 60-90 phút. Nếu mới học lập trình, hãy dành thêm thời gian cho module 03 vì phần Python/logic sẽ quyết định độ ổn định của visual novel.

## Tuần 1 - Ren'Py căn bản và game văn bản

- Hoàn thành Module 01.
- Mục tiêu: cài Ren'Py, hiểu Launcher, chỉnh code bằng VS Code, viết label/menu/branching/multiple endings.
- Bài tập: tạo một game văn bản 5 phút chơi có ít nhất 3 lựa chọn và 2 ending.

## Tuần 2 - Visual novel cơ bản

- Hoàn thành Module 02.
- Mục tiêu: thêm nhân vật, background, sprite, transition, music, sound và đổi màu GUI.
- Bài tập: tạo một cảnh visual novel có 2 nhân vật, 2 background, 1 transition và 1 đoạn nhạc nền.

## Tuần 3 - Python và reputation system

- Hoàn thành Module 03.
- Mục tiêu: dùng biến, flag, toán tử, if/elif/else, input tên người chơi, reputation và điều kiện ending.
- Bài tập: tạo 2 nhân vật có điểm thiện cảm riêng và ít nhất 3 lựa chọn ảnh hưởng điểm.

## Tuần 4 - Bản đồ tương tác và xuất game

- Hoàn thành Module 04.
- Mục tiêu: screen, imagebutton, focus mask, list, event system, day/night, tuyến truyện riêng, ending và export.
- Bài tập: tạo bản đồ có 3 địa điểm, mỗi địa điểm có event riêng và ít nhất 1 ending phụ thuộc trạng thái.

## Checklist cuối khóa

- Có game văn bản chạy được.
- Có visual novel cơ bản với asset/audio/transition.
- Có hệ thống reputation dùng Python.
- Có prototype Tales of the Village với bản đồ tương tác.
- Có bản export cho Windows hoặc Linux.
