# 004 - Visual Studio Code Local Version

## Module

Module 01 - Basics of RenPy: Creating a Text-Based Game

## Thời lượng

1 phút 10 giây

## Nội dung bài học

Chuẩn bị Visual Studio Code để chỉnh sửa mã nguồn.

## Vai trò của bài học

Bài này thuộc dự án **Text-Based Game**. Dùng bài này như ghi chú học kèm video: nắm ý chính, thực hành ngay trong Ren'Py, rồi ghi lại lỗi, lựa chọn thiết kế hoặc đoạn script quan trọng.

## Mục tiêu sau bài học

- Hiểu bài **Visual Studio Code Local Version** đang đóng góp gì cho visual novel trong module này.
- Thực hiện được thao tác hoặc đoạn script chính theo video.
- Chạy thử game từ Ren'Py Launcher và xác nhận hành vi mới hoạt động đúng.
- Ghi lại ít nhất một ghi chú cá nhân: lỗi gặp phải, biến đã thêm, asset đã dùng, hoặc điều cần ôn lại.

## Kiến thức nền của module

- Cấu trúc dự án Ren'Py
- Label và luồng truyện
- Menu lựa chọn
- Phân nhánh cốt truyện
- Nhiều kết thúc
- Chú thích trong mã nguồn

## Việc cần làm trong Ren'Py

- [ ] Tạo hoặc mở project Ren'Py
- [ ] Chỉnh file script theo bài học
- [ ] Chạy game từ Ren'Py Launcher
- [ ] Ghi lại lựa chọn, nhánh truyện và lỗi gặp phải
