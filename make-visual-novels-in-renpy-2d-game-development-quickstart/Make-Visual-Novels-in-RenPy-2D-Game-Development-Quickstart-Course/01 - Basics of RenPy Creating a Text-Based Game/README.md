## Kiến thức chính

- Cấu trúc dự án Ren'Py
- Label và luồng truyện
- Menu lựa chọn
- Phân nhánh cốt truyện
- Nhiều kết thúc
- Chú thích trong mã nguồn

## Bài tập thực hành

- Tạo hoặc mở project Ren'Py
- Chỉnh file script theo bài học
- Chạy game từ Ren'Py Launcher
- Ghi lại lựa chọn, nhánh truyện và lỗi gặp phải

## Điều kiện hoàn thành

- Có thể chạy project/module từ Ren'Py Launcher không lỗi.
- Những thay đổi trong bài học được test bằng ít nhất một lần chơi thử.
- Các lựa chọn, biến hoặc asset mới được đặt tên rõ ràng.
- Ghi chú cá nhân đủ để ôn lại mà không cần xem lại toàn bộ video.
