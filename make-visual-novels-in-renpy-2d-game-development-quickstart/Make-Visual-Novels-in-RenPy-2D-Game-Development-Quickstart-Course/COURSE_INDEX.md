# Course Index

## Make Visual Novels in Ren'Py: 2D Game Development Quickstart

Khóa học này phù hợp nếu bạn muốn học Ren'Py từ đầu bằng cách xây visual novel thực tế: đầu tiên là game văn bản, sau đó là visual novel có nhân vật/background/âm thanh, rồi hệ thống thiện cảm và cuối cùng là bản đồ tương tác với nhiều tuyến truyện.

## Mục tiêu đầu ra

Sau khóa học, bạn nên có thể:

- Tạo và cấu trúc project Ren'Py.
- Viết hội thoại, label, menu lựa chọn và phân nhánh truyện.
- Hiển thị nhân vật, background, transition, âm nhạc và sound effect.
- Dùng Python cơ bản trong Ren'Py để lưu trạng thái, tạo flag và reputation.
- Tạo screen, imagebutton, focus mask và bản đồ tương tác.
- Quản lý event, ngày đêm, tuyến truyện song song và ending.
- Đóng gói game cho Windows và Linux.

## Đường học khuyến nghị

1. Làm module 01 chậm để quen indentation, label và menu.
2. Ở module 02, đặt quy ước tên asset ngay từ đầu.
3. Ở module 03, test mọi nhánh lựa chọn vì lỗi logic thường không hiện ngay như lỗi syntax.
4. Ở module 04, vẽ sơ đồ event/ngày/địa điểm trước khi thêm nhiều nội dung.
5. Sau khóa học, polish dự án Tales of the Village thành demo portfolio ngắn.
