## Cách học

1. Mở COURSE_INDEX.md để xem toàn bộ khóa.
2. Học theo thứ tự module nếu bạn mới làm visual novel.
3. Với mỗi bài, mở file lesson tương ứng và ghi lại script/asset/lỗi gặp phải.
4. Dùng LEARNING_PLAN_4_WEEKS.md nếu muốn học gọn trong 4 tuần.
5. Dùng PRACTICE_CHECKLIST.md để theo dõi các kỹ năng Ren'Py và Python.
