# Module 14 - Load Balancer

## Mục tiêu module
Hiểu load balancing, failover và thuật toán phân phối traffic cơ bản.

## Thực hành trọng tâm
Mô tả cách cân bằng tải cho 3 web servers bằng round robin, least connections và failover.

## Output sau module
- Load balancer decision note and failover test plan
- Lab note hoặc troubleshooting checklist có thể dùng lại
- Danh sách rủi ro, câu hỏi mở hoặc command/tool cần luyện thêm
