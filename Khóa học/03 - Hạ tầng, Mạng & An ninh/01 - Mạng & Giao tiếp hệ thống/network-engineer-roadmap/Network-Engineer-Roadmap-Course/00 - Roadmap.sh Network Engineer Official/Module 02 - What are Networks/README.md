# Module 02 - What are Networks?

## Mục tiêu module
Phân biệt các loại mạng và kiến trúc client-server, peer-to-peer.

## Thực hành trọng tâm
Thiết kế topology nhỏ cho nhà/văn phòng, chỉ rõ LAN, WLAN, VPN hoặc cloud network nếu có.

## Output sau module
