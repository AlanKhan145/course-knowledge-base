# Module 16 - Network Security

## Mục tiêu module
Nắm nền tảng network security: firewall, VPN, attacks, IDS/IPS và Zero Trust.

## Thực hành trọng tâm
Tạo baseline security cho mạng nhỏ: firewall rules, VPN, IDS/IPS, Zero Trust và response cho DoS/DDoS.

## Output sau module
- Network security baseline and incident scenario notes
- Lab note hoặc troubleshooting checklist có thể dùng lại
- Danh sách rủi ro, câu hỏi mở hoặc command/tool cần luyện thêm
