# Course Index

## Complete C# Unity 3D Game Development in Unity 6

Khóa học này đi từ Unity/C# căn bản đến 5 game 3D hoàn chỉnh: Obstacle Dodge, Rocket Boost, Galaxy Strike, Royal Run và Sharp Shooter. Trọng tâm là vừa học syntax C#, vừa xây các hệ thống gameplay thực tế trong Unity 6.

## Mục tiêu đầu ra

Sau khóa học, bạn nên có thể:

- Tạo project Unity 6, quản lý scene, GameObject, component, prefab và script.
- Viết C# gameplay script với lifecycle method, biến, điều kiện, loop, list, coroutine, inheritance và property.
- Làm việc với Rigidbody, collision, trigger, physics material, raycast, projectile và NavMesh.
- Dùng Cinemachine, Input System, Terrain, Timeline, Particle System, Audio Source, Post Processing và ProBuilder.
- Xây các hệ thống game: movement, camera, score, hazard, scene loading, weapon switching, ammo, enemy AI, UI, win/lose flow và build.
- Hoàn thiện 5 game 3D nhỏ đủ làm portfolio học tập.

## Đường học khuyến nghị

1. Học module 01-02 thật chậm để chắc Unity Editor, C# cơ bản, collision, tag và prefab.
2. Ở Rocket Boost, tập trung vào Rigidbody, scene flow, audio, particle và build.
3. Ở Galaxy Strike, ghi chú kỹ Timeline/Terrain vì đây là phần có nhiều công cụ Unity chuyên biệt.
4. Ở Royal Run, chú ý procedural generation, list, inheritance, property và dependency injection.
5. Ở Sharp Shooter, test từng hệ thống FPS nhỏ: raycast, weapon, ammo, enemy AI, turret, projectile, UI và win condition.
