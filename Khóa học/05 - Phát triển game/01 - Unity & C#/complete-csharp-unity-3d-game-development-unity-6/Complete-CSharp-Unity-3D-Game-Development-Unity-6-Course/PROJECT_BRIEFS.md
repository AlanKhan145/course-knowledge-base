# Project Briefs

## Obstacle Dodge

Thể loại: sandbox né vật cản 3D.

Trọng tâm: C# cơ bản, lifecycle method, input, collision, tag, prefab, score và hazard.

Bài tập mở rộng:

- Thêm hazard tự xoay.
- Thêm projectile bay về phía player.
- Thêm UI điểm theo thời gian sống sót.

## Rocket Boost

Thể loại: game vật lý điều khiển tên lửa.

Trọng tâm: Rigidbody, Input System, scene loading, audio, particle, state, level dressing, lights và build.

Bài tập mở rộng:

- Thêm obstacle dao động.
- Thêm level thứ hai có độ khó cao hơn.
- Thêm SFX riêng cho crash và success.

## Galaxy Strike

Thể loại: rail shooter.

Trọng tâm: Terrain, Timeline, animation curve, ship movement, laser, enemy wave, UI, signal, render texture, lighting và coroutine.

Bài tập mở rộng:

- Thêm enemy wave mới.
- Thêm đoạn dialogue bằng Timeline Signal.
- Tạo vertical slice 60 giây.

## Royal Run

Thể loại: endless runner sinh bản đồ tự động.

Trọng tâm: procedural generation, chunk movement, loop, list, lane, pickup, inheritance, timer, checkpoint, camera và VFX.

Bài tập mở rộng:

- Thêm chunk hiếm.
- Thêm pickup tăng tốc hoặc tăng thời gian.
- Thêm camera shake khi va chạm.

## Sharp Shooter

Thể loại: FPS.

Trọng tâm: first-person controller, NavMesh AI, raycast, weapon, ammo, pickup, ScriptableObject, ProBuilder, turret, projectile, UI và win condition.

Bài tập mở rộng:

- Thêm enemy wave room.
- Thêm weapon mới bằng ScriptableObject.
- Thêm màn win/game over hoàn chỉnh.
