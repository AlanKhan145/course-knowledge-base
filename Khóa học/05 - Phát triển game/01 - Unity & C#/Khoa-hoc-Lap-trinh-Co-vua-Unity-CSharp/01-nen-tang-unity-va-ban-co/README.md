# Module 01. Nền tảng Unity và bàn cờ

> **Đầu ra:** Tạo scene bàn cờ 3D, sinh đủ quân, tương tác bằng chuột và cập nhật mảng dữ liệu nhất quán.

## 2. Quy trình học và thực hành

1. Đọc từng bài theo thứ tự và chạy bài thử trong Unity.
2. Đối chiếu phần **Checkpoint** sau mỗi bài; ghi lại lỗi và cách sửa.
3. Commit code sau mỗi mốc có thể chạy ổn định.
4. Giữ bản scene và prefab để kiểm thử hồi quy khi thêm logic mới.

## 3. Tiêu chí hoàn tất module

- Trình bày được cơ chế cốt lõi mà không cần nhìn mã.
- Hoàn thành các checkpoint trong mọi bài.
- Trả lời đúng tối thiểu 4/5 câu trắc nghiệm mỗi bài.
- Không có lỗi làm thay đổi state cờ ngoài thao tác chủ đích.
