# Module 03 - Snow Surfer

- Xây game trượt tuyết dựa trên physics 2D.
- Dùng Sprite Shape, Edge Collider, Surface Effector 2D và particle effect.
- Quản lý scene, crash, finish line, timer, power-up và UI responsive.

## Kiến thức chính

- Sprite Shape để vẽ đường trượt mềm.
- Edge Collider và Surface Effector 2D để tạo chuyển động trượt.
- Input System mới để điều khiển xoay.
- `SceneManagement` và `Invoke()` để reload scene sau delay.
- Particle System cho tuyết, crash hoặc power-up.
- ScriptableObject để tách dữ liệu power-up khỏi logic.
- Anchor, pivot và layout group cho UI linh hoạt.

## Bài tập thực hành

- Tạo một đường trượt mới dài tối thiểu 60 giây chơi.
- Thêm power-up tăng tốc và power-up giảm trọng lực.
- Thêm timer hiển thị thời gian hoàn thành.
- Thêm nút restart và menu đơn giản.

## Điều kiện hoàn thành

- Nhân vật trượt ổn định, không xuyên địa hình.
- Crash và finish line hoạt động đúng.
- Particle bật/tắt đúng trạng thái.
- UI không lệch khi đổi độ phân giải.
