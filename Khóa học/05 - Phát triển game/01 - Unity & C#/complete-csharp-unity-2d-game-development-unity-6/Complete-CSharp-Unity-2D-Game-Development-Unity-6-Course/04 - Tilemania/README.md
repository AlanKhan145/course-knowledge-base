# Module 04 - Tilemania

Dự án game platformer 2D - 41 bài, 5 giờ 48 phút.

## Mục tiêu

- Xây platformer 2D có chạy, nhảy, leo thang, enemy, hazard, coin và shooting.
- Dùng Tilemap, Rule Tile, Animator, Cinemachine và hệ thống scene.
- Tạo score/lives persistent bằng Singleton và Scene Persist.

## Kiến thức chính

- Tilemap, Rule Tile và Sorting Layer.
- Animator state, transition và điều khiển animation bằng code.
- Platformer movement: chạy, nhảy, flip sprite, leo thang.
- Composite Collider và Physics Material 2D.
- Cinemachine Follow, Confiner và State-Driven Camera.
- Enemy patrol, hazard, bullet và coin pickup.
- Sound effect, level loading, coroutine, Singleton và scene persistence.

## Bài tập thực hành

- Tạo 2 level hoàn chỉnh có độ khó tăng dần.
- Thêm checkpoint hoặc cửa bí mật.
- Thêm enemy có hành vi khác enemy mặc định.
- Thêm màn hình win khi hoàn thành level cuối.

## Điều kiện hoàn thành

- Người chơi không thể nhảy tường ngoài ý muốn.
- Ladder hoạt động đúng và không trượt.
- Score/lives không reset sai khi chuyển scene.
- Enemy, bullet, coin và hazard không sinh lỗi Console.
