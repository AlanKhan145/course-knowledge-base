## Cách học

1. Học sau khi đã nắm Ren'Py cơ bản và Python cho Ren'Py.
2. Chạy thử project hoàn chỉnh trước để hiểu mục tiêu rhythm game.
3. Học module 01 để hiểu screen, displayable và Creator-Defined Displayable.
4. Học module 02-03 thật chậm vì đây là phần render thời gian thực, input PyGame và scoring.
5. Dùng PRACTICE_CHECKLIST.md để kiểm tra từng mảnh: beat map, track, notes, key events, HUD và return result.
