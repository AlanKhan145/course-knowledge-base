## Nội dung bài học

## Scoring chi tiết

```text
Sai lệch <= 0.08 giây -> Perfect
Sai lệch <= 0.16 giây -> Great
Sai lệch <= 0.30 giây -> Good
Sai lệch > 0.30 giây -> Miss
```
