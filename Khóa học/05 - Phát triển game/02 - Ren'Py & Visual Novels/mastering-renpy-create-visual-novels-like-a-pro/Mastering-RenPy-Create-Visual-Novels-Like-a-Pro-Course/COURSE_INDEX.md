# Course Index

## Mastering Ren'Py: Create Visual Novels Like a Pro

Khóa học này phù hợp nếu bạn muốn làm một visual novel ngắn bằng Ren'Py theo cách thực hành: cài công cụ, tạo project, viết hội thoại, thêm nhân vật/background/âm thanh, tạo lựa chọn tương tác, dùng Python để lưu điểm quan hệ, rồi phân nhánh thành nhiều ending.

## Mục tiêu đầu ra

Sau khóa học, bạn nên có thể:

- Cài đặt Ren'Py và dùng Ren'Py Launcher để tạo, mở, cấu hình và build project.
- Dùng VS Code để chỉnh sửa script Ren'Py.
- Khai báo nhân vật, viết dialogue, hiển thị sprite và background.
- Tạo menu lựa chọn và chuyển hướng qua label.
- Quản lý điểm quan hệ bằng biến Python.
- Tạo screen trạng thái quan hệ với frame và vbox.
- Tích hợp âm thanh, video hoặc hiệu ứng đơn giản vào scene.
- Viết minigame logic bằng Python trong Ren'Py.
- Xây dựng nhiều ending dựa trên điểm quan hệ và flag sự kiện.

## Đường học khuyến nghị

1. Hoàn thành module 01 trong một buổi ngắn, nhưng ghi kỹ đường dẫn project và cách mở script.
2. Ở các bài 02.01-02.04, tập trung vào nền móng: character, scene, label, menu và biến quan hệ.
3. Ở các bài 02.05-02.08, lập bảng theo dõi flag và điểm để tránh rối logic.
4. Ở bài minigame, tách rõ phần giao diện nhập đáp án và phần Python kiểm tra đáp án.
5. Trước bài ending, tạo một ma trận điều kiện để biết điểm/flag nào dẫn tới kết thúc nào.
