# Module 02 - Creating Your First Game

## Tổng quan

Module này xây một visual novel học viện với Alex, Emma và Lily. Người chơi lựa chọn cách phản ứng trong các scene, điểm quan hệ thay đổi theo lựa chọn, minigame Mystery Letter ảnh hưởng nội dung và cuối game mở khóa ending tương ứng.
