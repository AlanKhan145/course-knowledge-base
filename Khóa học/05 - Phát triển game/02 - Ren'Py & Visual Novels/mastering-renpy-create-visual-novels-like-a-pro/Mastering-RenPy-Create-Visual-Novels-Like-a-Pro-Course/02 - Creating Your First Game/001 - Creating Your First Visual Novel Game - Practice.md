# 001 - Creating Your First Visual Novel Game

## Module

Module 02 - Creating Your First Game

## Thời lượng

12 phút 43 giây

## Nội dung bài học

Bài học bắt đầu project visual novel: tạo phần mở đầu, khai báo nhân vật, viết lời thoại, hiển thị nhân vật/background, thêm sprite, thêm âm thanh, tạo biến điểm quan hệ và đưa ra lựa chọn đầu tiên cho người chơi.

## Mục tiêu sau bài học

- Tạo được opening scene cơ bản.
- Khai báo và dùng nhân vật trong dialogue.
- Hiểu cách `scene`, `show`, audio và `menu` phối hợp trong một scene.
- Tạo nền tảng cho cốt truyện phân nhánh.

## Ghi chú script

```renpy
define a = Character("Alex")
define e = Character("Emma")

default alex_relationship = 0
default emma_relationship = 0
default lily_relationship = 0
```

## Việc cần làm trong Ren'Py

- [ ] Tạo label mở đầu.
- [ ] Thêm background học viện.
- [ ] Thêm sprite Alex và Emma.
- [ ] Thêm nhạc hoặc sound effect cho scene.
- [ ] Tạo menu lựa chọn ảnh hưởng điểm quan hệ.

## Kiểm tra nhanh

- [ ] Game chạy từ `start` không lỗi.
- [ ] Nhân vật hiện đúng tên khi nói.
- [ ] Lựa chọn đầu tiên thay đổi biến quan hệ đúng như mong muốn.
