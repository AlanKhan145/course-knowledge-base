# 006 - Adding a Third Character: Lily

## Module

Module 02 - Creating Your First Game

## Thời lượng

10 phút 9 giây

## Nội dung bài học

Bài học thêm nhân vật thứ ba là Lily: khai báo character, thêm dialogue, sprite, biểu cảm, biến điểm quan hệ riêng và mở rộng màn hình trạng thái quan hệ.

## Mục tiêu sau bài học

- Thêm nhân vật mới vào project đang có.
- Liên kết biểu cảm với hình ảnh nhân vật.
- Mở rộng biến quan hệ và relationship screen.
- Chuẩn bị route tình cảm mới.

## Ghi chú script

```renpy
define l = Character("Lily")

default lily_relationship = 0
```

## Việc cần làm trong Ren'Py

- [ ] Khai báo Lily.
- [ ] Thêm sprite và biểu cảm của Lily.
- [ ] Thêm điểm Lily vào relationship screen.
- [ ] Tạo hai lựa chọn tương tác với Lily.
- [ ] Tăng hoặc giảm điểm Lily theo quyết định người chơi.

## Kiểm tra nhanh

- [ ] Lily hiển thị đúng sprite.
- [ ] Relationship screen có đủ Alex, Emma, Lily.
- [ ] Điểm Lily không dùng nhầm biến của Alex hoặc Emma.
