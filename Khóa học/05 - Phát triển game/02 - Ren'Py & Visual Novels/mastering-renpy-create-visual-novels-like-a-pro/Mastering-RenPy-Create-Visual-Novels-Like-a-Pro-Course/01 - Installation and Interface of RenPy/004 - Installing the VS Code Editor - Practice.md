## Nội dung bài học

Bài học hướng dẫn tải và cài Visual Studio Code, mở ứng dụng lần đầu, cấp quyền cần thiết và mở thư mục project Ren'Py để chỉnh mã nguồn.

## Mục tiêu sau bài học

- Cài được VS Code.
- Mở được thư mục project Ren'Py trong VS Code.
- Biết nơi chỉnh script của project mẫu.

## Việc cần làm

- [ ] Tải VS Code từ trang chính thức.
- [ ] Cài VS Code trên Windows hoặc macOS.
- [ ] Mở project Ren'Py bằng VS Code.
- [ ] Mở file `script.rpy`.
- [ ] Chạy lại game từ Launcher sau khi chỉnh một dòng dialogue nhỏ.

## Kiểm tra nhanh

- [ ] VS Code hiển thị cây thư mục project.
- [ ] File `.rpy` mở được và có thể chỉnh sửa.
- [ ] Thay đổi trong script xuất hiện khi launch game.
