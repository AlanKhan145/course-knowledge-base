Module 01 - Installation and Interface of Ren'Py

## Thời lượng

1 phút 21 giây

## Nội dung bài học

Bài học hướng dẫn cài đặt Ren'Py trên Windows và macOS, chọn đường dẫn cài đặt, xử lý cảnh báo bảo mật của hệ điều hành và khởi động Ren'Py lần đầu.

Ghi chú: mô tả tự động trên Udemy có một số chỗ ghi thành "Wren Pi", nhưng nội dung thực tế đang nói về Ren'Py.

## Mục tiêu sau bài học

- Cài được Ren'Py trên máy cá nhân.
- Mở được Ren'Py Launcher.
- Chuẩn bị môi trường để bắt đầu phát triển game.

## Việc cần làm

- [ ] Chạy file cài đặt hoặc giải nén Ren'Py.
- [ ] Đặt Ren'Py ở thư mục dễ truy cập.
- [ ] Mở Ren'Py Launcher lần đầu.
- [ ] Ghi lại vị trí thư mục Ren'Py và thư mục project.

## Kiểm tra nhanh

- [ ] Launcher mở không báo lỗi.
- [ ] Có thể thấy danh sách project hoặc nút tạo project mới.
- [ ] Hệ điều hành không còn chặn ứng dụng sau khi cấp quyền.
