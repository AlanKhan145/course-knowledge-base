## Cách học

1. Mở COURSE_INDEX.md để xem vai trò của khóa trong lộ trình Ren'Py.
2. Học từng khái niệm Python trong Google Colab trước.
3. Chuyển cùng khái niệm sang file `.rpy` tương ứng trong project Ren'Py.
4. Dùng PRACTICE_CHECKLIST.md để theo dõi biến, cấu trúc dữ liệu, điều kiện, vòng lặp, hàm và class.
5. Sau khóa học, áp dụng vào affection system, inventory, lựa chọn có điều kiện hoặc minigame.
