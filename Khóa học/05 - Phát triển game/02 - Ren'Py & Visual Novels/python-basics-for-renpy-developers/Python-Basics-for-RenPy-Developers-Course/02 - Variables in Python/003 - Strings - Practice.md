## Nội dung bài học

Học chuỗi ký tự: khai báo bằng dấu nháy, gán cho biến, ghép chuỗi, đưa biến vào lời thoại, so sánh chuỗi và dùng chuỗi làm dữ liệu cho giao diện/hội thoại.

## Ví dụ Ren'Py

```renpy
default player_name = "Khanh"

label start:
    "Tên của tôi là [player_name]."
```

## Ứng dụng

- Nhập tên nữ chính.
- Lưu tên route đang chơi.
- Lưu địa điểm hiện tại.
- Hiển thị tên nhân vật trong dialogue box.
- Thay thế thông tin động trong lời thoại.
