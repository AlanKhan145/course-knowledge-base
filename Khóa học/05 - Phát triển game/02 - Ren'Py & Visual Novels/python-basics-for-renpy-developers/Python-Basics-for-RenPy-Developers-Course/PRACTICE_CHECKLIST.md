# Practice Checklist

## Python trong Ren'Py

- [ ] Viết Python một dòng bằng `$`.
- [ ] Viết khối nhiều dòng bằng `python:`.
- [ ] Viết hàm/class trong `init python:`.
- [ ] Kiểm tra biến trong Developer Console.

## Variables

- [ ] Tạo string cho tên người chơi.
- [ ] Hiển thị string trong dialogue bằng `[player_name]`.
- [ ] Tạo int cho affection/money/score.
- [ ] Tạo float cho energy/progress nếu cần.
- [ ] Tạo Boolean flag cho sự kiện đã xảy ra.

## Data Structures

- [ ] Tạo list inventory.
- [ ] Thêm item bằng `append`.
- [ ] Kiểm tra item bằng `in`.
- [ ] Tạo set unlocks.
- [ ] Thêm unlock bằng `add`.
- [ ] Tạo dictionary affection nhiều nhân vật.
- [ ] Cập nhật dictionary bằng key.

## Statements

- [ ] Viết `if`.
- [ ] Viết `elif` và `else`.
- [ ] Kết hợp điều kiện bằng `and`, `or`, `not`.
- [ ] Ẩn/hiện lựa chọn menu bằng điều kiện.
- [ ] Viết vòng lặp `for`.
- [ ] Viết vòng lặp `while` có điều kiện dừng.
- [ ] Lặp qua `.items()` của dictionary.

## Functions and Classes

- [ ] Viết function có parameter.
- [ ] Viết function có `return`.
- [ ] Gọi function từ script Ren'Py.
- [ ] Tạo class có `__init__`.
- [ ] Tạo object từ class.
- [ ] Viết method cập nhật trạng thái object.

## Mini Systems

- [ ] Affection system nhiều nhân vật.
- [ ] Inventory cơ bản.
- [ ] Lựa chọn có điều kiện.
- [ ] Ending condition.
- [ ] Minigame nhập đáp án có số lần thử.
- [ ] Class quản lý nhân vật hoặc item.
