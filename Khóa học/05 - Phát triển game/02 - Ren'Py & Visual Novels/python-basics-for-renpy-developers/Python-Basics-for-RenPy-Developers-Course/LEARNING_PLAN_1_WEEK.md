# Learning Plan - 1 Week

## Ngày 1 - Python trong Ren'Py

- Học module 01.
- Mở Google Colab notebook và project Ren'Py mẫu.
- Thử `$ variable = value`, khối `python:` và `init python:`.
- Mở Developer Console để kiểm tra giá trị biến.

## Ngày 2 - Biến cơ bản

- Học bài Strings và Numbers.
- Tạo `player_name`, `current_route`, `money`, `energy`, affection score.
- Áp dụng biến vào dialogue và menu.

## Ngày 3 - Boolean và data structures

- Học Booleans, Lists và Sets.
- Tạo event flags, inventory list và unlocked CG set.
- Test membership bằng `in`.

## Ngày 4 - Dictionary

- Học Dictionaries.
- Tạo bảng affection cho nhiều nhân vật.
- Thử tăng/giảm điểm và kiểm tra route bằng key.

## Ngày 5 - Điều kiện và vòng lặp

- Học Conditionals và Loops.
- Tạo lựa chọn có điều kiện trong menu.
- Tạo minigame nhập mật mã có số lần thử giới hạn.

## Ngày 6 - Iterables và functions

- Học Looping Over Iterables và Functions.
- Lặp qua inventory/affection.
- Viết helper `change_affection`, `has_item`, `can_unlock_route`.

## Ngày 7 - Classes và ứng dụng nhỏ

- Học Classes and OOP và Conclusion.
- Tạo class `LoveInterest` hoặc `Item`.
- Ghép lại thành một mini-demo: nhận item, tăng affection, mở lựa chọn và kiểm tra ending.
