# 006 - Translucency & Transparency

**Module:** Advanced Rendering  
**Roadmap topic:** Translucency & Transparency  
**Thời lượng gợi ý:** 20–40 phút  
**Nguồn:** [Game Developer Roadmap](https://roadmap.sh/game-developer) · [Sơ đồ PDF](https://roadmap.sh/pdfs/roadmaps/game-developer.pdf)

## Nội dung cốt lõi

Transparency truyền hoặc pha trộn ánh sáng qua bề mặt; translucency cho ánh sáng xuyên tán xạ trong vật liệu.

## Bài thực hành

So sánh alpha blending với mô phỏng translucency trên kính và lá; ghi vấn đề thứ tự render.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
