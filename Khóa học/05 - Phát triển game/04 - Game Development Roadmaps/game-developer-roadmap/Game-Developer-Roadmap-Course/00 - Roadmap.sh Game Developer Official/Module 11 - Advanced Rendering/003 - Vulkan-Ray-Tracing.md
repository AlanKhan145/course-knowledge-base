## Nội dung cốt lõi

Vulkan ray tracing mở rộng Vulkan bằng acceleration structures, ray-tracing pipelines và synchronization explicit.

## Bài thực hành

Vẽ vòng đời acceleration structure cùng barrier cần thiết trong một frame Vulkan ray tracing.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
