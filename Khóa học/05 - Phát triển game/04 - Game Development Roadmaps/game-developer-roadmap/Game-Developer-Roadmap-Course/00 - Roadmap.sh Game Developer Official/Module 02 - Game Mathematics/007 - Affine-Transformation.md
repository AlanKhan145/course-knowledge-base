# 007 - Affine Transformation

**Module:** Game Mathematics  
**Roadmap topic:** Affine Transformation  
**Thời lượng gợi ý:** 20–40 phút  
**Nguồn:** [Game Developer Roadmap](https://roadmap.sh/game-developer) · [Sơ đồ PDF](https://roadmap.sh/pdfs/roadmaps/game-developer.pdf)

## Nội dung cốt lõi

Phép biến đổi affine kết hợp tuyến tính với tịnh tiến và giữ đường thẳng song song, phù hợp cho transform object.

## Bài thực hành

Dùng ma trận affine biến đổi một sprite hoặc mesh qua translate, rotate, scale và xác nhận thứ tự phép biến đổi.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
