# 002 - Unreal Engine

**Module:** Game Engine  
**Roadmap topic:** Unreal Engine  
**Thời lượng gợi ý:** 20–40 phút  
**Nguồn:** [Game Developer Roadmap](https://roadmap.sh/game-developer) · [Sơ đồ PDF](https://roadmap.sh/pdfs/roadmaps/game-developer.pdf)

## Nội dung cốt lõi

Unreal Engine kết hợp C++, Blueprints, hệ actor/component, editor và công cụ đồ họa hướng đến game 3D quy mô lớn.

## Bài thực hành

Tạo một gameplay loop nhỏ bằng Blueprint hoặc C++; xác định phần nào cần code và phần nào phù hợp với visual scripting.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
