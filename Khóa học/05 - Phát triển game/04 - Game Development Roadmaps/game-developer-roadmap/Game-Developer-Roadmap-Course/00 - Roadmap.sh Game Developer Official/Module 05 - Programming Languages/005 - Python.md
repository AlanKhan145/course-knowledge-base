## Nội dung cốt lõi

Python thường phù hợp cho tool, pipeline asset, automation, prototype và kiểm thử hơn là vòng lặp game thời gian thực chính.

## Bài thực hành

Viết tool đọc manifest asset, phát hiện file thiếu và tạo báo cáo để tích hợp vào quy trình build.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
