# 029 - DBVT

**Module:** Game Physics

## Nội dung cốt lõi

Dynamic Bounding Volume Tree tổ chức bounding volume động thành cây để truy vấn cặp va chạm và vùng lân cận.

## Bài thực hành

Vẽ cây bao động cho các object di chuyển và theo dõi cập nhật khi một object rời khỏi node cha.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
