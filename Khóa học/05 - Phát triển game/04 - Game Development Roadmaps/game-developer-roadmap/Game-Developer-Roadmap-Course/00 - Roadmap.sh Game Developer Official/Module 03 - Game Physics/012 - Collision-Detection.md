# 012 - Collision Detection

**Module:** Game Physics  
**Roadmap topic:** Collision Detection  
**Thời lượng gợi ý:** 20–40 phút  
**Nguồn:** [Game Developer Roadmap](https://roadmap.sh/game-developer) · [Sơ đồ PDF](https://roadmap.sh/pdfs/roadmaps/game-developer.pdf)

## Nội dung cốt lõi

Collision detection tìm cặp vật giao nhau, xác định contact và cung cấp thông tin để gameplay hoặc solver phản hồi.

## Bài thực hành

Tạo bài test collider cho circle, box và capsule; ghi lại false positive, false negative và contact normal.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
