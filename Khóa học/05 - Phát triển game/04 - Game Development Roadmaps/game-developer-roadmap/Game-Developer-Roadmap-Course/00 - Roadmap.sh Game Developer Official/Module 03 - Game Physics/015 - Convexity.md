# 015 - Convexity

**Module:** Game Physics  
**Roadmap topic:** Convexity  
**Thời lượng gợi ý:** 20–40 phút  
**Nguồn:** [Game Developer Roadmap](https://roadmap.sh/game-developer) · [Sơ đồ PDF](https://roadmap.sh/pdfs/roadmaps/game-developer.pdf)

## Nội dung cốt lõi

Convexity quyết định nhiều thuật toán va chạm có dùng được hay không; đoạn nối giữa hai điểm trong convex shape luôn nằm trong shape.

## Bài thực hành

Phân loại một tập polygon lồi/lõm và cho thấy thuật toán hỗ trợ convex shape xử lý từng trường hợp.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
