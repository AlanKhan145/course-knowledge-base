# 024 - OBB

**Module:** Game Physics

## Nội dung cốt lõi

Oriented Bounding Box là hộp bao có thể xoay theo object, chặt hơn AABB nhưng phép kiểm tra thường tốn hơn.

## Bài thực hành

So sánh OBB và AABB bao quanh một object dài đang xoay; đo số va chạm giả.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
