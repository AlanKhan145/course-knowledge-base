# 003 - Moment of Inertia

**Module:** Game Physics

## Nội dung cốt lõi

Moment of inertia đo mức kháng lại gia tốc góc quanh trục và phụ thuộc khối lượng phân bố cách trục quay.

## Bài thực hành

So sánh hai vật cùng khối lượng nhưng phân bố khác nhau khi áp cùng torque.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
