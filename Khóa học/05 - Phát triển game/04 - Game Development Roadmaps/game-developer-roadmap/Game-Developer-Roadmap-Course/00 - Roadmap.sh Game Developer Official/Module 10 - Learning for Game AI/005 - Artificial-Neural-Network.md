# 005 - Artificial Neural Network

**Module:** Learning for Game AI

## Nội dung cốt lõi

Artificial neural network kết hợp neuron, trọng số và activation để xấp xỉ ánh xạ từ input sang output.

## Bài thực hành

Huấn luyện mạng nhỏ dự đoán một hành động từ feature giả lập; theo dõi loss và kiểm tra trên dữ liệu chưa thấy.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
