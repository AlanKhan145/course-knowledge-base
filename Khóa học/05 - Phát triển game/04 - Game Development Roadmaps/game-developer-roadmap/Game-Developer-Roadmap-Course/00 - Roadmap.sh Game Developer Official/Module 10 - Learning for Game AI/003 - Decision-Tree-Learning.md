# 003 - Decision Tree Learning

**Module:** Learning for Game AI  
**Roadmap topic:** Decision Tree Learning  
**Thời lượng gợi ý:** 20–40 phút  
**Nguồn:** [Game Developer Roadmap](https://roadmap.sh/game-developer) · [Sơ đồ PDF](https://roadmap.sh/pdfs/roadmaps/game-developer.pdf)

## Nội dung cốt lõi

Decision tree learning học các phép chia feature từ dữ liệu có nhãn để dự đoán lớp hoặc giá trị.

## Bài thực hành

Huấn luyện cây nhỏ dự đoán hành động NPC từ khoảng cách, máu và line of sight; đọc các nhánh kết quả.

Ghi lại một ảnh, đoạn code, sơ đồ hoặc phép đo chứng minh kết quả. Nếu engine đã cung cấp tính năng tương đương, hãy quan sát dữ liệu đầu vào/đầu ra và giới hạn của nó.
