# Từ điển thuật ngữ Pixel Art & Game VFX

| Thuật ngữ | Ý nghĩa |
|---|---|
| Pixel Art | Tạo hình bằng đơn vị pixel được kiểm soát có chủ đích |
| Sprite | Hình 2D của nhân vật/đối tượng/hiệu ứng |
| Frame | Mốc hình ảnh trên Timeline |
| Cel | Nội dung của một lớp tại một frame |
| Layer | Lớp nội dung chỉnh sửa độc lập |
| Timeline | Trục thời gian cho animation |
| Onion Skin | Bóng mờ frame lân cận để căn chuyển động |
| Animation Tag | Nhãn đánh dấu khoảng frame thuộc một hoạt ảnh |
| Key Pose / Keyframe | Tư thế/mốc cốt lõi của hành động |
| In-between | Khung trung gian nối key poses |
| Anticipation | Động tác báo trước, tích lực |
| Follow-through | Chuyển động tiếp diễn của phần phụ khi phần chính dừng |
| Overshoot | Vượt qua vị trí đích trước khi hồi lại |
| Smear frame | Khung kéo giãn để diễn đạt tốc độ rất cao |
| Impact / Hit Flash | Điểm va chạm/chớp sáng nhấn lực |
| Recovery | Giai đoạn nhân vật trở về trạng thái trung tính |
| Particle System | Bộ phát và mô phỏng nhiều hạt/ảnh nhỏ |
| Burst | Phát nhiều hạt ở một thời điểm xác định |
| Rate over Time | Mật độ sinh hạt liên tục theo thời gian |
| Lifetime | Thời gian tồn tại của hạt |
| Trail | Vệt kéo theo hạt hoặc vật chuyển động |
| Sorting Layer | Thứ tự nhóm hiển thị 2D |
| VFX Graph | Đồ thị hiệu ứng hạt của Unity |
| Shader Graph | Đồ thị dựng vật liệu/shader |
| Voronoi | Dạng hoa văn thủ tục, thường dùng tạo nhiễu cho VFX |
| Linked Mesh (Spine) | Mesh liên kết dùng chung dữ liệu mesh gốc |
| Bone / Attachment | Xương điều khiển và hình ảnh gắn vào xương |
| Atlas | Texture gộp nhiều sprite để tiết kiệm tài nguyên |
| Overdraw | Một pixel màn hình bị vẽ chồng nhiều lần, gây tốn GPU |
| Finisher | Hiệu ứng kết thúc hạ gục mục tiêu |
| Synergy | Hiệu ứng cộng hưởng nhiều thuộc tính/tộc/hệ |

> Bản phiên âm có một số lỗi như “test” thay cho “tag”, “ảnh ảo” thay cho Onion Skin, “gạch chéo” thay cho slash; tài liệu dùng thuật ngữ chuyên môn chuẩn và giữ liên hệ với ý bài giảng.
