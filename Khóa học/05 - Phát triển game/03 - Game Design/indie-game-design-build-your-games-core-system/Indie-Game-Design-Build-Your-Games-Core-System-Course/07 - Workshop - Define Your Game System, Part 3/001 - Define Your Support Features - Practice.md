## Module

Module 07 - Workshop - Define Your Game System, Part 3

## Nội dung bài học

Hoàn thiện game system bằng cách lựa chọn game mode, cấu trúc, giao diện và phương pháp kể chuyện phù hợp.

## Vai trò của bài học

Bài này thuộc khóa **Indie Game Design: Build Your Game's Core System**. Dùng bài này như ghi chú học kèm video: nắm ý chính, áp dụng ngay vào ý tưởng game của bạn, rồi ghi lại quyết định thiết kế, trade-off và câu hỏi còn mở.

## Mục tiêu sau bài học

- Hiểu bài **Define Your Support Features** đang đóng góp gì cho game system.
- Chuyển khái niệm trong bài thành một quyết định thiết kế cụ thể.
- Ghi lại ít nhất một giả định về người chơi, thử thách, động lực hoặc trải nghiệm mong muốn.
- Cập nhật tài liệu game system nếu bài học làm thay đổi core gameplay, engagement gameplay hoặc support features.

## Kiến thức nền của module

- Core gameplay
- Engagement gameplay
- Support features
- Checklist kiểm tra mâu thuẫn
- Checklist kiểm tra giá trị thiết kế

## Checklist thiết kế

- [ ] Quyết định thiết kế có liên hệ trực tiếp với trải nghiệm người chơi.
- [ ] Quyết định này không mâu thuẫn với core gameplay đã chọn.
- [ ] Có cách prototype hoặc playtest để kiểm chứng.
- [ ] Có tiêu chí để biết thiết kế đang hoạt động tốt hay chưa.

## Câu hỏi ôn tập

1. Khái niệm chính của bài này là gì?
2. Nó ảnh hưởng đến challenge, reward, progression, GUI hoặc narrative như thế nào?
3. Nếu áp dụng sai, người chơi có thể gặp vấn đề gì?
4. Bạn sẽ kiểm chứng bài học này bằng prototype, playtest hay checklist nào?
