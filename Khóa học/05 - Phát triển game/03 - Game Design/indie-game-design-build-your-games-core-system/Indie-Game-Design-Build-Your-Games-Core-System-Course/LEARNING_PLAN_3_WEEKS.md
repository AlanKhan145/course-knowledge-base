# Learning Plan 3 Weeks

## Tuần 1 - Core Gameplay

- Hoàn thành Module 01-03.
- Mục tiêu: xác định challenge, camera, controls, feedback, juiciness và core gameplay.
- Bài tập: viết phần Core Gameplay trong `GAME_SYSTEM_TEMPLATE.md`.

## Tuần 2 - Engagement Gameplay

- Hoàn thành Module 04-05.
- Mục tiêu: thiết kế reward, renewal, difficulty curve, progression, core loop, meta loop và pacing.
- Bài tập: bổ sung Engagement Gameplay vào game system và ghi ít nhất 3 rủi ro cần playtest.

## Tuần 3 - Support Features và hoàn thiện hệ thống

- Hoàn thành Module 06-08.
- Mục tiêu: chọn game modes, structure, GUI, narrative approach và rà soát checklist cuối.
- Bài tập: hoàn thiện bản game system 3 lớp và chuẩn bị kế hoạch prototype đầu tiên.
