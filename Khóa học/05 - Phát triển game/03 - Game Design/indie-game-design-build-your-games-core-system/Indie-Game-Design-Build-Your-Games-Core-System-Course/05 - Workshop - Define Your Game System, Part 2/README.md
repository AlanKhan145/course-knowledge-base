# Module 05 - Workshop - Define Your Game System, Part 2

Thực hành xác định game system - Phần 2 - 1 bài, 11 phút.

## Mục tiêu

Module workshop này bổ sung reward, renewal, difficulty, progression, loop và pacing vào game system.

## Bài học

- [ ] [001 - Define Your Engagement Gameplay](<001 - Define Your Engagement Gameplay.md>) - `11:15`

## Kiến thức chính

- Phần thưởng ngắn hạn và dài hạn
- Cơ chế làm mới trải nghiệm
- Đường cong độ khó
- Tiến triển của người chơi
- Các vòng lặp gameplay
- Nhịp độ tổng thể

## Sản phẩm thực hành

Phần Engagement Gameplay trong tài liệu game system.

## Bài tập thực hành

- Áp dụng bài học vào một ý tưởng game cụ thể
- Ghi lại quyết định thiết kế trong Decision Log
- Tìm một rủi ro hoặc giả định cần playtest
- Cập nhật checklist game system sau bài học

## Điều kiện hoàn thành

- Có ít nhất một quyết định thiết kế được ghi lại.
- Có rủi ro hoặc giả định cần prototype/playtest.
- Thiết kế mới không mâu thuẫn với các lớp game system đã xác định.
- Checklist module được cập nhật trước khi chuyển module tiếp theo.
