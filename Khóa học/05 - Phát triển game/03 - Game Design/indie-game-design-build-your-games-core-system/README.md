## Cách học

1. Mở [COURSE_INDEX.md](Indie-Game-Design-Build-Your-Games-Core-System-Course/COURSE_INDEX.md) để xem toàn bộ khóa.
2. Học theo thứ tự module vì ba lớp thiết kế được xây chồng lên nhau: core gameplay, engagement gameplay và support features.

4. Dùng [GAME_SYSTEM_TEMPLATE.md](Indie-Game-Design-Build-Your-Games-Core-System-Course/GAME_SYSTEM_TEMPLATE.md) để xây tài liệu game system cho dự án indie.
