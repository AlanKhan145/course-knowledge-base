# Module 01 - Introduction - Giới thiệu BI Analyst

## Mục tiêu module
Hiểu BI Analyst làm gì, kỹ năng cần có và vai trò của BI trong quyết định kinh doanh.

## Thực hành trọng tâm
Chọn một công ty/sản phẩm quen thuộc và viết BI có thể giúp quyết định kinh doanh nào tốt hơn.

## Output sau module
- BI role map and stakeholder value note
- Ghi chú decision/report có thể chia sẻ với stakeholder
- Danh sách câu hỏi dữ liệu, rủi ro metric hoặc việc cần phân tích tiếp
