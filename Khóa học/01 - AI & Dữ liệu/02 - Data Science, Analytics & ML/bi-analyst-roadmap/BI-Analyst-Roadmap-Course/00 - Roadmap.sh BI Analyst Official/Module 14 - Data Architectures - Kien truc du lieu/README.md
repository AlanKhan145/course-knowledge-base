# Module 14 - Data Architectures - Kiến trúc dữ liệu

## Mục tiêu module
Hiểu data warehouse, lake, mart, cloud BI ecosystem và data modeling cho BI.

## Thực hành trọng tâm
Thiết kế star schema đơn giản cho dashboard bán hàng, marketing hoặc finance.

## Output sau module
- BI data model with fact/dimension tables
- Ghi chú decision/report có thể chia sẻ với stakeholder
- Danh sách câu hỏi dữ liệu, rủi ro metric hoặc việc cần phân tích tiếp
