# Module 06 - BI Core Skills - Kỹ năng cốt lõi của BI

## Mục tiêu module
Có kỹ năng cốt lõi: SQL, database, EDA, data cleaning và transformation.

## Thực hành trọng tâm
Viết SQL truy vấn KPI, làm sạch dữ liệu lỗi và tạo bảng phân tích sẵn cho dashboard.

## Output sau module
- SQL notebook, EDA checklist and data cleaning workflow
- Ghi chú decision/report có thể chia sẻ với stakeholder
- Danh sách câu hỏi dữ liệu, rủi ro metric hoặc việc cần phân tích tiếp

## Checklist hoàn thành
- [ ] Đọc toàn bộ bài học trong module
- [ ] Tạo ít nhất một artifact thực hành
- [ ] Liên hệ nội dung với một business question thật
- [ ] Ghi lại 3 điều sẽ áp dụng trong công việc BI Analyst
