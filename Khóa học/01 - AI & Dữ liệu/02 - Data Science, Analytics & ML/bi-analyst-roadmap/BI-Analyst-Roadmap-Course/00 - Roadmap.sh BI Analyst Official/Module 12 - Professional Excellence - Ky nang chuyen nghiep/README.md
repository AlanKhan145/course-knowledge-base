# Module 12 - Professional Excellence - Kỹ năng chuyên nghiệp

## Mục tiêu module
Biết giao tiếp insight, kể chuyện bằng dữ liệu và làm việc với stakeholder.

## Thực hành trọng tâm
Viết executive summary 1 trang từ một dashboard hoặc phân tích dữ liệu.

## Output sau module
- Executive summary and stakeholder presentation deck outline
- Ghi chú decision/report có thể chia sẻ với stakeholder
- Danh sách câu hỏi dữ liệu, rủi ro metric hoặc việc cần phân tích tiếp
