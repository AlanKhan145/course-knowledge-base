# Module 16 - Building Your Portfolio - Xây dựng portfolio

## Mục tiêu module
Biết xây portfolio BI Analyst bằng project end-to-end, dashboard và case study.

## Thực hành trọng tâm
Hoàn thành một case study portfolio gồm problem, data, analysis, dashboard và business impact.

## Output sau module
- End-to-end portfolio case study
- Ghi chú decision/report có thể chia sẻ với stakeholder
- Danh sách câu hỏi dữ liệu, rủi ro metric hoặc việc cần phân tích tiếp
