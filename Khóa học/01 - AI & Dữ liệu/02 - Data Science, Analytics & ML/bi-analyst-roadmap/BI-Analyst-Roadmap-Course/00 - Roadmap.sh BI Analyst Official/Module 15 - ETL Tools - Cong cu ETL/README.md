# Module 15 - ETL Tools - Công cụ ETL

## Mục tiêu module
Biết ETL basics, công cụ ETL và cách thiết kế pipeline dữ liệu đáng tin cậy.

## Thực hành trọng tâm
Thiết kế pipeline ETL: source, transform, schedule, quality check và failure handling.

## Output sau module
- ETL pipeline design and data quality checks
- Ghi chú decision/report có thể chia sẻ với stakeholder
- Danh sách câu hỏi dữ liệu, rủi ro metric hoặc việc cần phân tích tiếp
