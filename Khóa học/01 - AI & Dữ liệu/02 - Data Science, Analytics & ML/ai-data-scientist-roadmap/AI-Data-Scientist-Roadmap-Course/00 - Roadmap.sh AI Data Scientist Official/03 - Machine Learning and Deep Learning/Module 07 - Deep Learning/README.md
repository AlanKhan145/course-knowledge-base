# Module 07 - Deep Learning

**Course:** 03 - Machine Learning and Deep Learning

This module has 24 lessons from the AI & Data Scientist roadmap.

## Outcome

Understand neural networks, CNNs, RNN/LSTM, Transformers and transfer learning at a practical level.

## Project

Mini project: Image Classification comparing a small CNN and transfer learning with accuracy and confusion matrix.

## Content Groups

- [Neural Network Foundations](01-NN/README.md) (Lessons 001-005)
- [Training and Optimization](02-Train/README.md) (Lessons 006-008)
- [Core Architectures](03-Arch/README.md) (Lessons 009-013)
- [Attention and Transformers](04-Attn/README.md) (Lessons 014-017)
- [Computer Vision Applications](05-Vision/README.md) (Lessons 018-020)
- [Sequence and Transfer Learning Applications](06-SeqTL/README.md) (Lessons 021-024)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
