# Module 01 - Mathematics for AI and Data Science

**Course:** 01 - Math, Statistics and Econometrics

This module has 19 lessons from the AI & Data Scientist roadmap (~24 min each, ~7.6 hours total).

## Outcome

Understand the math language behind vectors, optimization, gradients, PCA, neural networks and embeddings.

## Project

Mini project: Gradient Descent from Scratch with MSE loss and a loss curve over epochs.

## Content Groups

- [Linear Algebra Foundations](01-Algebra/README.md) (Lessons 001-007)
- [Calculus Foundations](02-Calc/README.md) (Lessons 008-016)
- [Optimization for Machine Learning](03-Optim/README.md) (Lessons 017-019)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
