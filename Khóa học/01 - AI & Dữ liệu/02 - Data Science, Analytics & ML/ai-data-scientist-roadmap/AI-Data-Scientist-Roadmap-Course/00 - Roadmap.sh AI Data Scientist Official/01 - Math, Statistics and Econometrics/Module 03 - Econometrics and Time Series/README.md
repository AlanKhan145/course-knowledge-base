# Module 03 - Econometrics and Time Series

**Course:** 01 - Math, Statistics and Econometrics

This module has 18 lessons from the AI & Data Scientist roadmap (~22 min each, ~6.6 hours total).

## Outcome

Model relationships and time-dependent data with regression, diagnostics, ARIMA and forecasting workflows.

## Project

Mini project: Sales Forecasting with trend/seasonality analysis and a baseline or ARIMA forecast.

## Content Groups

- [Regression Foundations](01-Regress/README.md) (Lessons 001-006)
- [Regression Diagnostics and Distributions](02-DiagDist/README.md) (Lessons 007-009)
- [Time Series Components](03-TSParts/README.md) (Lessons 010-013)
- [Stationarity and Autocorrelation](04-Station/README.md) (Lessons 014-016)
- [Forecasting Models and Pipeline](05-Forecast/README.md) (Lessons 017-018)

## How to Study This Module

- Go through the lessons in order if you're just starting out.
- For each lesson, write down 3 key takeaways and 1 real data/ML example.
- Build a small artifact: a notebook, SQL query, chart, model metric, API endpoint, Dockerfile, or portfolio note.
