# 003 - PDF for entire course

## Section

VS Code & GitHub Repo Setup

## Duration

1 minute

## Main Idea

Points students to the downloadable PDF resource that contains the full course notes, diagrams, and reference material for offline use.

## What the PDF Contains

- Module-by-module notes mirroring the video content.
- Architecture diagrams for the RAG pipeline.
- Code snippets and command references.
- Key concept summaries for quick review.

## How to Use the PDF

- Download it from the course resources section in Udemy.
- Use it as a companion reference while watching videos.
- Print specific sections for desk reference (e.g., the LangChain component diagram).
- Search it quickly with `Ctrl+F` / `Cmd+F` to find a specific topic.

## Learning Objectives

By the end of this lesson, you should be able to:

- Download the course PDF from the Udemy resources section.
- Know what content it contains and when to reference it.

## Summary

The course PDF provides offline access to all key notes and diagrams. Download it once from Udemy and keep it as a reference throughout the course.
