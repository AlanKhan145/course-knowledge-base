# 001 - Section Intro

## Section

Advanced Projects with LangChain

## Duration

1 minute

## Main Idea

Introduces the four advanced project builds in this section: SQL chatbot, prompt caching chatbot, multimodal chatbot, and DeepSeek-R1 RAG chatbot. These represent production-grade patterns applicable to real enterprise scenarios.

## Projects in This Section

| Project | Technology | Output |
|---|---|---|
| SQL Chatbot | LangChain + SQLDatabase | Natural language → SQL → result |
| Prompt Caching | In-memory + SQLite cache | Faster, cheaper repeated queries |
| Multimodal Chatbot | LangChain + vision model | Text + image input understanding |
| DeepSeek-R1 RAG | DeepSeek-R1 + Streamlit | Full web chatbot with reasoning |

## Learning Objectives

By the end of this lesson, you should be able to:

- Know which project in this section addresses which use case.
- Set expectations for the complexity and tools involved in each project.

## Summary

This section moves from building RAG skills to applying them in production project patterns. SQL chatbot, prompt caching, multimodal, and DeepSeek-R1 RAG are all patterns used in real enterprise AI products.
