# Module 06 — Pydantic Settings

## 1. Mục tiêu

Học theo thứ tự để đi từ ví dụ nhỏ đến cách ứng dụng Pydantic với dữ liệu thật. Mỗi bài là Markdown độc lập, có lý thuyết, ví dụ, lỗi thường gặp, bài tập và trắc nghiệm kèm giải thích.

## 2. Danh sách bài học

1. [Pydantic Settings: cấu hình từ environment variables](./01-env-va-basesettings.md)
2. [Đọc file .env và quản lý bí mật khi triển khai](./02-dotenv-secrets-production.md)

## 3. Cách thực hành

Tạo một dự án Python mới, lần lượt sao chép ví dụ vào `main.py` hoặc notebook. Thử ít nhất một payload hợp lệ và một payload không hợp lệ sau mỗi bài. Tham khảo [hướng dẫn học](../README.md).
