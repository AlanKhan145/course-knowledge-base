# Module 04 — VS Code And Anaconda Installation

- Lessons: 1
- Phase: Phase 1

## Purpose

This module covers the development environment setup required for the course. Students install Anaconda for Python environment management and VS Code as their primary code editor, ensuring a consistent and reproducible workspace for all subsequent modules.

## Lessons

- [001 - Anaconda Installation And VS Code Installation](001%20-%20Anaconda%20Installation%20And%20VS%20Code%20Installation.md)

## Key Concepts

- Anaconda distribution and conda environment management
- Creating isolated Python environments per project
- VS Code installation and essential Python/Jupyter extensions
- Verifying the development environment is working

## Study Checklist

- [ ] Install Anaconda successfully
- [ ] Create a new conda environment for the course
- [ ] Install VS Code and the Python extension
- [ ] Verify Python version and conda activation in the terminal
- [ ] Run a simple Python script from VS Code
