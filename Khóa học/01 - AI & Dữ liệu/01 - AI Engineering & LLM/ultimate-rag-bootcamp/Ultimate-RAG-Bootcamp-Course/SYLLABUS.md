# Syllabus — Ultimate RAG Bootcamp Using LangChain, LangGraph & LangSmith

## Course Summary

A comprehensive RAG bootcamp covering every major pattern: Traditional RAG, Advanced RAG, Multimodal RAG, Agentic RAG, Autonomous RAG, Multi-Agent RAG, Corrective RAG, Adaptive RAG, Graph RAG, and a complete end-to-end production project using LangChain, LangGraph, and LangSmith.
