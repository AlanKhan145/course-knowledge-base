## What You Will Learn

- Build LLM-powered applications with LangChain and LCEL
- Create AI Agents using the ReAct pattern and LangChain tools
- Understand agent internals: function calling, tool binding, ReAct loops
- Build RAG pipelines with Pinecone, FAISS, and Chroma
- Design stateful agent workflows with LangGraph
- Implement multi-agent systems and supervisor patterns
- Integrate the Model Context Protocol (MCP)
- Manage memory: buffer, summary, entity, and vector store memory
- Trace, evaluate, and monitor with LangSmith
- Deploy production-ready agentic AI systems
