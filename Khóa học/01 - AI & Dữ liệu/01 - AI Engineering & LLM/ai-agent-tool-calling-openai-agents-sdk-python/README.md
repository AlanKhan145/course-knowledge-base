# Khóa học OpenAI Agents SDK với Python — Từ cơ bản đến Deep Research

**Ngôn ngữ:** Tiếng Việt  
**Hình thức:** Giáo trình Markdown độc lập theo từng module, kèm lab, mã Python và trắc nghiệm giải thích đáp án  
**Định hướng:** Xây dựng agent có tools, handoffs, tracing, streaming, guardrails, multi-turn state và hệ thống Deep Research  
**Yêu cầu:** Python cơ bản, khái niệm LLM/prompt, môi trường chạy Python và API key hợp lệ

## 1. Giới thiệu

Khóa học tổ chức kiến thức theo 13 module. Mỗi module là một thư mục chứa một **bài lý thuyết** và một **bài lab** độc lập, không phải bản chép lại lời thoại. Dự án Deep Research có thêm hai bài chuyên sâu về kiến trúc dữ liệu và triển khai tìm kiếm. Trong mỗi bài có giải thích khái niệm, ví dụ, lỗi dễ gặp, thực hành và trắc nghiệm 4 đáp án có giải thích.

## 4. Cấu hình dự án mẫu

```bash
python -m venv .venv
# macOS / Linux: source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install openai-agents python-dotenv
```

Tạo `.env` chứa `OPENAI_API_KEY=...` trên máy cá nhân và **không chia sẻ file này**. Thêm `.env` và `.venv/` vào `.gitignore`. Một số ví dụ sử dụng tool hoặc tính năng cần phiên bản SDK/model hỗ trợ; tham khảo hướng dẫn chính thức nếu API thay đổi.
