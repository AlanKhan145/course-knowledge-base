# Tài liệu tham khảo từ paper

## Paper chính

Haotong Bao, Jianjin Zhang, Weihao Han, Xue Wu, Qi Chen, Dongzhe Jiang, Zhengxin Zeng, Mingzheng Li, Hao Sun, Weiwei Deng, Feng Sun, and Qi Zhang. **HybridSparse: An End-to-End Hybrid Framework for Efficient Large-Scale Retrieval.** SIGIR 2026.

DOI: `10.1145/3805712.3808415`

## Các công trình nền tảng được paper dùng trực tiếp để định vị phương pháp

- BGE M3-Embedding (2024) - multi-functionality embeddings/self-knowledge distillation.
- MS MARCO Web Search (2024) - large-scale web search dataset.
- SPANN (2021) - billion-scale ANN search.
- OneSparse (2024) - unified system for multi-index vector search.
- BERT (2018), RoBERTa (2019) - PLM foundations.
- SPLADE / SPLADE v2 (2021) - neural sparse lexical retrieval.
- coCondenser (2021) - corpus-aware pre-training for dense retrieval.
- Semantic residual embeddings / hybrid lexical-semantic retrieval lines.
- DiskANN (2019), LSH (1999) - ANN foundations.
- SimANS (2022) - negative sampling for dense retrieval.
- Uni-Retriever (2022) - unified embedding based retriever in Bing sponsored search.
