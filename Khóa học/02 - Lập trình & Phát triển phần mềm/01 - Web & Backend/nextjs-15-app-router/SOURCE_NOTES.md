# Nguồn và phương pháp biên soạn

**Nguồn chính:** transcript tiếng Việt người học cung cấp (gần 500 KB) và dãy 92 dấu thời gian từ video.

**Đối chiếu nguồn video:** [Next.js Full Tutorial - Beginner to Advanced, Codevolution/Vishwas](https://www.youtube.com/watch?v=k7o9R6eaSes); repo tham khảo [gopinav/Next.js-15-Tutorials](https://github.com/gopinav/Next.js-15-Tutorials).

- Mỗi bài căn theo đoạn `[timestamp bài hiện tại, timestamp bài kế tiếp)`.
- Văn bản phụ lục trong bài giữ nguyên bản chép lời do người học cung cấp, kể cả các lỗi nhận dạng giọng nói và thuật ngữ phiên âm.
- Mục lý thuyết và code ví dụ là nội dung **biên soạn lại, minh họa/giải thích bổ sung**, không phải bản dịch nguyên văn hay bản bảo đảm tác giả gốc gõ đúng từng dòng.
- Mẫu code trong khóa có thể dùng API hoặc service demo và có TODO; luôn xem nhãn `pseudo`, `minh họa`, `TODO` trước khi copy.
- Chủ đích bám Next.js 15; các bản mới của Next.js/Clerk có thể thay đổi API, options và defaults.
- Nếu transcript mơ hồ, dùng tài liệu gốc của Next.js 15 và source GitHub làm điểm kiểm chứng.

**Chính sách ghi chú:** Không ghi API key, cookie bí mật, thông tin nhận dạng người dùng hay dữ liệu riêng vào file học; code minh họa dùng dữ liệu giả.
