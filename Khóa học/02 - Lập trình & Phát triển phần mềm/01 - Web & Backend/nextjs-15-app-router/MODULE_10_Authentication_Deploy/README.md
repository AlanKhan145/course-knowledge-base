## Cách học module này

1. Đọc lý thuyết trước, ghi lại những từ khóa hoặc quy ước chưa hiểu.
2. Xem video đúng timestamp và thử lại code TSX từ bài học.
3. Dùng checklist thực hành ở cuối mỗi bài để ghi tiến độ.
4. Hoàn thành một nhánh tính năng trong đồ án cuối khóa, tránh chỉ xem video thụ động.
5. Chuyển sang module kế tiếp sau khi giải thích được vì sao code của mình hoạt động.
