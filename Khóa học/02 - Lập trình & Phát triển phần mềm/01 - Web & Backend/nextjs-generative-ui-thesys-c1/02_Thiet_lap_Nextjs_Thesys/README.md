# Thiết lập Next.js và Thesys C1

**Mục tiêu module:** Nắm vững các kỹ năng cốt lõi của chủ đề, kết hợp lý thuyết và bài thực hành.

## 1. Danh sách bài học

1. [Thử C1 Playground và đặt bài toán đầu tiên](01_Thu_playground_va_chon_use_case.md) — Sử dụng Playground để thử prompt; lập tiêu chí đánh giá đầu ra và phát hiện kết quả thiếu dữ liệu thực.
2. [Khởi tạo ứng dụng Next.js bằng C1 CLI](02_Khoi_tao_ung_dung_Nextjs_C1.md) — Tạo được dự án mẫu C1, chạy dev server và xác định những biến môi trường phải giữ kín.
3. [Đọc cấu trúc project và triển khai route API](03_Cau_truc_project_va_API_route.md) — Xác định được layout, page, route handler; giải thích khác nhau giữa endpoint C1 đơn lẻ và hợp đồng /api/chat cho C1Chat.

## 2. Cách học

Đọc lần lượt các bài, chạy thử code ở những phần có code, hoàn thành mini-lab và tự làm 5 câu ôn tập của mỗi bài. Kiểm tra cả dữ liệu, trạng thái lỗi và quyền thực thi; không chỉ đối chiếu vẻ ngoài của UI.
