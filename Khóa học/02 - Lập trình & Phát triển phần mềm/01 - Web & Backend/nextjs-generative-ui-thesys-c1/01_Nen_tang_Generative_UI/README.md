# Nền tảng Generative UI và MCP-UI

**Mục tiêu module:** Nắm vững các kỹ năng cốt lõi của chủ đề, kết hợp lý thuyết và bài thực hành.

## 1. Danh sách bài học

1. [Từ chatbot văn bản đến Generative UI](01_Tu_chat_van_ban_den_giao_dien_tao_sinh.md) — Phân biệt được câu trả lời dạng văn bản với giao diện tạo sinh; lựa chọn đúng thành phần trình bày cho một yêu cầu.
2. [Kiến trúc C1: API, DSL và React renderer](02_Kien_truc_Thesys_C1_va_DSL.md) — Mô tả được luồng browser → backend → C1 API → DSL → React; xác định vị trí đặt khóa bí mật và điểm kiểm soát dữ liệu.
3. [MCP-UI và Thesys C1: hai hướng tiếp cận](03_MCP_UI_va_C1_khac_nhau_the_nao.md) — Giải thích được mối liên hệ giữa MCP-UI, generative UI và giao diện thương mại điện tử; tránh đánh đồng cách truyền tool với renderer.

## 2. Cách học

Đọc lần lượt các bài, chạy thử code ở những phần có code, hoàn thành mini-lab và tự làm 5 câu ôn tập của mỗi bài. Kiểm tra cả dữ liệu, trạng thái lỗi và quyền thực thi; không chỉ đối chiếu vẻ ngoài của UI.
