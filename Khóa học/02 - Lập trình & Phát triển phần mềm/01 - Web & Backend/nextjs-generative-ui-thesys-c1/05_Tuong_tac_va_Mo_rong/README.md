# Tương tác, custom actions và custom components

**Mục tiêu module:** Nắm vững các kỹ năng cốt lõi của chủ đề, kết hợp lý thuyết và bài thực hành.

## 1. Danh sách bài học

1. [Form, input, state và vòng lặp hành động](01_Forms_inputs_va_action_events.md) — Thiết kế được vòng lặp input → event → backend → phản hồi cập nhật; phân biệt action tiếp tục hội thoại và action nghiệp vụ.
2. [Custom actions: tải báo cáo, mở modal và kiểm soát quyền](02_Custom_actions_download_va_modal.md) — Mô tả được cách đăng ký custom action trong metadata C1 và xử lý callback frontend mà không bỏ qua xác thực.
3. [Custom React components: từ schema tới thẻ sản phẩm](03_Custom_React_components_va_schema.md) — Đăng ký được component do ứng dụng sở hữu, khai báo prop schema và render qua C1; nêu nguyên tắc chống dữ liệu không đáng tin cậy.
4. [Flow nhiều bước: form tiếp nối, xác nhận và tiến trình](04_Multi_step_forms_va_phan_hoi_tiep_noi.md) — Thiết kế flow hỏi-đáp nhiều bước mà không áp đặt một workflow cứng cho mọi ý định người dùng.

## 2. Cách học

Đọc lần lượt các bài, chạy thử code ở những phần có code, hoàn thành mini-lab và tự làm 5 câu ôn tập của mỗi bài. Kiểm tra cả dữ liệu, trạng thái lỗi và quyền thực thi; không chỉ đối chiếu vẻ ngoài của UI.
