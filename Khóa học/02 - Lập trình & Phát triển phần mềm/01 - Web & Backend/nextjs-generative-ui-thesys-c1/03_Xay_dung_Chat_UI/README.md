# Xây dựng trải nghiệm trò chuyện

**Mục tiêu module:** Nắm vững các kỹ năng cốt lõi của chủ đề, kết hợp lý thuyết và bài thực hành.

## 1. Danh sách bài học

1. [C1Chat và C1Component: chọn đúng mức tích hợp](01_C1Chat_va_C1Component.md) — Triển khai được cách render chatbot dựng sẵn và renderer riêng; giải thích đánh đổi giữa tốc độ và quyền tùy chỉnh.
2. [Streaming, threadId, responseId và quản lý lịch sử](02_Streaming_va_Conversation_State.md) — Giải thích được streaming, trạng thái hội thoại, giới hạn in-memory; thiết kế cách lưu thread khi đưa lên production.
3. [Tùy biến chủ đề, sidebar và giao diện chat](03_Theme_Layout_va_UX_chat.md) — Thiết kế layout chat có header, sidebar, khu phản hồi; đặt tiêu chí cho responsive, accessibility và trạng thái rỗng.

## 2. Cách học

Đọc lần lượt các bài, chạy thử code ở những phần có code, hoàn thành mini-lab và tự làm 5 câu ôn tập của mỗi bài. Kiểm tra cả dữ liệu, trạng thái lỗi và quyền thực thi; không chỉ đối chiếu vẻ ngoài của UI.

Có ghi chép giải thích được kiến trúc, một kết quả thực hành, testcase đầu vào hợp lệ và testcase lỗi.
