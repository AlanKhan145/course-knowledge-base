# Bài triển khai 1 — Lịch tập 3 buổi/tuần

## Mẫu tuần

| Ngày | Nội dung |
|---|---|
| Thứ 2 | Buổi A |
| Thứ 3 | Nghỉ / vận động nhẹ |
| Thứ 4 | Buổi B |
| Thứ 5 | Nghỉ / vận động nhẹ |
| Thứ 6 | Buổi C |
| Cuối tuần | Hồi phục |

Đây chỉ là một cách xếp lịch. Có thể đổi ngày miễn là vẫn duy trì khoảng nghỉ hợp lý.

## Toàn bộ chương trình

### Buổi A
1. Incline dumbbell press — 3 × 8–12
2. Squat — 3 × 6–8
3. Chest-supported dumbbell row — 3 × 8–12
4. Leg curl — transcript không nêu rõ set/rep
5. Incline dumbbell curl — superset
6. Overhead triceps extension — superset  
→ 3 vòng superset

### Buổi B
1. Barbell bench press — 3 × 4–6
2. Romanian deadlift — 3 × 6–8
3. Lat pulldown — 3 × 8–12
4. Walking lunge — 3 × 6–10 mỗi chân
5. Cable lateral raise — superset
6. Reverse crunch — superset  
→ 3 vòng superset

### Buổi C
1. Dumbbell shoulder press — 3 × 8–12
2. One-arm dumbbell row — 3 × 8–12
3. Hip thrust — 3 × 10–15
4. Leg extension — 3 × 10–15
5. Chest fly — 3 × 10–15
6. Standing calf raise + cable reverse fly — 3 vòng
