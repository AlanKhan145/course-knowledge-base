# About Essay - Tổng quan bài luận

Sách tổ chức phần luận theo **Brainstorming -> Paragraph Power -> Writing Essays**.

```mermaid
flowchart LR
    A[Đọc câu hỏi] --> B[Xác định dạng yêu cầu / chủ đề]
    B --> C[Chọn lập trường hoặc hướng triển khai]
    C --> D[Brainstorming lý do + ví dụ]
    D --> E[Lập dàn ý đoạn]
    E --> F[Viết Introduction - Body - Conclusion]
    F --> G[Đọc lại: logic, liên kết, ngữ pháp, từ vựng]
```

## Khung
- Introduction + thesis
- Body paragraphs: mỗi đoạn một ý chính + hỗ trợ
- Conclusion
