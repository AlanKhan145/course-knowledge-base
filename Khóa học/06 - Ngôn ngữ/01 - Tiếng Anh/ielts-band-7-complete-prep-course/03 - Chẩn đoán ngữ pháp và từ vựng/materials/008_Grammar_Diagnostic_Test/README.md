# Bài 008 - Grammar Diagnostic Test

Thư mục này chứa assessment Markdown, bài Grammar Diagnostic gốc, các tài liệu vocabulary/collocation đã cung cấp và shortcut tới các tài nguyên trực tuyến liên quan.

## Bắt đầu

1. Mở `008 - Grammar Diagnostic Test.md`.
2. Làm `01_Diagnostic/Grammar Diagnostic Test.pdf` trong 40 phút, không dùng trợ giúp.
3. Chấm bài sau khi hoàn thành.
4. Ghi lỗi vào `ERROR_LOG_TEMPLATE.md`.
5. Dùng thư mục `02_Academic_Vocabulary` và `03_Online_Resources` để ôn đúng phần còn yếu.

## Lưu ý về tài nguyên trực tuyến

Một số đường dẫn cũ đã thay đổi cấu trúc website hoặc yêu cầu JavaScript. Các shortcut trong `03_Online_Resources` ưu tiên đường dẫn hiện hành khi xác định được, đồng thời giữ playlist và link tham khảo gốc khi hữu ích.
