# Bản đồ khóa học

## Mục tiêu

Biến bằng chứng nghiên cứu về second-language acquisition thành quy trình học có thể lặp lại, thay vì chỉ sưu tầm “mẹo học”.

## Khung chung

**Retrieval/SRS → input vừa sức → listening có hỗ trợ → output → feedback → task repetition.**

Khung này phải điều chỉnh theo ngôn ngữ:

- **English:** extensive reading + collocation SRS + captioned viewing + speaking/output.
- **French:** pronunciation/phonetics sớm + article–noun chunks + gender cues + retrieval practice.
- **Japanese:** kana/vocabulary/grammar chạy song song với kanji; SRS + component analysis; pitch/mora perception.
- **Chinese:** tone perception + high-variability input; phonetic/semantic radicals; handwriting và typing dùng cho các mục tiêu khác nhau.

## Thứ tự học đề xuất

### Module A — Memory & retrieval
Học cách dùng spaced retrieval để nhớ **cụm**, không chỉ word đơn.

### Module B — Input
Dùng extensive reading và audiovisual input phù hợp trình độ.

### Module C — Sound system
Huấn luyện perception/production có feedback, đặc biệt French phonetics, Japanese pitch, Mandarin tone.

### Module D — Writing systems
Kanji/Hanzi không học như alphabet: gắn character với component, từ thật, reading/pronunciation và câu.

### Module E — Output loop
Tạo câu/nói lại → nhận feedback → lặp lại cùng loại task sau một khoảng cách thời gian.

## Quy tắc đọc bằng chứng

Không biến một study thành luật tuyệt đối. Luôn nhìn: đối tượng, cỡ mẫu, task, outcome, thời gian retention, ngôn ngữ, và mức độ generalization.
