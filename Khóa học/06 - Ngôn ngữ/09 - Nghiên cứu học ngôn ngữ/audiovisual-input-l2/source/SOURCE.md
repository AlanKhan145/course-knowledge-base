# Nguồn học thuật

**Sutton, Dru & Stuart Webb (2026).** *The effects of audiovisual input on second language learning: A meta-analysis.* Studies in Second Language Acquisition, 48, 571-595. DOI: 10.1017/S0272263126101612.

Paper tổng hợp **75 effect sizes từ 56 experiments (n = 1954)** để đánh giá tác động của video không có on-screen text lên việc học ngôn ngữ thứ hai. Tác giả phân tích nhiều moderator, bao gồm đặc điểm người học, mục tiêu học, loại video, thời lượng xem, cách xem và loại bài kiểm tra.

Bài báo được phát hành dưới **Creative Commons Attribution (CC BY 4.0)** theo thông tin in trên PDF. Khóa học này là bản chuyển thể/sắp xếp lại cho mục đích học tập và luôn ghi nguồn.

File gốc: `sutton-webb-2026-audiovisual-input-meta-analysis.pdf`.
