# Glossary

| Thuật ngữ | Nghĩa trong khóa học |
|---|---|
| Captioning | L2 video + L2 on-screen text |
| L1 subtitles | L2 video + L1 on-screen text |
| Reversed subtitles | L1 video + L2 text |
| Lexical coverage | Tỷ lệ từ trong input mà người học biết |
| Target Word (TW) | Từ mục tiêu được theo dõi trong nghiên cứu |
| Keyword | Từ quan trọng cho nghĩa của câu/đoạn |
| Salience | Mức độ nổi bật khiến item dễ thu hút attention |
| Noticing | Việc người học chú ý/nhận ra một form trong input |
| Form recognition | Nhận ra từ có xuất hiện trong clip hay không |
| Clip association | Gắn từ với clip phù hợp |
| Meaning recognition | Nhận ra đúng nghĩa trong các lựa chọn |
| Meaning recall | Tự nhớ và cung cấp nghĩa/bản dịch |
| Vocabulary size | Quy mô vốn từ của người học |
| Covariate | Biến được đưa vào phân tích để kiểm soát ảnh hưởng liên quan |
| MANCOVA | Phân tích nhiều biến phụ thuộc cùng lúc với covariate |
| Partial eta squared | Chỉ số effect size dùng trong paper |
| Incidental vocabulary learning | Học từ như sản phẩm phụ khi hoạt động chính là hiểu meaning |
| Staged video approach | Giảm dần text support: FC/FCHK → KC → NC |
