# Glossary

| Thuật ngữ | Giải thích trong ngữ cảnh paper |
|---|---|
| Extensive Reading (ER) | Đọc lượng văn bản lớn, thường cá nhân, im lặng, nhấn mạnh hiểu tổng quát/hứng thú. |
| Intensive Reading (IR) | Đọc ngắn và phân tích chi tiết văn bản. |
| L2 learner | Học một ngôn ngữ bổ sung đang được sử dụng phổ biến trong quốc gia/môi trường sống. |
| Foreign language learner | Học ngôn ngữ không được sử dụng phổ biến như ngôn ngữ bản địa trong môi trường sống. |
| Graded reader | Sách được đơn giản hóa/nghiệm soát từ vựng để phù hợp các trình độ học ngôn ngữ. |
| Accountability | Cơ chế yêu cầu người học chứng minh/ghi nhận việc đọc, như log, quiz, book report. |
| Text limitation | Giới hạn phạm vi văn bản người học có thể chọn, thường liên quan tới độ phù hợp trình độ. |
| Moderator | Biến dùng để kiểm tra vì sao effect size khác nhau giữa nhóm nghiên cứu/can thiệp. |
| Cohen’s d | Effect size chuẩn hóa được paper dùng để gộp và so sánh kết quả. |
| Random-effects model | Mô hình cho phép effect thực thay đổi giữa các nghiên cứu. |
| Heterogeneity | Mức độ các effect sizes khác nhau vượt quá sai số lấy mẫu. |
| Publication bias | Nguy cơ bằng chứng xuất bản không đại diện đầy đủ cho toàn bộ kết quả nghiên cứu. |
| Implementation fidelity | Mức độ can thiệp thực tế được thực hiện đúng như thiết kế. |
