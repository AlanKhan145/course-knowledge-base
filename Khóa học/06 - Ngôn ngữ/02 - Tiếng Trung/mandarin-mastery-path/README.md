# Mandarin Mastery Path — Tiếng Trung từ Nền tảng đến HSK 3

**Tên tiếng Việt:** Tiếng Trung Thực Chiến từ Cơ Bản đến HSK 3

> **Trạng thái:** 🚧 Khung template — toàn bộ module và bài học mới ở dạng khung, nội dung chi tiết sẽ biên soạn sau.

## Định hướng khóa học

Xây dựng năng lực tiếng Trung từ phát âm, Pinyin, chữ Hán và giao tiếp cơ bản
đến khả năng sử dụng các mẫu câu và cấu trúc ngữ pháp tương ứng trình độ
HSK 1, HSK 2 và HSK 3.

Curriculum này giữ phạm vi kiến thức HSK nhưng **không** sử dụng lại lời giảng,
slide, bài tập, ví dụ hoặc tài liệu độc quyền của bất kỳ khóa tham khảo nào.

## Cấu trúc thư mục

```
mandarin-mastery-path/
├── README.md                     ← file này (mục lục khóa học)

```

## Cách dùng khung này

1. Mở `README.md` của module để xem danh sách bài và checklist.
2. Biên soạn nội dung trực tiếp trong từng `bai-XX.md` theo 9 mục có sẵn.
3. Khi một bài xong, đổi 🚧 thành ✅ trong bảng ở README của module.
4. Mục nào không dùng thì xóa, không để trống trong bản hoàn thiện.

## Kết quả đầu ra mong đợi

- Đọc và viết Pinyin chuẩn, phân biệt 4 thanh điệu và thanh nhẹ.
- Nhận diện, viết và ghi nhớ chữ Hán theo bộ thủ, nét cơ bản.
- Giao tiếp trong các tình huống đời sống quen thuộc ở mức HSK 1–2.
- Sử dụng thành thạo các cấu trúc trọng tâm HSK 3: 把, 被, 像, 除了…以外,
  bổ ngữ kết quả/xu hướng/khả năng, câu so sánh, câu điều kiện.
- Đủ nền tảng để bước tiếp lên HSK 4.
