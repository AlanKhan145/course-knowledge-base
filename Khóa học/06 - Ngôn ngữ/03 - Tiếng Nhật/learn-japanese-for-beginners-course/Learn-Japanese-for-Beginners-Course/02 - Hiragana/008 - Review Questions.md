# 008 - Review Questions

**Học phần:** How to Write in Japanese: Hiragana and Katakana
**Loại bài:** review

---

## 1. Mục tiêu ôn tập

Bài ôn tập này giúp củng cố khả năng nhận diện, phát âm và ghi nhớ các Hiragana đã học, đặc biệt là hàng T:

```text
た ち つ て と
ta chi tsu te to
```

Sau khi hoàn thành, người học cần có thể:

* Nhận diện các ký tự Hiragana mà không phụ thuộc vào thứ tự trong bảng.
* Đọc đúng `ち` là `chi` và `つ` là `tsu`.
* Phân biệt `つ` với `っ` nhỏ.
* Nhận diện các dạng có `dakuten` của hàng T.
* Tự phát hiện những ký tự hoặc âm vẫn còn dễ nhầm.

## 3. Phần B - Nhận diện theo thứ tự ngẫu nhiên

Đọc thành tiếng các ký tự sau:

```text
と　ち　た　て　つ
```

Sau đó viết romaji:

```text
と → ______
ち → ______
た → ______
て → ______
つ → ______
```

Tiếp tục với nhóm có `dakuten`:

```text
づ　だ　ど　ぢ　で
```

Viết cách đọc:

```text
づ → ______
だ → ______
ど → ______
ぢ → ______
で → ______
```

Mục tiêu của phần này là kiểm tra khả năng nhận diện từng ký tự độc lập thay vì chỉ ghi nhớ chuỗi:

```text
た ち つ て と
```

## 5. Phần D - Đọc từ

Đọc thành tiếng các từ sau trước khi nhìn romaji.

| Từ     | Romaji của bạn |
| ------ | -------------- |
| `たつ`   | __________     |
| `て`    | __________     |
| `とおい`  | __________     |
| `つづく`  | __________     |
| `だいがく` | __________     |
| `きって`  | __________     |
| `きっぷ`  | __________     |

Khi đọc `きって` và `きっぷ`, chú ý khoảng ngắt do `っ` tạo ra.

So sánh:

```text
きて
きって
```

Đọc cả hai từ liên tiếp và cố gắng làm rõ sự khác biệt về nhịp.

1. `ta` → __________
2. `chi` → __________
3. `tsu` → __________
4. `te` → __________
5. `to` → __________
6. `da` → __________
7. `de` → __________

Đánh dấu những ký tự bạn viết sai hình dạng hoặc phải mất nhiều thời gian mới nhớ được.

## 8. Tự kiểm tra bằng phát âm

Đọc thành tiếng ba lần:

```text
た　ち　つ　て　と
```

Lần thứ hai, đọc theo thứ tự ngược:

```text
と　て　つ　ち　た
```

Lần thứ ba, đọc theo thứ tự ngẫu nhiên:

```text
ち　と　つ　た　て
```

Tiếp theo đọc:

```text
だ　ぢ　づ　で　ど
```

Cuối cùng, ghi âm một lần và nghe lại.

Đánh dấu những vấn đề còn gặp phải:

* [ ] Tôi còn đọc `ち` chưa chắc.
* [ ] Tôi còn đọc `つ` chưa chắc.
* [ ] Tôi khó phân biệt `つ` và `っ`.
* [ ] Tôi còn nhầm `ぢ` với `じ`.
* [ ] Tôi còn nhầm `づ` với `ず`.
* [ ] Tôi nhận diện chậm khi ký tự bị đảo thứ tự.
* [ ] Tôi nhớ âm nhưng chưa nhớ cách viết.
* [ ] Tôi có thể nhận diện và đọc tương đối tự động.
