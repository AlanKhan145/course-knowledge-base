# Module 05 - Product Planning — Lập kế hoạch sản phẩm

## Mục tiêu module
Biết viết yêu cầu, tạo roadmap, ưu tiên backlog và giao tiếp kế hoạch sản phẩm.

## Thực hành trọng tâm
Biến một problem đã validate thành PRD nhỏ, roadmap now/next/later và 5 user stories.

## Output sau module
- PRD, roadmap slice, backlog and user story map
- Ghi chú quyết định hoặc insight có thể chia sẻ với stakeholder
- Danh sách câu hỏi còn mở cho research, strategy hoặc execution

## Checklist hoàn thành
- [ ] Đọc toàn bộ bài học trong module
- [ ] Tạo ít nhất một artifact thực hành
- [ ] Liên hệ nội dung với một sản phẩm thật
- [ ] Ghi lại 3 điều sẽ áp dụng trong công việc PM
