# Module 10 - Product Management Tools — Công cụ PM

## Mục tiêu module
Biết chọn và dùng tool PM đúng mục đích thay vì biến tool thành quy trình.

## Thực hành trọng tâm
Thiết kế workflow quản lý roadmap, backlog, analytics và communication bằng bộ tool bạn chọn.

## Output sau module
- PM tool workflow and operating board
- Ghi chú quyết định hoặc insight có thể chia sẻ với stakeholder
- Danh sách câu hỏi còn mở cho research, strategy hoặc execution
