# Module 07 - Metrics & Analytics

## Mục tiêu module
Biết đo DevRel bằng metric, tooling, reporting, dashboard và recommendation thực tế.

## Thực hành trọng tâm
Xây metrics tree cho DevRel: community, content, docs, activation và developer satisfaction.

## Output sau module
- DevRel metrics dashboard spec and monthly insights report
- Một decision note hoặc content/support/community plan có thể chia sẻ với team
- Danh sách friction, insight hoặc feedback cần gửi lại product/engineering
