# Module 05 - Content Creation

## Mục tiêu module
Biết tạo nội dung DevRel đa kênh: blog, video, livestream, social và collaboration.

## Thực hành trọng tâm
Lập content calendar 4 tuần, viết một blog/tutorial và repurpose thành social post hoặc video script.

## Output sau module
- Content calendar, blog draft, video script or livestream plan
- Một decision note hoặc content/support/community plan có thể chia sẻ với team
- Danh sách friction, insight hoặc feedback cần gửi lại product/engineering
