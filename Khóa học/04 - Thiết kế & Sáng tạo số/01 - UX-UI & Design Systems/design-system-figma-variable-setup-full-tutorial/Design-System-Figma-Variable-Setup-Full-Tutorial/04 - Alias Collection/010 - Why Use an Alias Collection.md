# 010 - Why Use an Alias Collection?

## Module

Alias Collection

## Video Timestamp

41:38 (start time in the full-length course video)

## Main Idea

Explains the rationale for aliasing tokens rather than binding components directly to brand primitives.

## Key Topics Mentioned

* Avoiding direct references to raw brand values in components
* Making rebranding/retheming easier by changing one alias source
* Decoupling design intent from specific color/scale values

## Summary

Explains the rationale for aliasing tokens rather than binding components directly to brand primitives. This lesson is one building block toward the module's goal: Builds the semantic layer that maps primitive Brand/Scale values to reusable, purpose-named alias tokens (borders, fonts) instead of using raw values directly.
