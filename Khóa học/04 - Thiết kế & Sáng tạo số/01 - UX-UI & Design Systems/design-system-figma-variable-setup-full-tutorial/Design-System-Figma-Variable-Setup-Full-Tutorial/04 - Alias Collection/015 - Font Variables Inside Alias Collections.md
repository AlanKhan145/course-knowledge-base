## Summary

Brings font primitives into the Alias Collection so typography can be referenced semantically instead of by raw font family/weight. This lesson is one building block toward the module's goal: Builds the semantic layer that maps primitive Brand/Scale values to reusable, purpose-named alias tokens (borders, fonts) instead of using raw values directly.
