# 004 - What is PromptOps and How is it Different from Prompt Engineering

## Section

Mastering Prompts

## Duration

3:52

## Main Idea

Introduces PromptOps as the discipline of managing prompts like production assets -- versioning, testing, monitoring, and iterating on them over time -- versus prompt engineering, which is the act of writing a single effective prompt. By the end of the lesson, learners should see how What is PromptOps and How is it Different from Prompt Engineering connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* PromptOps definition
* Prompt versioning
* Prompt testing/monitoring
* Lifecycle management vs. one-off crafting
