# 007 - Animation in Figma

## Section

Figma Project: Prototyping and animation

## Duration

4:21

## Main Idea

Covers Figma's smart animate and easing/timing controls to add motion between prototype states, and when subtle animation improves versus distracts from a UX flow. By the end of the lesson, learners should see how Animation in Figma connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* Smart animate
* Easing and timing
* Motion for UX
* Restraint in animation use
