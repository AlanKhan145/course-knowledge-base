# 002 - Prompt Thinking - How to Talk to AI Like a Designer

## Section

AI as Your Design Partner

## Duration

3:11

## Main Idea

Teaches designers to translate design vocabulary (hierarchy, whitespace, contrast, tone) into prompt language the AI can act on, instead of vague requests like 'make it nicer'. By the end of the lesson, learners should see how Prompt Thinking - How to Talk to AI Like a Designer connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* Design vocabulary in prompts
* Specificity over vagueness
* Translating intent into instructions
