# 002 - How AI is changing UI/UX

## Section

Introduction to Vibe Coding for UX/UI Designers

## Duration

5:40

## Main Idea

Looks at how generative AI is reshaping the UX/UI workflow -- from research and ideation to wireframing, visual design, and handoff -- and why designers who can direct AI tools have an edge over those who only use traditional design software. By the end of the lesson, learners should see how How AI is changing UI/UX connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* AI-assisted research
* Generative wireframing
* AI in visual design
* Designer-as-director mindset
* Shift from manual tools to prompt-driven tools
