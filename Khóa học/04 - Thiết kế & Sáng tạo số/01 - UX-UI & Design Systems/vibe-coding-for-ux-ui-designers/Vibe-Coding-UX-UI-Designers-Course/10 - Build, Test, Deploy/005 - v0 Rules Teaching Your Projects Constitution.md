## Section

## Main Idea

Introduces v0's project 'rules' feature -- persistent instructions (a project constitution) that constrain every generation in a project to follow set conventions (styling, structure, naming). By the end of the lesson, learners should see how v0 Rules Teaching Your Projects Constitution connects to designing and shipping AI-assisted UX/UI work without traditional coding.
