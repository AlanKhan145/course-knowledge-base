# 005 - Variables for spacing

## Section

Building Design systems

## Duration

2:21

## Main Idea

Introduces spacing tokens (e.g., a 4/8/16/24px scale) as variables so padding and gaps stay consistent across components and layouts. By the end of the lesson, learners should see how Variables for spacing connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* Spacing scale
* Spacing variables
* Layout consistency
