# 008 - Build Your Prompt Portfolio

## Section

Advanced Prompt Engineering Tactics

## Duration

Not listed

## Main Idea

A capstone exercise having learners collect their best prompts (from Figma, Lovable, Cursor, Windsurf, and v0 work) into a personal, reusable prompt portfolio/library. By the end of the lesson, learners should see how Build Your Prompt Portfolio connects to designing and shipping AI-assisted UX/UI work without traditional coding.

## Key Topics Mentioned

* Personal prompt library
* Curating best prompts
* Reuse across future projects

## Summary

A capstone exercise having learners collect their best prompts (from Figma, Lovable, Cursor, Windsurf, and v0 work) into a personal, reusable prompt portfolio/library. This lesson is one building block toward the section's goal: Goes beyond the core prompting framework into few-shot, ReAct/Self-Ask, layered prompting, and prompt-testing tactics, ending with a personal prompt portfolio.
