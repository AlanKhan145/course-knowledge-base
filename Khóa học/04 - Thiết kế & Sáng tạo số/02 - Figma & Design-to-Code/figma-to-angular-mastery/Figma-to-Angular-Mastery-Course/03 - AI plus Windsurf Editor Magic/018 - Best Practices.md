## Main Idea

This lesson closes out the AI/Windsurf section with a set of cautionary best practices: never accept AI-generated code blindly, always review it before it lands in the project, and prefer small refinement loops over pasting large, unchecked blocks of generated code. It reinforces that speed from AI assistance is only valuable if the resulting codebase stays clean, readable, and maintainable. These habits directly protect the quality of the Atomic Design components that will be built in the following sections, where sloppy, unreviewed code would compound quickly across atoms, molecules, and organisms. This is the safety net that keeps the "vibe coding workflow" from turning into unmanageable technical debt.

## Key Topics Mentioned

* Never blindly copy-pasting AI-generated code
* Reviewing every piece of AI output before accepting it
* Refining in small loops rather than large pastes
* Keeping the codebase clean and organized
* Protecting maintainability across the rest of the course
