# 016 - Debugging with Windsurf – When AI code goes wrong, how to fix it

## Section

## Duration

1:48

## Main Idea

This lesson addresses an inevitable reality of AI-assisted coding: sometimes the generated Angular or Tailwind code is wrong. It covers how to read terminal output for clues, how to spot common failure patterns like broken imports, mismatched class names, or unbalanced brackets, and how to prompt Windsurf effectively to fix the issue rather than starting over from scratch. Treating debugging as a normal, expected step -- not a sign that the workflow has failed -- keeps learners from getting discouraged the first time generated code doesn't run. This debugging skill becomes essential once the hands-on build sections start generating larger and more complex components.

## Key Topics Mentioned

* Reading terminal/console output for error clues
* Spotting broken imports in generated code
* Spotting mismatched Tailwind classes
* Spotting unbalanced brackets or syntax errors
* Prompting Windsurf to fix identified issues
