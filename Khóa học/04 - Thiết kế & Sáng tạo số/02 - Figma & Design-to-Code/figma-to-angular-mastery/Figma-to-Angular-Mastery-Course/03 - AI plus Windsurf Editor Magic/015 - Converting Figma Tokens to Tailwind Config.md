## Section

## Duration

## Main Idea

This lesson puts Windsurf to work on a concrete task: taking the design tokens read out of Figma earlier -- colors, fonts, and spacing values -- and mapping them automatically into the project's tailwind.config.js. Instead of manually retyping every color and font value, the AI assistant is prompted to generate the config entries directly, turning designer decisions into reusable Tailwind utility classes. This is the first hands-on moment where Figma values and Angular/Tailwind code are directly connected through AI assistance. It sets the pattern for every later "read from Figma, generate with Windsurf" step used throughout the rest of the course.
