# 012 - Inspect Mode for Developers – Stealing CSS without shame

## Section

Crash Course: Figma for Non-Designers

## Duration

2:13

## Main Idea

This lesson introduces Figma's Inspect (Dev) mode as the direct bridge between what a designer created and the CSS a developer needs to write. It shows how to select any frame or element and read off the generated CSS, exact spacing, and layout values without guessing or eyeballing measurements. Framed playfully as "stealing CSS without shame," the lesson makes clear that this is a completely normal, expected part of professional handoff -- not a shortcut to feel guilty about. This closes out the Figma-for-developers section by turning everything learned about frames, components, and styles into a repeatable habit of reading a design file like a developer, which the next section builds directly on.

## Key Topics Mentioned

* Figma's Inspect/Dev mode overview
* Reading generated CSS directly off a frame
* Extracting exact spacing and layout values
* Treating CSS extraction as normal professional practice
* Bridging visual design and developer implementation
