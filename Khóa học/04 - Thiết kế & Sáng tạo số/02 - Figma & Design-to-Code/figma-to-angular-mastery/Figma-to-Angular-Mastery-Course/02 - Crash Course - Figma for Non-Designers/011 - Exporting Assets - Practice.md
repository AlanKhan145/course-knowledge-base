# 011 - Exporting Assets – Icons, Images, SVGs

## Section

Crash Course: Figma for Non-Designers

## Duration

2:21

## Main Idea

This lesson covers the practical mechanics of getting visual assets out of Figma and into a codebase, focusing on icons, images, and SVGs. It walks through Figma's export settings, appropriate naming conventions for exported files, and how to preserve quality -- especially for icons and vector graphics that need to stay crisp at any size. Getting export hygiene right early avoids a messy assets folder full of inconsistently named or badly compressed files later in the project. This is a small but essential practical skill that every later hands-on build lesson will depend on.

## Key Topics Mentioned

* Exporting icons from Figma
* Exporting images and choosing the right format
* Exporting SVGs for scalable vector graphics
* Naming conventions for exported assets
* Preserving quality when bringing assets into Angular
