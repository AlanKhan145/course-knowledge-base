# 010 - Variants & Auto-Layout – Resize once, reuse everywhere

## Section

Crash Course: Figma for Non-Designers

## Duration

## Main Idea

This lesson takes a deeper dive into two of Figma's most powerful features for developers: variants, which let a single component express multiple states or sizes, and Auto Layout, which lets frames resize and reflow automatically. Both features model behavior that maps almost directly onto concepts developers already know -- variants resemble component inputs/props, and Auto Layout resembles Flexbox rules. Understanding how a designer configured these features reveals a lot about the intended responsive behavior of a component before a single line of Angular code is written. This lesson closes the loop between static design values and the dynamic layout behavior that Tailwind's responsive classes will later reproduce.

## Key Topics Mentioned

* Figma variants for expressing component states/sizes
* Auto Layout for resizable, reflowing frames
* Mapping variants to Angular component inputs
* Mapping Auto Layout to Flexbox/Tailwind responsive classes
* Reading a design's intended responsive behavior
