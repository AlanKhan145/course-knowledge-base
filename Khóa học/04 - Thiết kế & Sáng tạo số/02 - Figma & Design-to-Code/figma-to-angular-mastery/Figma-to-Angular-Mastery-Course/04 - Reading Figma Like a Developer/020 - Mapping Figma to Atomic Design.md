## Main Idea

This lesson makes the connection between a Figma file and the Atomic Design hierarchy explicit and concrete: a Button in Figma maps to an Atom, a Card maps to a Molecule, and larger sections map further up to Organisms, Templates, and Pages. Walking through real examples from a design file rather than abstract definitions makes the mapping immediately actionable. Once a developer can look at any Figma component and instantly place it in the Atomic Design hierarchy, decomposing an entire design file into a concrete build plan becomes straightforward. This mapping skill is exactly what the upcoming Atoms-through-Pages sections will lean on when deciding what to build first.
