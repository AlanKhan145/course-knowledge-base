# 022 - Build All Atoms from Figma + Windsurf Editor

## Section

Atoms in Angular

## Duration

7:03

## Main Idea

This hands-on lesson puts the entire course's setup work into practice by building the Atom-level components -- buttons, inputs, icons, labels -- as real Angular components styled with Tailwind. Each atom is generated from its corresponding Figma piece using Windsurf, then reviewed and refined following the prompt-preview-refine loop and best practices established earlier. The lesson also covers organizing these atoms into a folder structure designed to scale as molecules, organisms, and pages get layered on top in later sections. This is the first true "design to code" moment of the course, where every earlier lesson on Figma literacy, design tokens, and AI workflow comes together in a single build.

## Key Topics Mentioned

* Identifying Atom-level pieces in the Figma file
* Generating buttons, inputs, icons, and labels with Windsurf
* Applying Tailwind styling driven by the design tokens
* Reviewing and refining AI-generated Atom components
* Organizing atoms into a scalable folder structure
