# 001 - Welcome To The Course – Ikea Furniture Joke + Why Figma → Angular Matters

## Section

Welcome & Setup

## Duration

2:47

## Main Idea

Opens the course with a relatable analogy -- assembling Ikea furniture without instructions -- to frame the pain of building UI from a design file without a clear process. Introduces the core promise of the course: turning a Figma design into working Angular code in under an hour using AI, and explains why the Figma-to-code gap (designers and developers speaking different languages) is worth closing with an AI-assisted workflow.

## Key Topics Mentioned

* The "Ikea furniture without instructions" analogy for coding without a plan
* Why the Figma-to-Angular handoff is traditionally slow and error-prone
* The course's core promise: design to code in under an hour
* Course structure overview (Figma literacy, AI/Windsurf workflow, Atomic Design, hands-on build)

## Summary

Sets expectations for the course by comparing an undirected coding process to assembling furniture without instructions, then promises a structured, AI-assisted path from Figma design to working Angular code. This lesson is one building block toward the section's goal: getting the tools, mental models, and motivation in place before touching Figma or Windsurf.
