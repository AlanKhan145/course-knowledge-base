## Main Idea

This lesson introduces Atomic Design, the mental model the entire course is built around for breaking a UI down into buildable pieces. Using a concrete UI component example, it walks through the five levels of the hierarchy: Atoms (buttons, inputs, labels), Molecules (small combinations of atoms), Organisms (complex sections like navbars), Templates (layout skeletons), and Pages (templates filled with real content). Seeing a single example traced through all five levels makes the abstract hierarchy concrete and memorable. This vocabulary becomes the shared language the course uses from here on to describe what's being built at every stage.

## Key Topics Mentioned

* Atomic Design as a component hierarchy
* Atoms: the smallest reusable UI pieces
* Molecules: small functional combinations of atoms
* Organisms: complex, complete UI sections
* Templates and Pages: layout skeletons versus real content
