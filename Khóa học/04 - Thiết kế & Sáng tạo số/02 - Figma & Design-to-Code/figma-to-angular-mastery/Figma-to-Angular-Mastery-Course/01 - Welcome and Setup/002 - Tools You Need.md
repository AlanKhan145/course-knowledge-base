## Main Idea

Before touching any code, this lesson lays out the exact toolchain the course relies on: Figma's free tier for design work, Angular 20 as the frontend framework, Tailwind CSS v4 for styling, and the Windsurf AI editor for generating and refining code. Each tool is given a short, plain-language explanation of the role it plays in the overall workflow, so learners understand why each piece is there before they install anything. Getting this list straight up front avoids confusion later when the course starts referencing these tools by name in rapid succession. Together, these four tools form the backbone of every hands-on exercise that follows in the rest of the course.

## Key Topics Mentioned

* Figma (free tier) as the design source of truth
* Angular 20 as the frontend framework used throughout the course
* Tailwind CSS v4 for utility-first styling
* Windsurf as the AI-powered code editor
* Why each tool exists in the workflow and how they connect to one another
