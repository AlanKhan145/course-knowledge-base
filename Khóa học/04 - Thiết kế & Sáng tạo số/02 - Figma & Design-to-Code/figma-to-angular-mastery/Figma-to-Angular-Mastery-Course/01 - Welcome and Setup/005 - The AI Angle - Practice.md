## Section

## Main Idea

This lesson makes the closing argument for why the course leans so heavily on an AI coding editor: Windsurf can generate Angular components far faster than typing every line by hand, freeing up time for design thinking and review instead of boilerplate. At the same time, it's careful to stress that speed is not the same as correctness -- a human still needs to read, test, and refine whatever the AI produces. This balanced framing sets expectations for the rest of the course: AI accelerates the mechanical work, but judgment and review remain the developer's job. It closes out the setup section by making the case for the AI-first workflow that every later section will put into practice.

## Key Topics Mentioned

* Why typing every component by hand is slow and repetitive
* Windsurf as a way to generate Angular/Tailwind code quickly
* The continued need for human review of AI-generated code
* Setting realistic expectations for what AI can and can't do well
