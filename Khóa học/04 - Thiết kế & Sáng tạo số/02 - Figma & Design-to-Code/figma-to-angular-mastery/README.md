## Requirements

- No coding experience required
- A free Figma account
- A computer with internet access
- The Windsurf Editor installed
- Node.js + Angular CLI are optional if you want to preview locally
- Curiosity about AI design-to-code workflows and clean, fast UI

## Tools Used

- Figma -- design handoff, inspect layout, export assets, design tokens
- Windsurf Editor -- AI-assisted coding to generate, refine, and debug Angular code
- Angular 20 -- the frontend framework
- Tailwind CSS v4 -- utility-first styling that maps Figma tokens to UI
- Storybook -- documents and tests components after the UI system is built

## What You Will Learn

- Convert Figma designs into Angular components using AI and Windsurf
- Apply Atomic Design: Atoms, Molecules, Organisms, Templates, Pages
- Read a Figma file like a developer: layout, spacing, CSS, component details
- Turn design tokens (colors, fonts, spacing) into Tailwind CSS config
- Build responsive Angular UI that matches a Figma frame exactly
- Use Windsurf to generate, refine, and debug Angular + Tailwind code
- Organize Angular components by Atomic hierarchy for maintainability and scale
