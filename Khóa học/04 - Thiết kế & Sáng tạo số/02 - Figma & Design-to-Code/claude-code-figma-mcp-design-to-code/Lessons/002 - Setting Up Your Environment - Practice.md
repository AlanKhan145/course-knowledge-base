# 002 - Setting Up Your Environment

## Section

Claude Code + Figma MCP Server for Design to Code

## Duration

0:29

## Main Idea

Walks through the three prerequisites needed before connecting Figma to Claude Code. First,
install Claude Code via `npm install -g @anthropic-ai/claude-code`. Second, a Figma Dev seat or
Full seat account is required, with at least one design file to work from — the presenter uses a
signup card design for the demo. Third, you need an actual project that needs the design
implemented — in this case, a React app using MUI (Material UI) components, where the signup page
still needs to be built. By the end of the lesson, learners should have Claude Code installed and
have both a Figma design and a target codebase ready before moving on to the MCP connection step.

## Key Topics Mentioned

* Installing Claude Code: `npm install -g @anthropic-ai/claude-code`
* Figma account requirement: Dev seat or Full seat, with at least one design file
* Demo design file: a signup card
* Demo codebase: an existing React + MUI app missing its signup page

## Summary

Covers the three prerequisites for the demo: installing Claude Code via npm, having a Figma Dev or
Full seat account with a design file, and having a target project (a React/MUI app) that needs the
design built. This lesson is the setup step that everything downstream — the MCP connection and
the actual design-to-code conversion — depends on.
