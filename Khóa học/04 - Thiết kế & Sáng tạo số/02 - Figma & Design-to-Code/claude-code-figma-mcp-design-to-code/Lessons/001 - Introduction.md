# 001 - Introduction

## Section

Claude Code + Figma MCP Server for Design to Code

## Duration

0:26

## Main Idea

Frames the problem the video is about to solve: every time a designer hands over a Figma file, a
developer effectively becomes a "human OCR machine," manually translating visual design into code.
A simple card component takes about 60 minutes; a full landing page can take half a week. The
video poses the alternative — pointing an AI directly at a Figma file and having it generate the
code — and names that as the promise of Claude Code combined with Figma's MCP (Model Context
Protocol) server. The rest of the video will show how to connect a Figma file to Claude Code for
an AI-driven, code-based design workflow.

## Key Topics Mentioned

* The "human OCR machine" problem: manually re-implementing Figma designs as code
* Rough time cost of manual hand-off: ~60 min for a simple card, ~half a week for a full landing page
* The pitch: point AI at a Figma file and have it generate code directly
* Naming the tools: Claude Code + Figma's MCP server

## Summary

Sets up the video's core promise: instead of manually re-implementing Figma designs as code (the
"human OCR" problem), you can point Claude Code at a Figma file via Figma's MCP server and have it
generate the code for you. This lesson is the framing for everything that follows — the setup, the
demo conversion, the limitations, and the alternative approach (Fusion) presented later.
