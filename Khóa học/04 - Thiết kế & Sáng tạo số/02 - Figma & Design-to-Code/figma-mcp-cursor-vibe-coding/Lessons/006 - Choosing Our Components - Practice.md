# 006 - Choosing Our Components

## Section

Vibe-Coding Figma Design System Components with Cursor & Figma MCP

## Duration

0:49

## Main Idea

Covers picking a scoped-down demo set of components in Figma so the exercise stays short enough
for a tutorial: instead of pulling the entire buttons group, a simplified "Button Demo" frame is
assembled with just default, default-hover, default-focus, and default-disabled states, plus
matching states for a subtle button, an outline button, and a transparent/ghost button. The
selection is then copied as a Figma link to hand off to Cursor. By the end of the lesson, learners
should see how Choosing Our Components connects to the next step, since this scoped link is what
Cursor will read to generate the actual React components.

## Key Topics Mentioned

* Scoping a demo selection instead of an entire component group to save time
* Button states covered: default, hover, focus, disabled
* Button variants covered: default, subtle, outline, transparent/ghost
* Copying a Figma link to a specific selection for use as a Cursor prompt input

## Summary

Covers assembling a scoped-down "Button Demo" selection in Figma — default, hover, focus, and
disabled states across default, subtle, outline, and transparent button variants — and copying its
link to hand off to Cursor. This lesson is one building block toward the section's goal: teaching
how to connect Cursor to Figma via the Figma MCP server, feed AI the right design-token context,
and vibe-code initial React design system components that stay wired to Figma variables.
