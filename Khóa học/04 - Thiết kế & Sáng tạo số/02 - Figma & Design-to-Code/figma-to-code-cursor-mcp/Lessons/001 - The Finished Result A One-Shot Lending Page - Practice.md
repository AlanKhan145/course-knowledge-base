# 001 - The Finished Result: A One-Shot Lending Page

## Section

Converting Figma Designs to Code with Cursor + Figma MCP

## Duration

1:01

## Main Idea

Opens with the finished product: a polished minimal lending page built entirely with Cursor plus
MCP, starting from nothing but a link to a Figma frame. The host stresses this isn't a static
mockup — buttons are hoverable, text is real text (not baked into an image), and images downloaded
automatically. The workflow was: open the design in Figma, right-click the frame, choose "Copy
link to selection," paste that link into Cursor, and let the AI take it from there. By the end of
the lesson, learners should understand the target outcome this whole video is building toward
before any of the setup steps are explained.

## Key Topics Mentioned

* The demo page was generated "completely by AI" using Cursor + MCP
* It's a working UI, not an image: real hoverable buttons, real text, auto-downloaded images
* Source workflow: Figma frame → right-click → "Copy link to selection" → paste into Cursor

## Summary

Sets up the video's goal by showing the finished lending page first: a fully interactive UI built
from a single Figma selection link via Cursor + MCP. This lesson is one building block toward the
section's goal: motivating why MCP is worth learning before walking through what it is and how to
set it up.
