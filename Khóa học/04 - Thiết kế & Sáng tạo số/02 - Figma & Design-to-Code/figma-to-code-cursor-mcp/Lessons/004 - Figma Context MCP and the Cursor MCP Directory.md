## Section

## Duration

## Main Idea

Names the specific MCP server used in this video's demo: an open source server on GitHub, referred
to as the "Figma Context MCP," which converts Figma designs into React code inside a project. It
works with Cursor, Windsurf, Cline, or any other MCP-capable client. The host then detours to a
broader resource — a directory of MCP servers curated for use with Cursor and other IDEs,
discovered via a colleague (Sean) — that lists MCPs for Google Drive, Puppeteer, to-do apps,
Docker, Figma, Postgres, GitHub, and more, with new ones being added regularly. The GitHub MCP
example is called out specifically: it can let an AI interact with a GitHub repo to create and
even review pull requests. By the end of the lesson, learners should know both the exact server
name used later in the video and where to browse for other MCP servers beyond Figma.

## Key Topics Mentioned

* Cursor's MCP directory: a curated list of available MCP servers (Figma, Google Drive, Puppeteer,
