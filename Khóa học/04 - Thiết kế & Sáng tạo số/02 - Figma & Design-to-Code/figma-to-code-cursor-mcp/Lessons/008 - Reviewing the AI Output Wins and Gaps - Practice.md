# 008 - Reviewing the AI Output: Wins and Gaps

## Section

Converting Figma Designs to Code with Cursor + Figma MCP

## Duration

2:34

## Main Idea

Walks through the first-pass result on the complex landing page with an honest, feature-by-feature
review. Strong points: the overall layout is correct, colors are near-perfect throughout, most
images resolved correctly, and interactive behavior works — an accordion section expands and
collapses on click. The team section, however, is called out as a clear miss: it looks close to
the design but lacks the "creative touch" (visual polish/personality) present in the original,
which the host frames as an expected limitation of AI output at this stage rather than a dealbreaker.
The host's overall reaction is enthusiastic: comparing this to a Figma-to-React tool tried 2–3
years ago that produced completely unusable code and layouts, today's one-shot result is different
in kind, not just degree — capable of turning what used to take one to two weeks into potentially
a single day, with some follow-up cleanup still required. By the end of the lesson, learners should
be able to list concrete strengths and weaknesses to check for in their own generations rather than
judging a result as simply "good" or "bad."

## Key Topics Mentioned

* Layout accuracy: correct from a layout perspective across the whole page
* Color accuracy: "literally everything" color-wise matched the design
* Images: mostly correct, with only minor gaps
* Interactivity: accordion section expands/collapses correctly on click
* Team section: visually close but missing the "creative touch" of the original design
* Historical comparison: a Figma-to-React tool from ~2–3 years ago produced unusable
  code/layouts, unlike today's result
* Reframing the time savings: potentially a single day of work instead of one to two weeks, with
  follow-up fixes still needed

## Review Questions

1. What is the main purpose of "Reviewing the AI Output" in the context of Converting Figma
   Designs to Code with Cursor + Figma MCP?
2. Which specific aspects of the generated landing page matched the Figma design closely, and
   which one (the team section) fell short?
3. How does the host's comparison to an older Figma-to-React tool change how you should interpret
   "the AI got the layout right"?
4. What risk or limitation should you keep in mind about treating a strong first-pass result as
   "done" without further review?

## Summary

Delivers a structured, honest review of the generated landing page — layout, color, images, and
interactivity all scored as strong, with the team section flagged as the clearest gap — while
framing the overall result against how far AI design-to-code tooling has progressed in a few
years. This lesson is one building block toward the section's goal: teaching learners how to
evaluate AI output critically instead of accepting or rejecting it wholesale.
