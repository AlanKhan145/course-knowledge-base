# 006 - Connecting Figma MCP Tools and Picking a Model

## Section

Converting Figma Designs to Code with Cursor + Figma MCP

## Duration

0:47

## Main Idea

Once the SSE connection is live, Cursor surfaces the tools the Figma MCP server exposes: two
tools in this case — one to fetch Figma design data, and one to download Figma images. The design
data tool reads layout, text, colors, and structure from a Figma file/selection; the image tool
downloads all images referenced in that design straight into the project. The host then gives
practical model advice: with a Cursor Pro plan, prefer Claude 3.7 Sonnet Thinking, 3.7 Sonnet, or
3.5 Sonnet Thinking for this kind of work — the host's own testing found 3.5 Sonnet Thinking to be
the strongest of the Sonnet family for this task, while noting results vary case by case. By the
end of the lesson, learners should know which two tools to expect from a working Figma MCP
connection and which model family to reach for.

## Key Topics Mentioned

* Two exposed Figma MCP tools: fetch Figma design data, and download Figma images
* Design data tool covers layout, text, color, and structure from a Figma file/selection
* Image tool downloads all images referenced in the design directly into the project
* Model recommendation (Cursor Pro): Claude 3.7 Sonnet Thinking, 3.7 Sonnet, or 3.5 Sonnet
  Thinking
* Host's personal finding: 3.5 Sonnet Thinking performed best among the Sonnet options tested,
  though results vary

gives concrete model guidance for the generation step that follows. This lesson is one building
