# 001 - Introduction to the Design-to-Code Workflow

## Section

Module 1: Introduction & Course Overview

## Duration

0:36

## Main Idea

Sets up the whole tutorial: taking a design from Figma, through Cursor, and out the other end as
a working iOS app. The presenter previews the full pipeline (Figma → Figma MCP Server → Cursor →
ReactJS/iOS app) and names the product to be built — a finance/wallet app — along with the tool
list required: Figma, Cursor, an MCP server, Expo, and Xcode/iOS Simulator.

## Key Topics Mentioned

* Overall pipeline: Figma → Figma MCP → Cursor → ReactJS → iOS app
* Final product: a wallet/finance app
* Required tools: Figma, Cursor, Figma MCP Server, Expo, Xcode/iOS Simulator
* The video is framed as a fast, practical walkthrough rather than a deep-dive

## Review Questions

1. What is the full pipeline this tutorial walks through, from design file to installed app?
2. Which five tools does the workflow require, and what role does each play?
3. Why might a wallet/finance app be a useful demo product for this kind of pipeline (interactive
   states, multiple screens, brand-consistent styling)?

## Summary

A short cold-open naming the end-to-end workflow (Figma → MCP → Cursor → ReactJS/iOS) and the
demo product (a wallet app), plus the tool stack needed to follow along: Figma, Cursor, Figma MCP
Server, Expo, and Xcode/iOS Simulator.
