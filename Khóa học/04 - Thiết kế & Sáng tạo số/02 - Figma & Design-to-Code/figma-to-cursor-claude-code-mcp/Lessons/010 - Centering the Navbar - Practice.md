# 010 - Centering the Navbar

## Section

From Figma to Cursor & Claude Code with MCP — Building Sidebling.com

## Duration

0:53

## Main Idea

A small, targeted follow-up prompt fixes the navbar alignment issue spotted in the previous
review: "Please center the navbar. The whole logo plus menu should remain centered in the
viewport." The instructor zooms into the layout on a 4K screen to confirm the logo and menu were
stuck to the left edge instead of being centered, sends the fix, and the agent briefly shows an
odd "processing" state before successfully applying the correction.

## Key Topics Mentioned

* Prompt: "Please center the navbar. The whole logo plus menu should remain centered in the
  viewport."
* Zooming in on a high-resolution display to confirm the exact defect before prompting
* Small, single-issue prompts instead of re-running the whole generation

## Review Questions

1. What is the main purpose of writing a single-issue prompt instead of regenerating everything?
2. How would you apply this "small fix" pattern to other layout issues you spot?
3. What specific defect does this prompt target, and how is it verified before and after?
4. What risk is there in re-prompting for a full regenerate every time one small issue appears?

## Summary

Demonstrates fixing one specific, isolated layout bug (an off-center navbar) with a short, targeted
prompt rather than regenerating the whole UI. This lesson is one building block toward the
section's goal of showing how iterative, small prompts keep the AI-coding workflow controllable
and fast to verify.
