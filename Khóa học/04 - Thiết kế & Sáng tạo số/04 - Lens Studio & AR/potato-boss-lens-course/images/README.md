# Ảnh minh họa

Thư mục này được thiết kế để chứa 8 ảnh từ tutorial gốc.

Môi trường đóng gói hiện tại xem được các ảnh nguồn nhưng máy sandbox không tải được binary trực tiếp từ host AR Bootcamp. Hãy chạy một trong hai file ở thư mục gốc:

- `download_images.ps1` trên Windows PowerShell
- `download_images.py` nếu có Python

Danh sách URL gốc nằm trong `sources/source-links.md`.
