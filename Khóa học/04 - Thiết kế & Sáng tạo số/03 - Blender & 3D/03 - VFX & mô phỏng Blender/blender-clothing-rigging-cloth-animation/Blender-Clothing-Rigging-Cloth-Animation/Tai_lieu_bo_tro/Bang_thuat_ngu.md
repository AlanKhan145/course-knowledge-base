# Bảng thuật ngữ Blender: Trang phục và animation

| Thuật ngữ | Nghĩa trong khóa học |
| --- | --- |
| `Armature` | Hệ khung xương điều khiển mesh nhân vật. |
| `Bone` / `Pose Bone` | Xương và đối tượng xương khi tạo tư thế. |
| `DEF` | Nhóm xương trực tiếp biến dạng lưới được skin. |
| `MCH` | Xương cơ chế, tính quan hệ/constraint trung gian. |
| `CTRL` | Xương điều khiển được animator chọn và keyframe. |
| `Rigify` | Hệ công cụ hỗ trợ sinh rig Blender. |
| `Mixamo` | Nguồn rig/animation để tải FBX thực hành. |
| `Skinning` | Gán mesh vào xương thông qua vertex groups và weight. |
| `Weight Paint` | Chỉnh trọng số ảnh hưởng xương tại từng vertex. |
| `Vertex Group` | Tập vertex cùng các trọng số được dùng bởi bone hoặc modifier. |
| `Parenting` | Liên kết đối tượng hoặc xương theo quan hệ cha–con. |
| `Symmetrize` | Tạo xương đối xứng theo quy ước tên `.L`/`.R`. |
| `Armature Modifier` | Modifier biến dạng mesh theo hệ xương. |
| `Copy Location/Rotation/Scale` | Constraint sao chép thành phần biến đổi. |
| `Copy Transforms` | Constraint theo biến đổi tổng hợp của target. |
| `Damped Track` | Constraint định hướng xương về target. |
| `B-Bone` | Bendy Bone, dạng xương có khả năng uốn cong trong Blender. |
| `Cloth` | Hệ mô phỏng động lực học vải. |
| `Pin Group` | Vertex group quyết định vùng ghim, chuyển từ cứng sang mềm. |
| `Collision` | Thuộc tính để đối tượng tương tác va chạm với hệ vật lý. |
| `Self Collision` | Cho các phần trong cùng mesh vải va chạm lẫn nhau. |
| `Proxy Collider` | Bản sao hình học đơn giản hóa chỉ dùng cho va chạm. |
| `Shrinkwrap` | Modifier kéo mesh gần bề mặt target. |
| `Surface Deform` | Modifier giúp một mesh biến dạng theo bề mặt khác sau Bind. |
| `Shape Key` | Các trạng thái hình dạng của mesh để pha trộn/che clipping. |
| `Mask Modifier` | Modifier ẩn/giữ nhóm hình học theo vertex group. |
| `Solidify` | Modifier tạo độ dày cho bề mặt vải. |
| `Subdivision Surface` | Modifier tăng độ mịn bề mặt/mật độ lưới. |
| `Bake Cache` | Tính và lưu trước kết quả mô phỏng. |
| `Bake Action` | Ghi chuyển động đánh giá của pose bone thành keyframe. |
| `Empty` | Đối tượng rỗng làm mốc biến đổi/trung gian. |
| `Vertex (Triangle) Parenting` | Empty/object theo ba đỉnh để có cả vị trí và hướng. |
| `FBX` | Định dạng phổ biến trao đổi model xương và animation. |
| `Clipping` | Hai bề mặt mesh cắt xuyên nhau. |
| `Rest Pose` / `T-pose` | Tư thế ổn định để bind, đặt cloth hoặc kiểm thử. |
