# Phụ lục 1 - Glossary thuật ngữ và ký hiệu

## 1. Cột sống

| Ký hiệu/thuật ngữ | Nghĩa trong bài báo |
| --- | --- |
| T | Tổng số đốt sống trong công thức cấu trúc cột sống |
| a1 | Số đốt predorsal nằm trước pterygiophore đầu tiên của vây lưng |
| A | Số đốt abdominal theo quy ước nghiên cứu |
| i | Số đốt intermediate: abdominal vertebrae có parapophyses hợp với centrum và không khớp với ribs |
| c1 | Số đốt caudal trước pterygiophore đầu tiên của vây hậu môn |
| C | Số đốt caudal theo quy ước công thức |
| c2 | Số đốt caudal phía sau pterygiophore đầu tiên của vây hậu môn |
| VH | Vertebral height |
| VL | Vertebral length |
| Vi | Vertebral index, Vi = P/SL |
| SL | Standard length |
| TL | Total length |

## 2. Vây và vùng đuôi

| Ký hiệu/thuật ngữ | Nghĩa trong bài báo |
| --- | --- |
| Pterygiophore | Phần tử xương nâng đỡ tia vây, được phân tích theo quan hệ với neural/haemal spines |
| PU1, PU2, ... | Preural vertebrae; PU1 là đốt preural cuối cùng theo quy ước nguồn |
| NSPU2-5 | Neural spine của preural vertebrae 2-5 |
| HSPU2-5 | Haemal spine của preural vertebrae 2-5 |
| E | Epural bone |
| PLS | Pleurostyle |
| UN | Uroneural |
| H | Hypural bones |
| PH | Parhypural bone |
| DPR | Dorsal procurrent rays |
| VPR | Ventral procurrent rays |
| BCFR | Branched caudal fin rays |
| UBCFR | Unbranched caudal fin ray |
| IMB | Intermuscular bones |

## 3. Cách dùng glossary

Các định nghĩa trên chỉ phản ánh cách bài báo sử dụng thuật ngữ và ký hiệu. Khi cần mô tả hình thái định lượng của các xương caudal (dài/ngắn, rộng/hẹp), xem ảnh Table 4 trong `assets/tables/`.
