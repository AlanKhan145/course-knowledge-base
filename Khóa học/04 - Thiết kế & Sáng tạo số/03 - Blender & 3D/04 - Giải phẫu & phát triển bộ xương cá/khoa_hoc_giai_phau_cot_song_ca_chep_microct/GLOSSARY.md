# Glossary - Thuật ngữ chính

| Thuật ngữ | Giải thích trong ngữ cảnh khóa học |
|---|---|
| Amphicoelous | centrum lõm ở cả hai đầu |
| Centrum / vertebral body | thân đốt sống |
| Neural arch | cung thần kinh |
| Neural spine | mỏm thần kinh |
| Hemal arch | cung huyết |
| Hemal spine | mỏm huyết |
| Trabeculae | các thanh/phiến xương tạo mạng bên trong |
| Abdominal vertebrae | nhóm đốt vùng thân trước |
| Transitional vertebrae | nhóm đốt chuyển tiếp |
| Caudal vertebrae | nhóm đốt vùng đuôi |
| Preural vertebrae | các đốt ngay trước phức hợp tận cùng của đuôi |
| Urostyle complex | phức hợp xương tận cùng của trục đuôi |
| Epural | xương ở phần lưng của phức hợp đuôi |
| Pleurostyle | thành phần xương liên quan tới phía lưng của urostyle complex |
| Hypural | nhóm xương nâng đỡ tia vây đuôi |
| Parhypural | thành phần xương phía bụng của phức hợp đuôi |
| Micro-CT | chụp cắt lớp vi tính độ phân giải cao để tái tạo 3D |
| SEM | scanning electron microscopy |
| EDX | energy-dispersive X-ray spectroscopy |
| H&E | nhuộm hematoxylin và eosin |
| Picrosirius | phương pháp nhuộm hỗ trợ quan sát collagen dưới ánh sáng phân cực |
| Osteoclast | tế bào liên quan tới tiêu xương |
| Howship lacunae | hõm bề mặt xương thường liên quan hoạt động tiêu xương |
| Mineralization | quá trình khoáng hóa mô xương |
