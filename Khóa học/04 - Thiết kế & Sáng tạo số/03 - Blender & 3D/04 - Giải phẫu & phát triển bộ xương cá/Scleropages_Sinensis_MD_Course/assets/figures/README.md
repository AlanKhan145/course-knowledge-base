# Ảnh tách từ PDF nguồn

Các file trong thư mục này được tách trực tiếp từ PDF Zhang & Wilson (2017) do người dùng cung cấp. Tên file đã được chuẩn hóa theo số hình trong bài báo.

- `fig01` đến `fig09` tương ứng Figure 1 đến Figure 9.
- Ảnh được chuyển sang RGB khi cần để tăng khả năng tương thích với trình xem Markdown.
- Không thay đổi nội dung khoa học của hình; chỉ đổi định dạng/màu không gian khi cần cho khả năng mở file.
