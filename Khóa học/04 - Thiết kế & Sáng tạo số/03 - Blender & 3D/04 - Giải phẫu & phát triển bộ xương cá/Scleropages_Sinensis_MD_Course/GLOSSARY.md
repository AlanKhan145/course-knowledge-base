# Bảng thuật ngữ giải phẫu và cổ sinh học

| Thuật ngữ | Giải thích ngắn |
| --- | --- |
| `Osteoglossomorpha` | Nhóm cá xương lưỡi, bao gồm Osteoglossidae và các nhóm liên quan. |
| `Osteoglossidae` | Họ cá rồng/cá xương lưỡi mà `Scleropages` thuộc về. |
| `holotype` | Mẫu chuẩn tên dùng làm cơ sở mô tả một loài mới. |
| `fusiform` | Dạng thân thuôn hình thoi, rộng hơn ở giữa và hẹp về hai đầu. |
| `infraorbital` | Xương quanh hốc mắt, phía dưới hoặc sau mắt. |
| `opercle` | Xương nắp mang chính. |
| `preopercle` | Xương nằm trước nắp mang. |
| `cleithrum` | Xương lớn của đai vai ở cá xương. |
| `supracleithrum` | Xương ở phía trên cleithrum, thuộc đai vai. |
| `pterygiophore` | Cấu trúc xương nâng đỡ tia vây giữa. |
| `centrum` | Phần thân chính của một đốt sống. |
| `neural spine` | Gai thần kinh hướng về phía lưng từ đốt sống. |
| `haemal spine` | Gai huyết hướng về phía bụng ở vùng đuôi. |
| `preural centrum` | Đốt sống nằm ngay trước vùng ural của bộ xương đuôi. |
| `ural centrum` | Trung tâm đốt sống ở phần cuối cột sống, liên quan trực tiếp đến bộ xương đuôi. |
| `hypural` | Các bản xương đuôi nâng đỡ phần lớn tia vây đuôi. |
| `uroneural` | Xương dạng que ở phần lưng của bộ xương đuôi teleost. |
| `procurrent ray` | Tia vây ngắn nằm trước các tia chính của vây đuôi/dorsal/anal. |
| `cycloid scale` | Vảy mỏng, mép sau không có gai cứng kiểu ctenoid. |
| `squamule` | Đơn vị nhỏ tạo nên hoa văn lưới đặc trưng trên vảy của osteoglossid. |
| `lateral line` | Hệ thống đường bên cảm nhận dao động và chuyển động của nước. |
| `synapomorphy` | Đặc điểm tiến hóa dẫn xuất dùng để nhận biết một nhóm có chung tổ tiên. |
| `mouthbrooding` | Kiểu ấp trứng hoặc giữ cá non trong khoang miệng. |
| `vicariance` | Sự chia cắt phân bố do xuất hiện rào cản địa lý. |
| `marine dispersal` | Phát tán qua môi trường biển. |
