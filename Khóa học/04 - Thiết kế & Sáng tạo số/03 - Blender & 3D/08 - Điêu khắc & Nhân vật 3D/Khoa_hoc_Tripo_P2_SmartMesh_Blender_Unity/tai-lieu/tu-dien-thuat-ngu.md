# Từ điển thuật ngữ

| Thuật ngữ | Nghĩa dùng trong khóa học |
|---|---|
| **Mesh** | Hình học 3D gồm vertices, edges và faces |
| **Vertex / Edge / Face** | Đỉnh / cạnh / mặt |
| **Topology** | Cách các đỉnh, cạnh, mặt liên kết với nhau |
| **Quad / Triangle** | Mặt tứ giác / mặt tam giác |
| **Edge Loop** | Chuỗi cạnh có hướng liên tục; quan trọng quanh mắt/miệng/khớp |
| **Retopology** | Xây/sửa lưới theo cấu trúc phù hợp biến dạng |
| **Mirror** | Phản chiếu hình học đối xứng |
| **Merge / Weld** | Hàn các đỉnh; khác với Join Objects |
| **Origin** | Gốc transform của đối tượng |
| **Normals / Face Orientation** | Hướng pháp tuyến / hướng mặt trước sau |
| **UV / UV Island / Seam** | Bản đồ 2D / vùng UV / đường rạch UV |
| **Texture Paint** | Vẽ trực tiếp trên texture/bề mặt |
| **Shape Key / Blendshape** | Trạng thái biến đổi hình học để tạo biểu cảm |
| **Armature / Bone** | Hệ xương / xương điều khiển |
| **IK / FK** | Inverse/Forward Kinematics |
| **Bind / Skinning** | Gắn mesh với ảnh hưởng của hệ xương |
| **Weight Paint** | Điều chỉnh trọng số xương lên vertices |
| **Iris / Sclera / Eyelash** | Mống mắt / lòng trắng mắt / lông mi |
| **Retarget** | Chuyển động tác từ rig này sang rig khác |
| **Game-ready** | Đủ chất lượng cho use case game cụ thể; không đồng nghĩa hoàn hảo |

> Bản chép lời tiếng Việt tự động có các từ sai ngữ cảnh như "cây diên vĩ", "thi thể", "thân xe", "cần đàn". Trong khóa học các cụm này được chuẩn hóa theo ngữ cảnh 3D thành **mống mắt (iris)**, **cơ thể/thân**, **cổ**, v.v.
