# Bảng thuật ngữ & phím tắt — AI 3D Game-Ready

| Thuật ngữ | Diễn giải |
|---|---|
| A-pose / T-pose | Tư thế chuẩn bị rig; tay chéo xuống nhẹ hoặc ngang vai |
| High-poly / Low-poly | Bản chi tiết cao / bản tối ưu cho runtime |
| Retopology | Tổ chức lại mạng lưới đỉnh/cạnh/mặt để sạch và biến dạng tốt |
| Quad / Triangle | Mặt 4 đỉnh / mặt 3 đỉnh |
| Seam / UV Island | Đường cắt UV / mảng bề mặt được trải phẳng |
| Baking | Chuyển thuộc tính geometry/shader thành map texture |
| Normal Map | Map giả lập hướng bề mặt để giữ cảm giác chi tiết |
| Ambient Occlusion | Map che khuất vùng khe/hốc |
| PBR | Kết xuất vật liệu dựa trên mô hình vật lý |
| Metallic / Roughness | Tính kim loại / độ nhám phản xạ |
| Armature / Skinning | Xương điều khiển / gán độ ảnh hưởng xương lên mesh |
| Weight Paint | Chỉnh trọng số bone bằng sơn màu |
| Atlas | Texture chung cho nhiều vùng UV/object |

## Phím tắt trong Blender được nhắc tới hoặc áp dụng

| Phím | Mục đích (theo chế độ) |
|---|---|
| `G` | Di chuyển |
| `R` | Xoay |
| `S` | Đổi tỷ lệ |
| `X`, `Y`, `Z` sau G/R/S | Khóa trục |
| `Ctrl + A` | Apply Transform trong Object Mode |
| `Shift` khi sculpt | Smooth tạm thời với nhiều cọ |
| `E` trong Edit Mode | Extrude |
| `A` trong Edit Mode | Select All |
| `Alt + H` | Hiện object/đỉnh đang ẩn (tùy mode) |
| `Shift + H` | Ẩn phần không chọn (tùy mode) |

> Phím tắt và tên lệnh có thể bị đổi bởi keymap/add-on. Kiểm tra menu nếu phím không hoạt động.
