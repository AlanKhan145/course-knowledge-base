# Phụ lục. Bảng phím tắt Blender dùng trong khóa học

## 1. Điều hướng viewport

| Phím | Mục đích |
| --- | --- |
| `Numpad 1` | Nhìn trước (Front) |
| `Ctrl + Numpad 1` | Nhìn sau (Back) |
| `Numpad 3` | Nhìn cạnh (Right) |
| `Numpad 7` | Nhìn trên (Top) |
| `Numpad 5` | Perspective / Orthographic |
| `Numpad .` | Phóng viewport đến vùng chọn |
| Chuột giữa kéo | Quay góc nhìn |
| `Z` mở shading pie | Chọn Wireframe, Solid... |

## 2. Chế độ, lựa chọn và biến đổi

| Phím | Mục đích |
| --- | --- |
| `Tab` | Object Mode / Edit Mode |
| `1`/`2`/`3` hàng phím số trong Edit Mode | Vertex / Edge / Face Select |
| `A` | Chọn tất cả |
| `Alt + A` | Bỏ chọn tất cả (thiết lập mặc định thường dùng) |
| `B` | Box Select |
| `L` | Chọn hình học liên kết dưới con trỏ |
| `Alt + Click` cạnh | Chọn edge loop khi topology phù hợp |
| `G` | Di chuyển |
| `S` | Thay đổi kích thước |
| `R` | Xoay |
| `G → X`, `S → Z`, `R → Y`... | Giới hạn biến đổi theo trục |
| `S → Z → 0` | Làm phẳng theo Z, chú ý Pivot Point |
| `Shift + D` | Nhân bản lựa chọn |
| `Ctrl + Z` | Hoàn tác |
| `Ctrl + S` | Lưu |

## 3. Modeling và topology

| Phím / lệnh | Mục đích |
| --- | --- |
| `Shift + A` | Thêm đối tượng hoặc mesh |
| `Ctrl + R` | Loop Cut |
| `K` | Knife |
| `E` | Extrude |
| `I` | Inset |
| `Ctrl + B` | Bevel cạnh |
| `Ctrl + Shift + B` | Bevel đỉnh |
| `F` | Fill face |
| `X → Faces / Vertices` | Xóa mặt / đỉnh |
| `X → Dissolve Edges` | Loại cạnh giữ mặt khi hợp lệ |
| `Shift + N` | Recalculate Normals Outside |
| `F3` → tìm Bridge Edge Loops | Nối hai vòng biên |
| `P → Selection` | Tách selection thành object |
| `Ctrl + J` (Object Mode) | Join các object |
| `Shift + S` | Mở menu Snap cho 3D Cursor / Selection |

## 4. Tùy chọn theo công cụ

Một số phím như `I` (chuyển Inset Individual), `B` (Inset Boundary), `C` (Knife Cut Through) và các giới hạn hướng khi Knife đang chạy là **phím trong trạng thái công cụ**, không phải phím có nghĩa cố định ở mọi chế độ. Luôn nhìn thanh trạng thái hoặc hộp hướng dẫn trong phiên bản Blender đang dùng.

**Lưu ý:** `1` ở hàng số trên và `Numpad 1` là hai phím khác nhau. Khóa trục và menu có thể thay đổi theo keymap người dùng.
