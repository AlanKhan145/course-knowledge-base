# Glossary Anh - Việt

| Thuật ngữ | Diễn giải trong khóa học |
|---|---|
| Pectoral fin | Vây ngực |
| Fin ray | Tia vây |
| Dorsal leading ray | Tia dẫn phía lưng |
| Ventral leading ray | Tia dẫn phía bụng |
| Inner edge | Biên trong, sát thân |
| Outer edge | Biên ngoài, xa thân |
| BCF | Body and Caudal Fin - chuyển động dựa chủ yếu vào thân và vây đuôi |
| MPF | Median and/or Paired Fin - chuyển động dựa vào vây giữa và/hoặc vây đôi |
| Retreating | Bơi lùi |
| Hovering | Giữ vị trí/lơ lửng tương đối ổn định trong nước |
| In-stroke | Pha thu/quạt vây vào |
| Out-stroke | Pha quạt/mở vây ra |
| Expansion | Mở rộng bề mặt vây |
| Bending | Uốn cong |
| Cupping | Tạo dạng lòng/chén |
| Undulation | Gợn sóng, chuyển động có trễ pha dọc các tia |
| Span-wise | Theo phương sải/rộng của vây |
| Chord-wise | Theo phương dây cung của vây |
| SVD | Singular Value Decomposition |
| Singular value | Giá trị kỳ dị trong SVD |
| Principal mode | Mode chính |
| Residual mode | Mode dư/cấp thấp hơn trong phổ đóng góp |
| Marker | Điểm đánh dấu dùng để tracking |
| High-speed photography | Chụp/quay tốc độ cao |
| Morphological processing | Xử lý hình thái ảnh: dilation, erosion, opening, closing |
