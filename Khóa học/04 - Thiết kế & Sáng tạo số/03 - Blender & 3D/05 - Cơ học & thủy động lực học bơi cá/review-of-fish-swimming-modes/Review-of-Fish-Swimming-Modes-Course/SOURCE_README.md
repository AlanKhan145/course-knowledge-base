# Gói Review of Fish Swimming Modes

Gói này gồm:

- `Review_of_Fish_Swimming_Modes_VI.md`: tài liệu tiếng Việt chi tiết, biên soạn lại toàn bộ paper.
- `figures/`: 15 hình/diagram chính đã crop theo figure, dùng trực tiếp trong Markdown.
- `images_raw/`: 23 raster/ảnh nhúng được tách trực tiếp từ PDF, kèm `README.md` thống kê kích thước.
- `source/Review_of_Fish_Swimming_Modes.pdf`: PDF gốc người dùng cung cấp.

Mở file `.md` từ thư mục gốc để các đường dẫn ảnh tương đối hoạt động đúng.
