# Formula Sheet

## 1. Kinematics carangiform

\[
y(x,t)=a(x)\sin(k_wx-\omega t)
\]

\[
a(x)=c_1x+c_2x^2
\]

\[
k_w=\frac{2\pi}{\lambda}
\]

\[
c_p=\frac{\omega}{k_w}
\]

## 2. Strouhal number

\[
St=\frac{fA}{U}
\]

## 3. Potential flow

\[
\nabla^2\Phi=0
\]

\[
\Phi=\Phi_b+\Phi_w
\]

## 4. Discrete panel system

\[
[\tilde Q]\{\phi_b\}=[\tilde P]
\]

## 5. Circulation từ velocity field

\[
\Gamma=\oint \mathbf u\cdot d\mathbf l
\]

## 6. Hydrodynamic propulsive efficiency

\[
\eta=\frac{U\overline T_b}{\overline P_b}
\]

## 7. Ký hiệu nhanh

| Ký hiệu | Ý nghĩa |
|---|---|
| \(L\) | body length |
| \(U\) | swimming speed |
| \(f\) | tail-beat frequency |
| \(A\) | tail lateral double amplitude / excursion dùng trong St |
| \(\lambda\) | backbone wavelength |
| \(\omega\) | circular frequency |
| \(k_w\) | backbone wavenumber |
| \(\Gamma\) | circulation |
| \(\omega_z\) | vorticity component vuông góc plane |
| \(C_P\) | pressure coefficient |
| \(S_b\) | body surface |
| \(S_w\) | wake surface |
