# Thuật ngữ cốt lõi

| Thuật ngữ | Ý nghĩa trong khóa học |
|---|---|
| Labriform propulsion | Kiểu vận động trong đó vây ngực là bộ phận tạo lực đẩy chính. |
| Rowing | Quỹ đạo quạt thiên về trước-sau, thường gắn với lực đẩy tức thời và khả năng cơ động. |
| Flapping | Quỹ đạo quạt thiên về lưng-bụng, thường gắn với tốc độ duy trì và hiệu quả bơi cao hơn. |
| Pectoral girdle | Đai vây ngực, gồm các thành phần xương như cleithrum, coracoid và scapula. |
| Cleithrum (CL) | Xương lớn của đai vây ngực, là nơi bám của nhiều nhóm cơ. |
| Coracoid (CO) | Thành phần xương của đai vây, liên hệ với cleithrum và radials. |
| Scapula (SC) | Thành phần đai vây khớp với radials và tham gia vùng gốc vây. |
| Radials (RA) | Các phần tử xương gần gốc vây, truyền chuyển động từ đai vây sang tia vây. |
| Fin rays (FR) | Tia vây; mỗi tia gồm hai hemitrichia. |
| Hemitrichia | Hai nửa cấu thành một tia vây. |
| Aspect ratio (AR) | Chỉ số hình dạng mô tả mức độ thon/dài của vây; bài báo dùng AR để so sánh chiến lược bơi. |
| Leading edge | Mép trước của vây theo hướng chuyển động. |
| Trailing edge | Mép sau của vây. |
| ABS | Abductor superficialis. |
| ABP | Abductor profundus. |
| ARRV | Arrector ventralis. |
| ADS | Adductor superficialis. |
| ADM | Adductor medialis; không hiện diện ở tất cả loài khảo sát. |
| ADP | Adductor profundus. |
| ARRD | Arrector dorsalis. |
| ADR | Adductor radialis. |
| PCA | Principal Component Analysis, dùng để mô tả các trục biến thiên chính của tỷ lệ khối lượng cơ. |
| Intraradial ligaments | Hệ dây chằng nối giữa các radials và giữa radial với scapula/tia vây. |
