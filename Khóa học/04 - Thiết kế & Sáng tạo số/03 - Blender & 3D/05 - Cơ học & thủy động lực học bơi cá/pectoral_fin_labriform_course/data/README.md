# Dữ liệu đi kèm

## `table-01-taxa-fin-rays.csv`

Chuyển từ Table 1 của bài báo, gồm 12 loài, vị trí chèn ADP/ADR, tổng số tia vây và các tia không phân nhánh.

## `appendix-raw-muscle-masses.csv`

Chuyển từ Appendix trang 18. Các cột ABS, ABP, ARRV, ADS, ADP và ARRD là khối lượng tính bằng gram. `TL_mm` là total length; `BM_g` là body mass.

Dữ liệu được giữ theo nội dung bài báo. Khi dùng cho phân tích định lượng, nên đối chiếu PDF gốc nếu gặp giá trị bất thường hoặc lỗi định dạng từ bản in.
