# Thuật ngữ và phím tắt tham khảo

| Từ | Giải thích ngắn |
|---|---|
| Mesh | Lưới đỉnh/cạnh/mặt xác định bề mặt 3D |
| High-poly / low-poly | Mô hình nhiều/ít mặt tương đối so với mục tiêu |
| Tri / Quad | Mặt tam giác / tứ giác |
| Sculpt | Nắn/chải bề mặt mesh bằng brush |
| Remesh | Tạo lại phân bố lưới trên một hình khối |
| Retopology | Vẽ lại lưới có edge flow phù hợp chỉnh/rig |
| Mirror / X Symmetry | Đối xứng geometry hoặc nét sculpt |
| Voxel Remesh | Tái dựng lưới dựa vào khối voxel |
| Edge loop | Chuỗi cạnh tạo vòng quanh khu vực |
| UV Unwrap | Trải surface 3D ra bản đồ 2D |
| Mark Seam | Đánh dấu đường cắt UV |
| UV Island | Mảnh bề mặt liên tục trong UV 2D |
| Texture atlas | Một ảnh chứa texture của nhiều vùng/bộ phận |
| AO / Bake | Che khuất môi trường / ghi kết quả vào texture |
| Rig / Armature | Hệ xương điều khiển model |
| Skinning / Weight | Gán ảnh hưởng xương lên đỉnh mesh |
| IK | Cơ chế giải ngược vị trí khớp |
| Shape Key | Biến thể hình học để nội suy biểu cảm |
| Cel-shading | Shading mô phỏng tranh 2D theo cấp sáng |

## Một số thao tác được nhắc trong transcript
| Phím / thao tác | Ý nghĩa thường gặp (tùy mode/keymap) |
|---|---|
| `Shift+D` | Nhân bản object/selection |
| `H` / `Alt+H` | Ẩn / hiện phần đã ẩn |
| `Ctrl+A` | Apply transform trong Object Mode |
| `S` / `G` / `R` | Scale / Move / Rotate |
| `E` | Extrude trong Edit Mode |
| `F` | Chỉnh radius brush khi phù hợp |
| `A` | Chọn toàn bộ trong Edit/UV |
| `/` numpad (Local View) | Cô lập object đang chọn (phụ thuộc keymap) |
| `Alt` + click cạnh | Chọn edge loop trong nhiều keymap |
| `Ctrl+L` | Chọn connected geometry trong Edit Mode |
| `M` | Move to Collection trong Object Mode (tùy ngữ cảnh) |
| `N` | Toggle sidebar trong 3D View |
| `Shade Smooth` | Thay đổi shading normal, không giảm mặt |

> Không học thuộc phím tắt trước khi hiểu đang ở **Object / Edit / Sculpt / Pose / Texture Paint** nào. Menu và keymap có thể thay đổi theo Blender phiên bản.
