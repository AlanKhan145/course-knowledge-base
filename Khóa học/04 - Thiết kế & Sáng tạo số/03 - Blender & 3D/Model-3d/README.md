1. Học pipeline AI 3D đến game-ready trong Module 01.
2. Chọn thêm một nhánh thực hành: ComfyUI/Unreal, Tripo, hoặc Unity/Unreal.
3. Sang Module 03 nếu cần rig và animation chuyên sâu.
4. Học Module 04 để dựng môi trường Blender hoàn chỉnh.
