# Tài liệu bổ trợ — Thuật ngữ và phím tắt

## Thuật ngữ
| Tên | Nghĩa ngắn |
|---|---|
| Polygon / Triangle | Mặt đa giác / mặt tam giác của mesh |
| High-poly / Low-poly | Mesh có nhiều / ít mặt; không phải nhãn chất lượng tuyệt đối |
| Decimate | Giảm số mặt trên topology hiện tại |
| Retopology | Tái xây cấu trúc lưới / luồng cạnh |
| Quad | Mặt có 4 cạnh, thường hữu ích khi tạo edge loops |
| Silhouette | Đường viền hình dạng nhìn từ camera |
| Pivot / Origin | Điểm gốc dùng trong transform và quay đối tượng |
| UV Island | Một vùng mặt mesh được trải thành mảng trên ảnh 2D |
| Bake | Ghi thông tin màu/normal/ánh sáng thành texture |
| Selected to Active | Nướng từ đối tượng đã chọn sang đối tượng cuối cùng đang active |
| Base Color / Diffuse | Màu bề mặt không cộng ánh sáng trực tiếp (ở workflow Color only) |
| Normal map | Dữ liệu thay đổi pháp tuyến ảo cho shading |
| Metallic / Roughness | Điều khiển đặc tính kim loại / độ nhám |
| Emission mask | Ảnh quy định vị trí vật liệu tự phát sáng |
| Bloom | Hậu kỳ tạo quầng sáng quanh vùng rất sáng |
| Armature / Rig | Bộ xương và hệ điều khiển chuyển động |
| Skin weights | Độ ảnh hưởng của xương lên từng đỉnh |
| Retargeting | Chuyển animation từ skeleton này sang skeleton khác |
| Skeletal Mesh | Mesh có liên kết hệ xương trong Unreal |

## Phím tắt Blender
| Phím | Tác vụ phổ biến |
|---|---|
| `G` / `R` / `S` | Move / Rotate / Scale |
| `Tab` | Object/Edit Mode |
| `A` (Edit Mode) | Chọn tất cả vertices/faces |
| `Shift+D` | Duplicate |
| `Shift+S` | Menu Snap/3D Cursor |
| `Ctrl+A` | Apply transforms trong Object Mode |
| `U` (Edit Mode) | Menu UV Unwrap |
| `Shift+A` (Shader Editor) | Thêm node |
| `N` | Mở Sidebar |

> Phím và tên menu có thể thay đổi theo phiên bản Blender, keymap và editor đang active.
