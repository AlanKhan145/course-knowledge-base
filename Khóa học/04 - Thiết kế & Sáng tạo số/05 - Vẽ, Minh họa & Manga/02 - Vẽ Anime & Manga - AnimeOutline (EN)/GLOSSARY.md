# Essential English Drawing Vocabulary

| English term | Explanation | Example |
|---|---|---|
| Gesture | Fast line describing movement and action | A running pose begins with a gesture line. |
| Construction lines | Temporary marks to establish volumes and alignment | A face uses a centerline. |
| Silhouette | The outer shape of a form | A hairstyle should read in silhouette. |
| Landmark | Reliable reference point for proportions | The ear aligns with the head's side plane. |
| Foreshortening | Apparent shortening caused by depth orientation | A hand pointed at the viewer is foreshortened. |
| Vanishing point | Point toward which parallel receding lines converge | Room depth lines meet at one point. |
| Horizon line | Eye-level reference in perspective | The horizon crosses the room sketch. |
| Overlap | One contour hiding another in front | Front bangs cover part of the head. |
| Value | Lightness or darkness, independent of hue | A shadow uses a darker value. |
| Cel shading | Graphic shading using discrete flat regions | Shadows can use one clear tone. |
| Cast shadow | Shadow projected by one object onto another | Bangs cast a shadow on the forehead. |
| Form shadow | Darker part of a form facing away from light | The far cheek turns away from a lamp. |
| Line weight | Variation in line thickness | Thicker outlines emphasize foreground shapes. |
| Negative space | Empty region between or around shapes | Check space between fingers. |
| Rough | Exploratory drawing stage | Test proportions without polished contours. |
| Refined | Corrected, intentional finishing stage | Clean ink lines after construction. |
| Panel | Bounded sequence image in a comic | A manga page contains panels. |
| Speech balloon | Shape enclosing dialogue | Give the words room to breathe. |
| Thumbnail | Small composition sketch | Make several thumbnails before the final page. |
| Character sheet | Reference page for consistent design | Show the same character from three views. |
