# Anime & Manga Drawing — English Study Course

**An independent, structured learning course inspired by the public tutorial catalogue of [AnimeOutline](https://www.animeoutline.com/).**

This pack contains **62 separate English Markdown lessons**, **8 learning modules**, and **8 original schematic SVG illustrations**. The lesson pages provide guided practice, exercises, diagnostic questions, and precise links to the original tutorials. They do **not** reproduce AnimeOutline articles or distribute the site's copyrighted drawings.

## Recommended use

- Practice **4–5 sessions per week**, 25–45 minutes each.
- In each session: **5 min warm-up → 15 min rough construction → 15 min refinement → 5 min review**.
- Read the companion Markdown, then consult the linked AnimeOutline page for its original sequential illustration.
- Save every rough sketch and final version in a dated personal portfolio.

## Learning flow

```mermaid
flowchart LR
  A[Drawing fundamentals] --> B[Head construction]
  B --> C[Eyes and expression]
  C --> D[Hair and silhouette]
  D --> E[Body and gesture]
  E --> F[Clothing and accessories]
  F --> G[Light, color and perspective]
  G --> H[Characters and short manga]
```
