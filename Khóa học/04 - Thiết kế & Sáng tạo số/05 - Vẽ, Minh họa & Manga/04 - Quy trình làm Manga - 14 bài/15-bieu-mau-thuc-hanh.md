# Bộ biểu mẫu thực hành khóa học manga

## 1. Cách sử dụng

Sao chép các biểu mẫu dưới đây vào file Markdown riêng cho dự án của bạn. Các trường để trống là câu hỏi cần trả lời, không phải nội dung nên hiển thị trong manga hoàn chỉnh.

## 2. Biểu mẫu tiền đề

```text
Tên tạm của tác phẩm:
Thể loại và không khí:
Nhân vật chính:
Mục tiêu cụ thể:
Trở ngại chính:
Hệ quả nếu thất bại:
Điều thay đổi ở kết thúc:
Phạm vi truyện ngắn sẽ kể:
```

## 3. Biểu mẫu dòng thời gian

| Mốc thời gian | Sự kiện | Nguyên nhân | Hệ quả | Ai biết chuyện này? | Có hiện trên trang? |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

## 4. Biểu mẫu nhân vật

```text
Tên / vai trò:
Mong muốn:
Nhu cầu bên trong:
Điểm mạnh:
Điểm yếu:
Nỗi sợ:
Thói quen / kiểu nói:
Quan hệ chính:
Quyết định quan trọng nhất:
Thay đổi sau câu chuyện:
Silhouette và dấu hiệu nhận diện:
Chi tiết ngoại hình cần giữ nhất quán:
```

## 5. Biểu mẫu địa điểm / đạo cụ

```text
Tên:
Vai trò trong câu chuyện:
Vị trí hoặc kích thước tương đối:
Hình dáng từ trước / bên / sau:
Đặc điểm cố định:
Chức năng:
Giới hạn:
Ai sử dụng / ai sở hữu:
Mốc thời gian xuất hiện:
Tài liệu hoặc hình tham chiếu:
```

## 6. Biểu mẫu kịch bản cảnh

| Cảnh | Bối cảnh | Mục tiêu | Trở ngại | Quyết định | Kết quả | Thông tin cần hình ảnh hóa |
| --- | --- | --- | --- | --- | --- | --- |
| 1 |  |  |  |  |  |  |
| 2 |  |  |  |  |  |  |

## 7. Biểu mẫu storyboard / trang

| Trang | Panel | Cỡ khung | Hành động hoặc biểu cảm | Lời thoại | Hướng nhìn / chú ý |
| --- | --- | --- | --- | --- | --- |
| 1 | 1 |  |  |  |  |
| 1 | 2 |  |  |  |  |

## 8. Biểu mẫu nghiệm thu trước xuất bản

- [ ] Tất cả các trang đã được soát nội dung và chính tả.
- [ ] Thiết kế nhân vật, đạo cụ, bối cảnh nhất quán.
- [ ] Đã kiểm tra chiều đọc và thứ tự trang.
- [ ] Đã kiểm tra chữ và screentone ở kích thước thực.
- [ ] Font, hình ảnh và tài nguyên có quyền sử dụng phù hợp.
- [ ] Đã đối chiếu thông số xuất với nhà in hoặc nền tảng.
- [ ] Đã mở lại file sau xuất để kiểm tra lỗi.

## 9. Biểu mẫu ghi nhận phản hồi người đọc thử

```text
Người đọc thử / ngày:
Tóm tắt câu chuyện người đọc hiểu:
Trang hoặc panel gây nhầm:
Nhân vật / động cơ chưa rõ:
Chỗ nhịp truyện chậm hoặc vội:
Lỗi hình / chữ:
Ba sửa đổi được ưu tiên:
Kết quả sau khi sửa:
```

## 10. Gợi ý ứng dụng

Dùng biểu mẫu tiền đề và timeline cho học phần I; biểu mẫu nhân vật, đạo cụ và địa điểm cho học phần II; biểu mẫu storyboard cho học phần III; checklist nghiệm thu cho học phần IV và V. Không cần điền mọi trường nếu nó không liên quan đến câu chuyện cụ thể.
