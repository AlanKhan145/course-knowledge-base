# Bản đồ học tập và kiểm kê nguồn

## Thứ tự học

| Mô-đun | Nội dung | Kết quả |
|---|---|---|
| 01 | Nền tảng viết review | Biết phân biệt review với tóm tắt, chọn tiêu chí, lập luận bằng bằng chứng và viết theo từng nền tảng. |
| 02 | Nghiên cứu review đa nền tảng | Biết thiết kế câu hỏi, xử lý Goodreads/Douban, đối sánh dữ liệu và đọc giới hạn nghiên cứu. |
| 03 | Bản đồ và nguồn | Kiểm tra xuất xứ, bản trùng và phạm vi tài liệu đã nhập. |
