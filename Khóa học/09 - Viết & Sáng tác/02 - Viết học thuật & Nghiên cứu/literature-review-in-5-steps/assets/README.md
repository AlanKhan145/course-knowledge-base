# Visual Assets

Khóa học dùng **Mermaid diagrams** trực tiếp trong từng lesson để tránh phụ thuộc vào ảnh bên ngoài và giúp sơ đồ có thể chỉnh sửa.

## Sơ đồ đã có

- Course workflow.
- Summary → synthesis → critical evaluation.
- Keyword decomposition.
- Iterative search.
- Boolean query construction.
- Source screening pipeline.
- Backward/forward citation chaining.
- Synthesis matrix flow.
- Four review structures.
- Paragraph synthesis architecture.

## Nếu renderer không hỗ trợ Mermaid

Có thể dùng:

- GitHub Markdown;
- Obsidian;
- Typora có Mermaid;
- VS Code + Markdown Preview Mermaid Support;
- Mermaid Live Editor để export SVG/PNG.
