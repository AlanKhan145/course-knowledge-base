# Final Submission Checklist

## Content
- [ ] Tôi trả lời đúng đề/câu hỏi nghiên cứu.
- [ ] Thesis rõ.
- [ ] Evidence đầy đủ.
- [ ] Không có claim vượt quá evidence.

## Organization
- [ ] Introduction, body, conclusion đồng bộ.
- [ ] Heading logic.
- [ ] Paragraph flow rõ.

## Language
- [ ] Đã editing cho clarity/concision.
- [ ] Đã proofreading riêng.
- [ ] Terminology nhất quán.

## Sources
- [ ] Không thiếu citation.
- [ ] Reference list khớp in-text.
- [ ] Citation style đúng yêu cầu.

## Submission rules
- [ ] Word count.
- [ ] File format.
- [ ] Naming convention.
- [ ] Font / spacing / margin.
- [ ] Deadline.
- [ ] Academic integrity declaration nếu có.
