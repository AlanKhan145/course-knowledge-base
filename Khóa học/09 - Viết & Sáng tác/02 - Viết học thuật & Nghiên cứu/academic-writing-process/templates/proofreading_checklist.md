# Proofreading Checklist

## Language
- [ ] Spelling.
- [ ] Grammar.
- [ ] Punctuation.
- [ ] Capitalization.
- [ ] Article / plural / agreement.
- [ ] Tense consistency.

## Style
- [ ] US hoặc UK English nhất quán.
- [ ] Terminology nhất quán.
- [ ] Abbreviation được định nghĩa.
- [ ] Heading capitalization nhất quán.
- [ ] Number formatting nhất quán.

## Document
- [ ] Figure numbering.
- [ ] Table numbering.
- [ ] Cross-references.
- [ ] Page numbers.
- [ ] Captions.
- [ ] Appendix labels.

## Citations
- [ ] In-text citations.
- [ ] Reference list.
- [ ] DOI/URL.
- [ ] Citation style.
