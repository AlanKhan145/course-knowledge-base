# 04 — Xây dựng outline có logic

**Timestamp nguồn:** 01:12–01:52

## Vì sao cần outline?

Outline cho phép bạn kiểm tra cấu trúc **trước khi** bỏ thời gian viết thành câu hoàn chỉnh.

Một outline tốt trả lời:
- phần nào xuất hiện trước?
- mỗi section có nhiệm vụ gì?
- luận điểm nào hỗ trợ thesis?
- bằng chứng nào đi với luận điểm nào?

## Cấu trúc cơ bản

```text
I. Introduction
   A. Context
   B. Problem
   C. Research question / thesis

II. Main Point 1
   A. Claim
   B. Evidence
   C. Analysis

III. Main Point 2
   ...

IV. Conclusion
```

## Nguyên tắc hierarchy

Một mục con phải thật sự thuộc về mục cha.

Nếu `II.B` không hỗ trợ `II`, có thể:
- nó ở sai vị trí;
- nó cần section riêng;
- hoặc nó không cần xuất hiện.
