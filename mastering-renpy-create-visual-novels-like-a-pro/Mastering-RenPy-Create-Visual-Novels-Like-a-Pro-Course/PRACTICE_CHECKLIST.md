# Practice Checklist

## Cài đặt và môi trường

- [ ] Tải Ren'Py từ trang chính thức.
- [ ] Cài Ren'Py trên Windows hoặc macOS.
- [ ] Mở Ren'Py Launcher và chạy project mẫu.
- [ ] Cài Visual Studio Code.
- [ ] Mở thư mục project Ren'Py trong VS Code.

## Ren'Py cơ bản

- [ ] Khai báo nhân vật bằng `define`.
- [ ] Viết hội thoại đúng indentation.
- [ ] Dùng `scene`, `show`, `hide` để điều khiển hình ảnh.
- [ ] Thêm background và sprite đúng thư mục.
- [ ] Thêm nhạc nền hoặc sound effect.
- [ ] Dùng `menu` để tạo lựa chọn.
- [ ] Dùng `label` và `jump` để điều hướng nhánh truyện.

## Python và trạng thái game

- [ ] Tạo biến quan hệ bằng `default`.
- [ ] Tăng/giảm điểm quan hệ bằng Python line.
- [ ] Tạo flag ghi nhớ lựa chọn quan trọng.
- [ ] Kiểm tra điều kiện bằng `if`, `elif`, `else`.
- [ ] Xác định nhân vật có điểm cao nhất ở cuối game.

## Screen và UI

- [ ] Tạo screen trạng thái quan hệ.
- [ ] Dùng `frame` để tạo khung.
- [ ] Dùng `vbox` để sắp xếp text.
- [ ] Hiển thị điểm Alex, Emma và Lily.
- [ ] Cập nhật UI khi biến thay đổi.

## Minigame

- [ ] Thiết kế câu đố Caesar Cipher.
- [ ] Cho người chơi nhập hoặc chọn đáp án.
- [ ] Giới hạn ba lần thử.
- [ ] Xử lý giải đúng.
- [ ] Xử lý hết lượt.
- [ ] Dùng kết quả minigame để mở hoặc khóa nội dung.

## Ending và QA

- [ ] Tạo ending Alex.
- [ ] Tạo ending Emma.
- [ ] Tạo ending Lily.
- [ ] Tạo ending tình bạn.
- [ ] Test mỗi ending ít nhất một lần.
- [ ] Kiểm tra không có biến chưa khai báo.
- [ ] Kiểm tra save/load không làm hỏng điểm quan hệ.
- [ ] Build thử project bằng Ren'Py Launcher.
