## Nội dung bài học

Bài học hướng dẫn truy cập trang chính thức của Ren'Py, tìm phần tải xuống và chọn phiên bản phù hợp với hệ điều hành. Nội dung minh họa việc tải bộ cài dành cho macOS và mở tệp cài đặt từ thư mục Downloads.

## Mục tiêu sau bài học

- Biết nơi tải Ren'Py đáng tin cậy.
- Chọn đúng bản tải cho Windows hoặc macOS.
- Hiểu rằng Ren'Py nên được tải từ nguồn chính thức để tránh bản cũ hoặc bị chỉnh sửa.

## Việc cần làm

- [ ] Truy cập trang tải Ren'Py chính thức.
- [ ] Xác định hệ điều hành đang dùng.
- [ ] Tải bản Ren'Py phù hợp.
- [ ] Lưu file tải về vào vị trí dễ tìm.
