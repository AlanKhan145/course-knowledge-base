# Module 01 - Installation and Interface of Ren'Py

## Tổng quan

Module này chuẩn bị môi trường làm visual novel: tải Ren'Py, cài đặt trên Windows/macOS, làm quen Ren'Py Launcher và cấu hình VS Code làm trình soạn thảo script.

| Bài | Tên bài | Thời lượng | Kết quả |
| --- | --- | --- | --- |
| 001 | Downloading Ren'Py | 00:57 | Tải đúng bản Ren'Py |
| 002 | Installing Ren'Py | 01:21 | Cài và chạy Ren'Py lần đầu |
| 003 | Launcher Interface | 08:05 | Biết các chức năng chính trong Launcher |
| 004 | Installing the VS Code Editor | 02:49 | Mở project Ren'Py trong VS Code |

## Kết quả sau module

- Ren'Py đã được cài và mở được.
- VS Code đã sẵn sàng để chỉnh file `.rpy`.
- Bạn biết tạo project, mở script, quản lý asset, chỉnh GUI và build project từ Launcher.
