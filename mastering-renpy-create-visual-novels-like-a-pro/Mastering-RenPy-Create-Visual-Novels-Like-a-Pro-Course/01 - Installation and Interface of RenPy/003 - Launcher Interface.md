# 003 - Launcher Interface

## Module

Module 01 - Installation and Interface of Ren'Py

## Thời lượng

8 phút 5 giây

## Nội dung bài học

Đây là bài dài nhất trong module đầu tiên. Bài học giới thiệu màn hình chính của Ren'Py Launcher và các thao tác quan trọng khi làm project visual novel.

## Chủ điểm chính

- Tạo và quản lý project.
- Mở script của game.
- Truy cập thư mục hình ảnh và tài nguyên.
- Điều chỉnh giao diện GUI.
- Thay đổi thiết lập project.
- Truy cập phần Preferences.
- Tạo bản phát hành game.
- Đóng gói game cho Windows và macOS.
- Chuẩn bị bản dựng Android, iOS và web.
- Sử dụng công cụ tạo bản dịch.

## Mục tiêu sau bài học

- Biết Launcher dùng để làm gì ngoài việc bấm Launch Project.
- Mở nhanh các file và thư mục cần thiết khi làm visual novel.
- Nắm khái niệm build/export trước khi hoàn thiện game.

## Việc cần làm

- [ ] Tạo một project Ren'Py thử.
- [ ] Mở `script.rpy` từ Launcher.
- [ ] Mở thư mục `images` hoặc thư mục game.
- [ ] Vào Preferences và xem các tùy chọn chính.
- [ ] Tìm mục build/distribute để biết nơi xuất bản game.
