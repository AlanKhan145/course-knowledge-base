# 005 - Evening Encounter Scene

## Module

Module 02 - Creating Your First Game

## Thời lượng

12 phút

## Nội dung bài học

Bài học tạo scene gặp gỡ vào buổi tối, cho người chơi lựa chọn giữa Alex và Emma, mở rộng tuyến truyện riêng, tiết lộ quá khứ hoặc động cơ cảm xúc của nhân vật, đồng thời dùng flag để ghi nhớ hành động.

## Mục tiêu sau bài học

- Tạo scene có không khí riêng bằng background, âm thanh và lời thoại.
- Dùng flag để lưu lựa chọn ngoài điểm quan hệ.
- Hiển thị thông báo khi điểm hoặc trạng thái thay đổi.
- Chuẩn bị dữ kiện cho scene sau.

## Ghi chú script

```renpy
default praised_alex = False
default praised_emma = False
```

## Việc cần làm trong Ren'Py

- [ ] Viết scene buổi tối.
- [ ] Tạo lựa chọn gặp Alex hoặc Emma.
- [ ] Thêm flag lời khen hoặc hành động đáng nhớ.
- [ ] Tăng điểm quan hệ thông qua dialogue.
- [ ] Hiển thị thông báo trạng thái nếu cần.

## Kiểm tra nhanh

- [ ] Flag chỉ đổi khi người chơi chọn đúng nhánh.
- [ ] Scene sau có thể đọc flag để phản hồi lựa chọn trước.
- [ ] Không có lựa chọn nào dẫn tới đoạn truyện cụt.
