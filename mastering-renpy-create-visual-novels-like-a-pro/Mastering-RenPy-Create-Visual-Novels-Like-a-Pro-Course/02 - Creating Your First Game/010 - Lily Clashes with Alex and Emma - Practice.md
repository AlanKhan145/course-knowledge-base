# 010 - Lily Clashes with Alex and Emma

## Module

Module 02 - Creating Your First Game

## Thời lượng

9 phút 3 giây

## Nội dung bài học

Bài học tạo cuộc xung đột giữa Lily, Alex và Emma, đưa các mâu thuẫn trước đó trở lại câu chuyện. Người chơi chọn cách giải quyết, điểm quan hệ thay đổi và lựa chọn được ghi nhớ bằng biến để chuẩn bị xác định ending.

## Mục tiêu sau bài học

- Tạo scene cao trào trước ending.
- Cho quyết định trước đó ảnh hưởng cảm xúc hiện tại.
- Ghi nhớ lựa chọn giải quyết xung đột.
- Chuẩn bị điều kiện phân nhánh cuối game.

## Ghi chú script

```renpy
default final_conflict_choice = ""
```

## Việc cần làm trong Ren'Py

- [ ] Gọi lại các flag đã tạo ở scene trước.
- [ ] Cho Alex, Emma và Lily phản ứng khác nhau.
- [ ] Tạo lựa chọn cách giải quyết.
- [ ] Thay đổi cả ba điểm quan hệ nếu cần.
- [ ] Gán `final_conflict_choice`.

## Kiểm tra nhanh

- [ ] Scene phản ánh kết quả minigame hoặc bí mật của Lily nếu phù hợp.
- [ ] Không có điểm quan hệ bị cập nhật nhầm.
- [ ] Cuối scene dẫn tới label kiểm tra ending.
