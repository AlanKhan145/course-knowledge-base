# 007 - Navigating Figma – Frames, layers, menus

## Section

Crash Course: Figma for Non-Designers

## Duration

2:28

## Main Idea

This lesson builds practical navigation skills inside the Figma workspace, covering how frames are organized, how the layers panel reflects the structure of a design, and where to find the top menus that control view and edit options. It also gives a first look at the inspector panel, which will become important later for reading exact CSS values off a design. Learning to move around the interface confidently is a prerequisite for everything else in the section, since every later lesson assumes the learner can locate frames and layers without hesitation. This hands-on orientation turns Figma from an intimidating blank canvas into a familiar workspace.

## Key Topics Mentioned

* Reading and organizing frames in a Figma file
* Using the layers panel to understand design structure
* Key top-menu options for viewing and editing
* A first look at the inspector panel
* General workspace navigation habits for developers
