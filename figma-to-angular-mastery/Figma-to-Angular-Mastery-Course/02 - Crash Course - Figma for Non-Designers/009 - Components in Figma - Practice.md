# 009 - Components in Figma – Buttons, inputs, icons

## Section

Crash Course: Figma for Non-Designers

## Duration

2:20

## Main Idea

This lesson explains Figma's component system -- components, instances, and variants -- through the lens of common UI pieces like buttons, inputs, and icons. Rather than treating this as pure design theory, the lesson frames each concept from a developer's point of view, drawing a direct line to how the same pieces will later become reusable Angular components. Understanding the component/instance relationship in Figma makes it much easier to spot which parts of a design are meant to be reusable versus one-off. This developer-first framing of Figma components sets up the more advanced variants and Auto Layout material in the next lesson.

## Key Topics Mentioned

* Figma components as reusable design definitions
* Instances as copies linked back to a component
* Common examples: buttons, inputs, icons
* Spotting reusable pieces versus one-off elements
* Connecting Figma components to future Angular components
