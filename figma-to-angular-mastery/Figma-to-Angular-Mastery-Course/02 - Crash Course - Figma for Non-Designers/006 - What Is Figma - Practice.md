# 006 - What Is Figma – Cloud Design Tool Explained Simply

## Section

Crash Course: Figma for Non-Designers

## Duration

2:24

## Main Idea

This lesson gives developers with no design background a plain-language introduction to Figma as a cloud-based design tool. It explains the core concepts -- the canvas, frames, layers, and components -- and shows how they map onto the kind of UI structure a developer already thinks in. It also covers Figma's real-time collaboration model, since design files are often shared and edited by multiple people at once. Establishing this vocabulary early means every later lesson in the section can reference frames, layers, and components without re-explaining them.

## Key Topics Mentioned

* Figma as a cloud-based, collaborative design tool
* The canvas as the infinite workspace for designs
* Frames as containers for screens or sections
* Layers as the building blocks stacked inside frames
* Components as reusable design elements
* Real-time collaboration between multiple designers/developers

## Summary

Introduces Figma as a cloud design tool built around canvas, frames, layers, and components, with real-time collaboration at its core, framed specifically for developers with no design background. This lesson is one building block toward the section's goal: giving developers enough Figma literacy to read a design file confidently before automating anything with AI.
