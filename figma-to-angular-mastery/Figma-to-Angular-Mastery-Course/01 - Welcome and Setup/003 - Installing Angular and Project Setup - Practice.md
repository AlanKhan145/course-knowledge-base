# 003 - Installing Angular & Project Setup – Hello Angular + Tailwind

## Section

Welcome & Setup

## Duration

2:58

## Main Idea

This lesson walks through the practical setup needed before any Figma-to-code work can happen: installing Node.js and the Angular CLI, then scaffolding a brand-new Angular project from scratch. It continues by wiring up Tailwind CSS into that fresh project so utility classes are available immediately. The lesson closes with a working "Hello Angular" screen styled with a Tailwind class, proving the environment is fully functional end to end. Having this baseline project running means every later lesson can focus purely on building components instead of fighting environment setup.

## Key Topics Mentioned

* Installing Node.js as a prerequisite
* Installing the Angular CLI globally
* Scaffolding a new Angular project
* Adding and configuring Tailwind CSS in the project
* Verifying the setup with a styled "Hello Angular" screen
