# 023 - Build Molecules – Combine Atoms into Functional UI Blocks

## Section

Molecules in Angular

## Duration

4:34

## Main Idea

This hands-on lesson takes the atoms built in the previous section and combines them into Molecules -- small, functional UI blocks such as a search box, a card title block, and an input-with-button combination. Building these pieces means working with Flex/Grid layout to arrange atoms correctly, then refining spacing and responsiveness with Windsurf until the molecule matches its Figma counterpart. Because molecules depend directly on the atoms already built, this lesson also tests whether those atoms were designed with enough flexibility to be reused in different combinations. Getting molecules right here sets up the more complex organism-level assembly that follows in the next section.

## Key Topics Mentioned

* Combining atoms into functional Molecules
* Building a search box as a molecule example
* Building a card title block and input-with-button combos
* Using Flex/Grid layout to arrange atoms
* Refining spacing and responsiveness with Windsurf
