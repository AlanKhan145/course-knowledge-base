# 013 - Why Windsurf – AI-powered coding explained simply

## Section

AI + Windsurf Editor Magic

## Duration

2:11

## Main Idea

This lesson explains, in plain language, why Windsurf is the AI editor of choice for this course rather than a simple autocomplete tool. It highlights that Windsurf understands the whole project context -- the Angular file structure, the Tailwind configuration, and existing component conventions -- instead of just predicting the next line of code in isolation. This whole-project awareness is what makes it possible to hand Windsurf a Figma screenshot and get back a component that actually fits the existing codebase. Understanding this distinction is the foundation for every workflow the rest of this section builds on top of.

## Key Topics Mentioned

* Windsurf as a whole-project-aware AI coding assistant
* Difference between line-level autocomplete and project-aware AI
* Understanding Angular structure and Tailwind config context
* Why project awareness matters for generating fitting components
