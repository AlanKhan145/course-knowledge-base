## Main Idea

This lesson walks through the concrete setup steps for using Windsurf against the Angular + Tailwind project built earlier in the course: installing the editor, opening the existing project inside it, and adding any Angular- or Tailwind-aware extensions that improve the AI's understanding of the codebase. It closes with running a first test prompt to confirm the assistant is correctly wired up and responding with sensible, project-aware suggestions. Getting this setup right before moving forward avoids wasted time troubleshooting configuration issues mid-build later in the course. This is the practical prerequisite that every subsequent AI-assisted lesson depends on.
