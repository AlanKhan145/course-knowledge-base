## Main Idea

This lesson lays out the end-to-end loop that powers the rest of the course: prompt Windsurf with a Figma screenshot or frame, preview the generated Angular component, and refine it through follow-up prompts until it matches the design. Naming and formalizing this loop turns what might feel like an unstructured, ad hoc process into a repeatable workflow that can be applied to any component, not just the examples shown in class. It's the practical answer to the course's opening promise of going from Figma to Angular in under an hour. Every hands-on build lesson from this point forward is really just this loop applied to a specific atom, molecule, organism, template, or page.

## Key Topics Mentioned

* The prompt → preview → refine loop
* Using a Figma screenshot or frame as the prompt input
* Generating a first-pass Angular component with Windsurf
* Refining output through follow-up prompts
* Applying the loop consistently across the rest of the course
