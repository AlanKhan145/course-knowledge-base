# 024 - Build Organisms – Complex Components Like Navbars & Cards

## Section

Organisms in Angular

## Duration

4:04

## Main Idea

This hands-on lesson assembles the atoms and molecules built in the previous two sections into complete, complex UI sections -- Organisms -- such as a Navbar, a Product Card, and a Footer. Each organism is built by composing smaller pieces together rather than starting from scratch, reinforcing the value of the Atomic Design hierarchy established earlier in the course. The lesson also includes responsive testing across tablet and mobile breakpoints, verifying that the composed organism holds together visually and structurally at every screen size. This is the point where the UI starts looking like a real, cohesive application section rather than a set of isolated components.

## Key Topics Mentioned

* Assembling a Navbar organism from atoms and molecules
* Assembling a Product Card organism
* Assembling a Footer organism
* Composing smaller components instead of building from scratch
* Responsive testing across tablet and mobile breakpoints
