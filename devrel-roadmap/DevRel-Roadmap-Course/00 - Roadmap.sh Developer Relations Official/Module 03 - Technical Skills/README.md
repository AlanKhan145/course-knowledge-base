# Module 03 - Technical Skills

## Mục tiêu module
Có năng lực kỹ thuật đủ để đọc code, viết demo, hiểu API/SDK, dùng GitHub và tạo tài liệu kỹ thuật.

## Thực hành trọng tâm
Tạo một sample project nhỏ dùng API/SDK, có README chạy được và troubleshooting ngắn.

## Output sau module
- Runnable demo, API/SDK quickstart and GitHub feedback workflow
- Một decision note hoặc content/support/community plan có thể chia sẻ với team
- Danh sách friction, insight hoặc feedback cần gửi lại product/engineering
