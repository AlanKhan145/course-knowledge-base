# Module 08 - Career Development

## Mục tiêu module
Biết phát triển sự nghiệp DevRel qua thought leadership, personal brand, networking và học liên tục.

## Thực hành trọng tâm
Chọn niche DevRel cá nhân, viết bio, talk proposal và kế hoạch xuất bản 30 ngày.

## Output sau module
- Personal DevRel brand plan, CFP/talk proposal and learning roadmap
- Một decision note hoặc content/support/community plan có thể chia sẻ với team
- Danh sách friction, insight hoặc feedback cần gửi lại product/engineering

## Checklist hoàn thành
- [ ] Đọc toàn bộ bài học trong module
- [ ] Tạo ít nhất một artifact thực hành
- [ ] Liên hệ nội dung với developer journey thật
- [ ] Ghi lại 3 điều sẽ áp dụng trong công việc DevRel
