# 003 - AI Generation Technique

## Section

Vibe-Coding Figma Design System Components with Cursor & Figma MCP

## Duration

1:30

## Main Idea

Explains the prep-before-generation technique that carries through the rest of the video: just as
AI produces better full designs when it's first prepped with a PRD, it produces better
components when it's first prepped with the design system's tokens and variables. Skipping that
prep and asking AI to build components straight away causes the output to drift from the design
system over time. Applied to full designs, the same principle extends to components and
variables — without that grounding, generated designs may reference the wrong component or
variable, forcing a costly rewire later once the design is developed/coded. By the end of the
lesson, learners should see how AI Generation Technique connects to the token-first workflow used
in the rest of the video.

## Key Topics Mentioned

* Prepping AI with context before generation (PRD analogy from the academy's AI design course)
* Why skipping variable/token prep causes drift in generated components
* Extending the same principle to full AI-generated designs (correct component/variable usage)
* The cost of not doing this: rewiring coded designs back to the right components/variables later

## Summary

Explains why AI needs to be prepped with design-token and variable context before generating
components or designs, drawing a parallel to prepping AI with a PRD before building an app —
skip this step and the output drifts from the design system. This lesson is one building block
toward the section's goal: teaching how to connect Cursor to Figma via the Figma MCP server, feed
AI the right design-token context, and vibe-code initial React design system components that stay
wired to Figma variables.
