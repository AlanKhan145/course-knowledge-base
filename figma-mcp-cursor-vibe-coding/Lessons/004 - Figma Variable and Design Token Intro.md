# 004 - Figma Variable and Design Token Intro

## Section

## Duration

## Main Idea

Introduces the Figma file used for the demo (the UI Collective Kit, a design system tied to the
academy) and its Variables panel: brand variables, alias variables, and mapped variables, plus
token references, gradients, and opacity values. These are the values that need to be imported
into Cursor before any tokens or components get coded. The brand → alias → mapped collection
structure is called out as the same structure used professionally whenever building design
systems for clients. By the end of the lesson, learners should see how Figma Variable and Design
Token Intro connects to the vibe-coding session that follows, since Cursor needs to understand
this exact collection structure to generate tokens correctly.

## Key Topics Mentioned

* UI Collective Kit as the demo design system (componentry- and token-focused)
* Figma Variables panel: brand, alias, mapped collections
* Token references, gradients, and opacity variables
* The brand → alias → mapped structure as a professional design-system convention
