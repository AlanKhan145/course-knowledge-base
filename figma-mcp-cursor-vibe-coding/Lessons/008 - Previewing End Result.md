# 008 - Previewing End Result

## Section

Vibe-Coding Figma Design System Components with Cursor & Figma MCP

## Duration

1:42

## Main Idea

Reviews the generated result at the local dev server URL: a design-token preview panel (flagged as
not necessarily accurate and removable via a follow-up prompt), the initial button components
matching the original Figma variants, and an interactive demo showing hover, click, and focus
states. Hover states darken slightly and react correctly to naming, but a visual gap is spotted —
the generated hover state is missing the light outer-glow effect present on the original Figma
buttons' hover state — which is called out as something to fix through a follow-up dialogue with
Cursor rather than a one-shot generation. Clicking a button shows a "button clicked" state along
with a visible focus ring. The chapter closes by noting the whole exercise, from MCP connection to
working components, took under 20 minutes, and frames this as useful for interviews, developer
demos, and pushing initiatives in a design role. By the end of the lesson, learners should see how
Previewing End Result connects back to the full workflow: research tokens, build tokens, select
components, generate components, then verify and iterate against the original Figma source.

## Key Topics Mentioned

* Local dev server preview of generated design tokens and button components
* Interactive states: hover, click ("button clicked"), and focus ring
* Spotting a missed hover effect (outer glow) versus the original Figma design
* Iterating with follow-up prompts rather than expecting a perfect first pass
* Time-to-result: initial components coded in under 20 minutes
* Practical use cases: interviews, developer demos, career advancement in design roles

Reviews the generated button components and their interactive states in the browser, spots a
missed hover-glow effect compared to the original Figma design, and frames fixing that as a
follow-up dialogue with Cursor rather than a one-shot task — all completed in under 20 minutes.
