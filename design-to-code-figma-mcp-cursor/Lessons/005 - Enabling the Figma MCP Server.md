# 005 - Enabling the Figma MCP Server

## Section

Module 3: Setting Up Figma MCP and Cursor

## Duration

0:55

## Main Idea

Shows how to turn on the Figma MCP Server, noting that Figma has moved this control since an
earlier channel video (it used to live under Preferences/Options). Now, enabling the MCP server
requires switching the file into Dev Mode first (bottom toolbar), after which the MCP Server
control appears in the right-side panel, showing its current on/off status. The presenter
confirms theirs is already enabled and shows where to toggle it.

## Key Topics Mentioned

* Figma's UI for MCP Server access has changed over time
* Dev Mode must be enabled first (bottom toolbar control)
* MCP Server control/status now lives in the right-side panel in Dev Mode
* MCP Server can be toggled on/off from that panel

## Review Questions

1. What is the prerequisite step before you can see the MCP Server toggle in the current Figma UI?
2. Where in the interface did the MCP Server control used to live, and where is it now?
3. How do you confirm the MCP Server is actually running for a given file?

## Summary

A short, UI-focused lesson: switch the Figma file into Dev Mode via the bottom toolbar, then find
and enable the MCP Server toggle in the right-side panel. Flags that this location changed
recently, so viewers relying on older tutorials may need to look in Dev Mode rather than
Preferences.
