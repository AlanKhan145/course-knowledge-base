# 013 - Testing the App in iOS Simulator

## Section

Module 6: Turning the Project into an iOS App

## Duration

2:04

## Main Idea

Closes out the tutorial by actually launching and testing the generated app in iOS Simulator. The
Simulator opens and runs the app; the presenter clicks through the Main, Bitcoin, and Ethereum
wallet tabs, then the Send Money screen, entering an amount and selecting a recipient from
contacts before tapping Send (which triggers a native macOS-style pop-up). Some UI bugs are
visible along the way, and the presenter has Cursor fix a few of them live, including adding
missing icons. The lesson — and the video — ends with a time/cost recap: the whole build took
roughly 30–40 minutes, including debugging several errors that Cursor was able to resolve, which
the presenter frames as saving what would otherwise be one to two days of manual development.

## Key Topics Mentioned

* Opening and running the generated app in iOS Simulator
* Testing tabs: Main wallet, Bitcoin wallet, Ethereum wallet
* Testing the Send Money screen end-to-end (amount, recipient, send action)
* Native-style pop-up triggered by the Send action
* Live bug fixing with Cursor (including missing icons)
* Total time spent: ~30–40 minutes, including error recovery
* Framing: this saved roughly 1–2 days of manual development time

Wraps up the project by running the generated app in iOS Simulator and manually testing every
screen built so far — the three wallet tabs and the Send Money flow — while fixing small UI bugs
live with Cursor. Ends on a practical cost/benefit note: about 30–40 minutes of total AI-assisted
build-and-debug time versus an estimated 1–2 days doing the same work by hand.
