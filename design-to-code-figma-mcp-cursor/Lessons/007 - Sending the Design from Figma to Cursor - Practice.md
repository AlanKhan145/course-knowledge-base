# 007 - Sending the Design from Figma to Cursor

## Section

Module 4: Turning the Figma Design into a ReactJS App

## Duration

1:45

## Main Idea

Demonstrates the actual hand-off: select the target frame in Figma, then use the example prompt
that Figma's MCP panel auto-generates for that selection (copy it via "Copy example prompt").
Paste that into Cursor's chat, pick a capable model (the presenter chooses Sonnet 4.5), and extend
the auto-generated prompt with two explicit asks: implement the design in ReactJS with close
attention to the file's variables, and generate a `design-system.json` file so future screens stay
consistent. The extended prompt used is given verbatim.

## Key Topics Mentioned

* Selecting a frame in Figma to expose the MCP panel's example prompt
* "Copy example prompt" feature in the MCP panel
* Pasting into Cursor chat and choosing a model (Sonnet 4.5)
* Extending the prompt beyond Figma's default text
* Explicit ask: generate a `design-system.json` for future consistency

## Prompt Used

```
Implement this design from Figma using ReactJS.
Pay close attention to the details and variables used in the file.
Create a design system file in JSON format to keep future designs consistent.
```

## Review Questions

1. Where does the starting-point prompt text actually come from — is it hand-written or
   auto-generated?
2. What two additions does the presenter make on top of Figma's default example prompt?
3. Why ask for a JSON design system file specifically, rather than relying on the generated CSS
   alone (this is elaborated further in Lesson 8)?

## Summary

Shows the core hand-off step: select a frame in Figma, copy its MCP-generated example prompt, and
paste it into Cursor. The presenter augments that default prompt with an instruction to implement
in ReactJS with attention to variables, and to additionally output a `design-system.json` file —
setting up long-term consistency for screens built later in the project.
