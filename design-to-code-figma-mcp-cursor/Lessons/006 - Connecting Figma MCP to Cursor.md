# 006 - Connecting Figma MCP to Cursor

## Section

Module 3: Setting Up Figma MCP and Cursor

## Duration

1:14

## Main Idea

Covers the client-side half of the MCP connection: installing the Figma MCP integration into
Cursor. The presenter visits Figma's developer-facing setup page, picks Cursor as the target tool,
and clicks the provided link, which prompts the browser to open Cursor and confirm the install.
After accepting, the MCP integration is installed into Cursor with no further configuration
needed. The lesson closes by opening the actual project folder in Cursor, ready for the first
prompt.

## Key Topics Mentioned

* Figma's developer setup page for connecting external tools
* Choosing "Cursor" as the target integration
* Browser → Cursor handoff and permission prompt
* One-click install, no manual config
* Opening the project folder in Cursor as the next step

## Review Questions

1. What site does the presenter use to find the Cursor-specific MCP setup link?
2. What confirmation step does the browser show before Cursor is actually configured?

   Figma-to-code prompt?

## Summary

Completes the MCP connection by installing the Figma MCP integration into Cursor via Figma's
developer setup page, approving the browser-to-Cursor handoff, and confirming installation. Ends
with the project folder open in Cursor, set up for the first design-to-code prompt in the next
lesson.
