# Module 02 - Foundational Knowledge - Kiến thức nền tảng

## Mục tiêu module
Có nền kỹ thuật đủ để đánh giá system design, technical debt và documentation.

## Thực hành trọng tâm
Chọn một hệ thống quen thuộc, đánh giá architecture, code quality, technical debt và tài liệu còn thiếu.

## Output sau module
- Technical foundation review checklist
- Một decision note hoặc checklist có thể dùng lại
- Danh sách rủi ro, câu hỏi mở hoặc việc cần follow-up

## Checklist hoàn thành
- [ ] Đọc toàn bộ bài học/project trong module
- [ ] Tạo ít nhất một artifact thực hành
- [ ] Liên hệ nội dung với một team, hệ thống hoặc dự án thật
- [ ] Ghi lại 3 điều sẽ áp dụng trong vai trò Engineering Manager
