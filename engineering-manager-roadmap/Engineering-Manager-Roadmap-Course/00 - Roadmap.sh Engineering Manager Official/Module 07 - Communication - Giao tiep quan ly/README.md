# Module 07 - Communication - Giao tiếp quản lý

## Mục tiêu module
Biết vận hành các kênh giao tiếp quản lý: 1-1, team meeting, status, stakeholder và cross-functional collaboration.

## Thực hành trọng tâm
Thiết kế meeting cadence, 1-1 template, status report và stakeholder update cho một team engineering.

## Output sau module
- Communication cadence and stakeholder update template
- Một decision note hoặc checklist có thể dùng lại
- Danh sách rủi ro, câu hỏi mở hoặc việc cần follow-up

## Checklist hoàn thành
- [ ] Đọc toàn bộ bài học/project trong module
- [ ] Tạo ít nhất một artifact thực hành
- [ ] Liên hệ nội dung với một team, hệ thống hoặc dự án thật
- [ ] Ghi lại 3 điều sẽ áp dụng trong vai trò Engineering Manager
