# Module 04 - Quality and Process - Chất lượng và quy trình

## Mục tiêu module
Biết xây quy trình chất lượng: monitoring, CI/CD, release, testing, standards và incident management.

## Thực hành trọng tâm
Thiết kế quality bar cho một team: testing, CI/CD, release workflow, monitoring và incident handling.

## Output sau module
- Quality/process operating checklist
- Một decision note hoặc checklist có thể dùng lại
- Danh sách rủi ro, câu hỏi mở hoặc việc cần follow-up

## Checklist hoàn thành
- [ ] Đọc toàn bộ bài học/project trong module
- [ ] Tạo ít nhất một artifact thực hành
- [ ] Liên hệ nội dung với một team, hệ thống hoặc dự án thật
- [ ] Ghi lại 3 điều sẽ áp dụng trong vai trò Engineering Manager
