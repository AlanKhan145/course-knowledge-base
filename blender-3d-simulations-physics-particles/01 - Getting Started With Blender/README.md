# Module 01 — Làm quen với Blender

**8 bài • 1 giờ 01 phút**

Module này tạo nền tảng tối thiểu để đọc giao diện, điều hướng scene, thao tác object và kiểm tra animation trước khi đi vào solver.

## Mục tiêu

- Cài Blender, chọn ngôn ngữ và phụ đề.
- Điều hướng viewport nhanh bằng chuột và phím tắt.
- Phân biệt Object Mode và Edit Mode.
- Di chuyển, xoay, scale object với transform có kiểm soát.
- Tạo keyframe và đọc một animation đơn giản.

## Bài thực hành đề xuất

Tạo một scene gồm một cube, một plane và một camera. Cho cube rơi từ frame 1 đến frame 48, đặt keyframe cho vị trí và xoay, rồi kiểm tra chuyển động từ camera. Lưu lại file trước khi chuyển sang module 02.

## Checklist

- [ ] Biết chuyển giữa Object Mode và Edit Mode.
- [ ] Đã Apply Scale cho object dùng làm collision.
- [ ] Đã đặt keyframe ở ít nhất hai frame.
- [ ] Có thể kiểm tra animation bằng Play, Scrub và Go to Frame.
- [ ] Có thể lưu một phiên bản `.blend` riêng cho từng project.

## Quiz Section 1 — trọng tâm ôn tập

Giải thích sự khác nhau giữa transform của object và transform của mesh; vì sao cần kiểm tra scale trước khi chạy simulation; và cách xác định một keyframe đang tác động lên thuộc tính nào.
